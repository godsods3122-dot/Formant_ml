## 0. 이 작업의 원칙 (가장 중요)

**우리는 귀가 없다.** 사용자가 "이상하다" 고 하면 추측해서 손잡이를 돌리는 게
아니라, **재고 숫자를 비교**한 다음 그 차이를 물리로 설명하고 고친다. 지금까지
진짜 원인은 **한 번도** 처음 짐작한 곳에 있지 않았다.

**파라미터가 아니라 구조를 고친다.** 곡선을 손으로 그려 맞추면 다음 요청에서
반드시 무너진다.

**측정이 underdetermined 인지 늘 의심하라.** 이번 세션의 가장 큰 실수가 그것이다.
호흡 구동 상수를 "정점 위치 57 %, 상승/하강비 1.3" 에 맞춰 적합했는데, **그 두
숫자는 평탄한 고원형과 아치형을 구분하지 못한다.** 그래서 3 개월간 틀린 구조가
"실측과 맞는다" 는 상태로 남아 있었다. 지표를 하나 더 찾아라(여기서는 정점 -3 dB
이내 비율).

## 2. 물리 구조 (무엇이 무엇을 만드는가)

```
폐압 Ps (거의 일정!) ──┐
                       │   ┌── 성문 Ag ──┐
                       └──>│   직렬 유량 U │──> 구강 협착 Ac ──> 입술
                           └── (기식)   ──┘      (마찰음)
                                  │                │
                                  │          Po 구강내압 (혀가 만든다)
                                  │                │
                            (Ps − Po) ──> 발성 역치 ──> 유성
```

**핵심 인과 사슬** — 이걸 깨뜨리면 소리가 무너진다.

1. **마찰음 포락선은 혀가 만든다. 호흡압이 아니다.** (§3.1, §5.1) Ps 는 마찰음
   내내 거의 일정하고, 변하는 건 협착이 만드는 Po 다.
2. **정점 위치 = 폐쇄시간/(폐쇄시간+해제시간).** Ps 가 일정하면 협착부 속도가
   Ac 의 단조감소 함수라 포락선 정점이 협착 최소와 **정확히** 일치한다.
   실측 상승/하강비 1.3 은 곧 "혀가 닫을 때가 열 때보다 1.3 배 느리다" 는 뜻이다.
3. **구강내압이 발성 개시를 정한다.** /s/ 동안 Po 가 Ps 의 85 % 를 먹어
   (Ps−Po) 가 역치에 못 미친다. 협착이 열려 Po 가 빠져야 떨기 시작한다.
   VOT 를 손으로 박지 않는다.
4. **마찰음을 끝내는 건 혀다. 후두가 아니다.** /s/ 는 성문을 벌린 채 낸다.
5. **마찰음과 목소리를 잇는 건 기식이다.** 마찰음 꼬리가 아니다.
6. **앞니 공명은 순수 기하다.** 기류 속도로 그 주파수를 옮기면 /s/ 가 /ʃ/ 로
   시작한다(§5.2).

## 3. 논문 요약 — **원본이 없어도 여기서 작업할 수 있게 적었다**

### 3.1 Signorello, Hassid & Demolin (2018) — 가장 중요

> *Toward an aerodynamic model of fricative consonants.*
> J. Acoust. Soc. Am. 143(5), EL386–EL392. doi:10.1121/1.5038123

**방법**: 벨기에 프랑스어 4 명(남 2 여 2). 성문하압 Ps 를 **기관 천자**(윤상연골
아래 바늘)로 **직접** 측정 — 추정이 아니다. 구강내압 Po 는 비강으로 넣은 관을
연구개 뒤 인두에 두고, 구강 유량 Oaf 는 실리콘 마스크로. VCV 무의미어
[f,v,s,z,ʃ,ʒ] × [i,a,u], 5 회 반복. 마찰음의 **개시(Fs) / 중간(Fm) / 종료(Fr)**
세 점에서 측정.

**/s/ 의 값** (hPa; 1 hPa = 1.019 cmH₂O = 1019 dyn/cm²):

| | 맥락 | 개시 Fs | 중간 Fm | 종료 Fr |
|---|---|---|---|---|
| **Ps** (성문하압) | i / a / u | 10.6 / 8.0 / 10.1 | 10.2 / **8.9** / 10.2 | 9.9 / 8.4 / 9.7 |
| **Po** (구강내압) | i / a / u | 4.8 / 2.5 / 4.6 | 8.7 / **7.6** / 9.1 | 6.3 / 5.6 / 6.0 |
| **ΔPs/Po** | i / a / u | 5.8 / 5.5 / 5.5 | 1.5 / **1.3** / 1.2 | 3.6 / 2.8 / 3.7 |
| **Oaf** (dm³/s) | i / a / u | 0.3 / 0.5 / 0.4 | 0.3 / **0.3** / 0.3 | 0.3 / 0.5 / 0.5 |
| **Int** (dB) | i / a / u | 59 / 61 / 61 | 59 / 57 / 57 | 54 / 58 / 61 |

**Po/Ps (중간점)**: [isi] 0.85, [asa] 0.85, [usu] 0.89.

**결정적 문장** (본문 4.2):
> *"Audible voiceless frication was sustained by a substantial decrease in ΔPs/Po
> and an increased Po which resulted from **constant high Ps** and a substantial
> increase in Po."*

전체 통계: 개시에서 Ps 평균 10.06 hPa (범위 4.37~16.93), Po 평균 3.31 hPa
(범위 0.41~8.74), Oaf 범위 0.06~1.05 dm³/s (n=336).

**읽어야 할 것 세 가지**:
1. **Ps 는 마찰음 내내 거의 일정하다** (8.0 → 8.9 → 8.4). 아치가 아니다.
2. **Po 는 낮게 시작해 크게 올랐다가 내려온다** (2.5 → 7.6 → 5.6).
3. **유량은 U 자다** — 양끝이 높고 가운데가 낮다 (0.5 → 0.3 → 0.5).
   개시는 협착이 아직 없어서, 종료는 **쌓인 Po 가 열린 협착으로 방전**돼서다
   (파열음 버스트와 같은 원리).

또: 무성 마찰음은 성문 개대가 크고 **선행 모음에서 이미 시작**된다. 그래야
후두 저항이 낮아져 Po 가 쌓인다.

### 3.2 Kim, Hwang, Ahn, Honda, Maeda (2022) — 한국어

> *External photoglottography, intra-oral air pressure, airflow and acoustic data
> on the Korean fricatives /s', s/.* Phonetics and Speech Sciences 14(3), 11–25.

**방법**: 서울 한국어 4 명(남 2 여 2). ePGG(외부 광성문촬영) + Pio + 유량 + 음향
**동시** 녹음. 문맥 /_a_a/, /_ama/, /ma_a/ (예: /sasa/, /sama/, /masa/).

**결정적 문장**:
> *"the duration of a **high Pio plateau**, which is **the aerodynamic counterpart
> of the acoustic frication duration** during oral constriction of a fricative"*

즉 한국어 /s/ 의 구강내압은 **올라가서 고원을 유지하다 내려온다**. 그 고원 길이가
곧 마찰음 길이다.

**측정된 값**:
- **유량 정점**: 0.08~0.12 L/s (= 80~120 cm³/s)
- **기식 지속(TASP)**: /s/ 30~50 ms. 어중 /s/ 에서 유의하게 짧아진다(어두 /s/ 대비).
- **성문 개대 개시(TGOO)**: 유량 정점보다 **80~120 ms 앞선다**
- **성문 개대 정점(GOP)**: /s/ 가 /s'/ 보다 **크다**(더 벌어진다)
- **Pio 고원 길이**: /s/ 가 /s'/ 보다 **유의하게 길다**
- **기류 저항 R = Pio/U**: /s'/ 가 /s/ 보다 유의하게 높다
- **Pio 정점, F0**: 두 마찰음 간 유의차 **없음**

**음운 자질 결론**: /s/ 와 /s'/ 둘 다 [−spread glottis]. 차이는 [±tense] 다
(/s/ 는 [−tense], /s'/ 는 [+tense]). 성문 개대 정점과 유량 정점에 유의차가
없다는 게 근거다.

**3 항 대립 (Kim et al. 2018, 파열음)** — ㅈ/ㅊ/ㅉ, ㄱ/ㅋ/ㄲ 작업에 그대로 쓰인다:
- 성문 개대 **위상**(이른 순): 평음(fortis) < 경음(lenis) < 격음(aspirated)
- 성문 개대 **정점 크기**: 같은 순서로 낮음 → 높음
- Pio 정점, Pio 고원 길이, 폐쇄 길이, F0 는 **성문 개대와 독립**이고
  평음 < 격음·경음 순으로 커진다

### 3.3 Koenig & Fuchs (2006) — 구강내압의 시간 미분

> *The time course of intraoral pressure changes during the formation and release
> of consonants and consonant clusters of German.* ISSP 2006.

**방법**: 독일어 화자 8 명 중 2 명(JD, DP) 분석. EPG 구개에 압력 트랜스듀서를
붙여 Pio 를 1859 Hz 로 기록. 단자음 [t], [ʃ] 와 군/파찰 [tʃ], [ts], [ʃt], [st].
Pio 의 **1 차·2 차 미분**으로 상승 개시·최대 속도·정점을 잡았다.

**Pio 정점 크기**: 그림 축이 0~1400 Pa (= 0~14 hPa). §3.1 의 Po 범위와 일치한다.

**어두, 모음에 마찰음이 붙는 경우** (압력 **하강** 기울기·최대속도):

| | [ʃa] | [tʃa] | [tsa] |
|---|---|---|---|
| Slopes (DP/JD) | 9 / 8 | 10 / 10 | **14 / 18** |
| PkVel (DP/JD) | 11 / 10 | 12 / 12 | **17 / 21** |

→ **파찰음 [ts] 의 압력 변화가 마찰음 [ʃ] 보다 훨씬 가파르다.** ㅈ·ㅊ 작업의
직접 근거다.

**어두, 모음에 파열음이 붙는 경우** (압력 상승):

| | [tʰa] | [sta] | [ʃta] |
|---|---|---|---|
| Slopes (DP/JD) | 15 / 18 | 30 / 22 | 32 / 27 |
| PkVel (DP/JD) | 18 / 20 | 36 / 26 | 39 / 33 |
| MinFall (Pa) | **324 / 472** | 118 / 119 | 95 / 96 |

**서론이 정리한 문헌 사실** (모형에 바로 쓰인다):
- **조음 속도·변위는 파열음이 마찰음보다 크다** (Gracco & Löfqvist 1994)
- **성문 개대 진폭은 마찰음이 파열음보다 크다** (Löfqvist & Yoshioka 1984)
- **성문 개대 시점은 마찰음이 파열음보다 이르다**
- **전체 길이는 마찰음이 파열음보다 길다** (Hoole et al. 2003)
- **조음 위치가 뒤일수록 압력이 빨리 오른다** — 협착 뒤 공동 부피가 작아서
  (Ohala 1983). → ㄱ(연구개)은 ㄷ(치경)보다 `ORAL_VOLUME` 이 **작아야** 한다.
  지금은 60 cm³ 상수다.

### 3.4 Chang (2013) / Yoon (1999) — **한국어 /s/ 대 /s'/ 의 지각 단서**

> Chang, C. B. (2013). *The production and perception of coronal fricatives in
> Seoul Korean: The case for a fourth laryngeal category.* Korean Linguistics
> 15(1), 7–49. (원문 PDF 는 프록시가 막는다 — 아래는 초록·인용에서 확인한 것)

- 어두 위치에서 두 마찰음은 **무게중심, 마찰 지속, 기식 지속, 뒤따르는 모음
  길이**, 그리고 **모음 개시의 세기 프로파일·스펙트럼 기울기·F1 개시**에서 다르다.
- **모음 문맥에 따라 다르고, /a/ 에서 차이가 가장 크다.** 저모음 환경에서는
  마찰 지속·기식 지속·F1 개시·**세기 상승(intensity buildup)**·성구(voice
  quality) 가 모두 갈린다. 고모음에서는 F1·세기 차이가 사라진다.
- **H1-H2 가 /sʰa/ 에서 /s'a/ 보다 훨씬 높다** — /a/ 에서 그 차이가 가장 크고
  /ɯ/ 보다 2~3 dB 더 크다. 즉 **평음 ㅅ 뒤의 모음 개시는 기식성**이다.

> Yoon, K. (1999). 합성 자극 실험. 마찰음의 **기식 구간을 줄이면 지각이 평음에서
> 경음으로 넘어가고, 그 경계가 약 37 ms** 다. 중·저모음 앞에서는 **기식 구간
> 길이가 두 마찰음의 유일하게 일관된 차이**여서 "그것만으로 1 차 단서가 된다".

**우리 작업에 주는 것**: "사" 가 "싸" 로 안 들리려면 기식 구간이 충분해야 하고,
모음 개시가 **기식성**(H1-H2 높음)이어야 하며 세기가 **서서히** 올라야 한다.
실측 이 화자: 모음 개시 H1-H2 +11.8/+12.6 dB, 세기 10→90 % 상승 87/81 ms.

> **측정 주의**: "기식 구간"(마찰음 종료 → 발성 개시)은 포락선 임계값으로는
> 못 잰다. 이 화자의 모음은 고역 에너지가 살아 있어서 "고역이 10 % 아래로
> 내려가는 점" 이 안 잡히고, 같은 함수로 실측을 재면 58 ms / −424 ms 처럼
> 발산한다. 논문의 37 ms 는 사람이 스펙트로그램에서 손으로 자른 값이다.
> 대신 **H1-H2 와 세기 상승**을 쓰라 — 둘 다 안정적으로 재진다.

### 3.5 마찰음/파찰음 지각 (검색으로 확인, 원문 미확보)

- 파찰음/마찰음 구분의 **1 차 단서는 마찰 지속시간**, 2 차가 **상승 기울기**이고,
  기울기의 영향은 지속 **150 ms 부근에서 최대**다.
- 파찰음은 마찰음보다 **지속도 짧고 상승시간도 짧다**.
- 치경 마찰음의 포락선은 *"gradually rising or arching"* 이다 — **고원이 아니다**.
- /s/–/ʃ/ 판별은 **개시가 아니라 수십 ms 들어간 지점에서 최대**가 된다
  (그래서 개시의 무게중심이 좀 낮은 건 정상이다. 다만 /ʃ/ 영역까지 내려가면 안 된다).

## 5. 이번 세션에 고친 것

### 5.1 마찰음 구동을 뒤집었다 — 혀 제스처가 포락선을 만든다 ★

`aeroacoustic.tongue_constriction` + 세그먼트 옵션 `drive="tongue"`.
그 모드에서 폐압은 **일정**하고 포락선은 전부 협착에서 나온다.

수학: Ps 가 일정하면 `v = sqrt(2Ps/ρ)/sqrt(Ac²/Ag²+1)` 로 Ac 의 단조감소 함수라
포락선 정점이 **협착 최소와 정확히 일치**한다. 로그 면적에서 일정 속도로 닫고
열면 `가청 정점 위치 = 폐쇄/(폐쇄+해제)` 가 **정확히** 성립한다.

| 긴 /s/ (44.1 kHz) | 가청 | 정점 | 상승/하강 | 평탄(−3dB) | 봉우리 |
|---|---|---|---|---|---|
| 기존 (호흡, 협착 고정) | 1091 ms | 56 % | 1.29 | 30 % | 10121 Hz |
| **혀 제스처** | **1103 ms** | **55 %** | **1.21** | **21 %** | **9991 Hz** |
| 실측 | 1097 ms | 56.1 % | 1.28 | — | 9905~9991 |

포락선 통계는 둘 다 맞지만 혀 제스처가 **공기역학까지** 맞고(Po/Ps 0.77~0.85,
유량 U 자 447→222→447) **덜 평평하다**. 부수 효과로 m04 토큰 간 레벨이 저절로
맞았다(모음이 긴 /s/ 보다 +11.0 dB, 실측 +11~13).

### 5.2 /s/ 가 /ʃ/ 로 시작하던 문제 — 소스/필터 분리

`_scale_sib_center` 가 입자속도 배율을 `teeth_f` 에까지 곱하고 있었다.
Stevens(1971) 는 난류 **소스** 얘긴데 성도 **공진**에 건 것이다.

| | 개시 봉우리 | 2~4 kHz(/ʃ/) | 8~12 kHz(/s/) |
|---|---|---|---|
| 이전 | 2812 Hz | 36.1 % | 8.5 % |
| **현재** | **10125 Hz** | **0.3 %** | **78.8 %** |

셋으로 나눴다: `teeth_f`(순수 기하) = 안 곱함 / `pole_f`,`zero_f` =
`area_centroid_scale`(면적) / `tilt` = `source_tilt_shift`(속도).

### 5.3 기식이 마찰음 위에 치경 F2 를 얹던 문제

"사" 마찰음 정점의 1~2 kHz 가 에너지의 36 % 였다(독립 마찰음은 0.01 %).
빠져 있던 물리 둘 다 순수 기하:
- `glottal_drop_fraction` = `Ac²/(Ac²+Ag²)` — 직렬 저항 배분
- `constriction_transmission` = `(Lc+Lf)·Ac/(Lc·A0+Lf·Ac)` — 협착 통과 전달

결과: 1~2 kHz 36 % → 0.1 % 미만, 8~12 kHz 38 % → 80 %.

### 5.4 "침묵" 이 침묵이 아니었다

`silence` 세그먼트가 `aspiration_bands` 를 안 껐다. m02 토큰 사이 **−3 dB**,
m04 **−19~−21 dB** 의 기식 잡음. 이제 −70/−77 dB.

### 5.5 그 밖

- `BREATH_NOISE_GAIN` 3.6 → 2.7 재적합 (모음 4~6 kHz 3.7 % → 2.1 %)
- 44.1 kHz 렌더 (§6.2)
- /z/ 에 `breath_sustain` — 마찰음이 65 % 에서 죽던 것을 96 % 까지
- `oral_cavity_reactive` 추가 (리액턴스 검증용, 기본 경로엔 안 물림 — §6.5)

## 6. 미해결 (우선순위 순)

### 6.1 ★★ 세그먼트 경계 클릭 = 사용자가 듣는 "ksa" 의 /k/ (최우선)

마찰음 포락선 자체는 이제 제대로 페이드한다(44 ms 0.06 -> 87 ms 0.76 ->
113 ms 0.10). 그런데 **경계에서 1 ms 짜리 트랜지언트**가 난다.

| | 경계 직후 1 ms 최대진폭 |
|---|---|
| 실측 녹음 개시 | 0.0054 |
| 합성 (고치기 전) | 0.648 |
| noise_entry 점프 제거만 | 0.544 |
| sib.mix 램프만 | 0.538 |
| **둘 다 (현재)** | **0.469** |

원인 셋 이상. 확인된 둘은 고쳤다.
1. `noise_entry` 가 무음(0) -> /s/(K+6=18) 로 한 프레임에 뛴다. 무음 구간은
   기류가 없어 주입 위치가 무의미하므로 뒤 세그먼트 값으로 **채운다**(보간이
   아니라 점프 제거 — 보간은 §9 대로 하면 안 된다).
2. `sib.mix` 가 0 -> 1 로 한 프레임에 뛴다. mix 는 항등응답과의 크로스페이드라
   (`(1-m)+m·H`) 중간값이 정의되므로 램프해도 된다.

**남은 것**: 0.469 를 만드는 세 번째 원인. 후보는 포먼트 주파수 점프
(879 -> 614 Hz), 치찰음 극/앞니 주파수가 프리셋에서 화자 지문으로 뛰는 것,
LTV 필터의 프레임 간 계수 급변. `formant_freq` 는 이미 `_smooth` 대상인데도
남는 걸 보면 필터 쪽일 가능성이 크다.

파일 **시작**의 클릭은 해결했다: 발화 앞에 무음 세그먼트를 둔다(0.34 -> 0.0002).
생성 스크립트가 `lead` 를 붙인다.

### 6.1b ★ 구강공명 비중이 아직 모자라다

사용자 지시: "구강공명 비중을 무조건 더 높여야 한다".

| | 봉우리 | 2-4k | 4-6k | 6-8k | 8-10k | 10-13k |
|---|---|---|---|---|---|---|
| 실측 사 #1 | 5556 Hz | 11.8 | **44.2** | 28.4 | 7.8 | 6.8 |
| 실측 사 #2 | 4673 Hz | 13.1 | **48.1** | 22.6 | 8.8 | 6.7 |
| 합성 사 (전) | 10207 Hz | 5.0 | 18.8 | 10.9 | 27.7 | 24.2 |
| **합성 사 (현재)** | 10088 Hz | 8.6 | **37.0** | 18.9 | 22.6 | 11.4 |

4~6 kHz 를 18.8 -> 37.0 % 로 두 배 올렸다(실측 44~48). 봉우리는 아직 앞니
공명이 근소하게 이긴다.

무엇을 했나 — **장애물 다이폴을 협착 기하에 묶었다**:
- `obstacle_strength(area)`: 앞니 다이폴 세기 0~1. **속도로 재면 안 된다** —
  성문이 넓어(0.25 cm²) Ac ≪ Ag 인 동안 v 가 압력에만 묶여서, 협착을 두 배로
  넓혀도 속도비가 0.897 밖에 안 움직인다(측정). 실제로 변하는 건 제트의
  기하라서 면적비 `(a_ref/Ac)^exp` 로 잡는다.
- `SibilantParams.teeth_gain`: 앞니 공진의 **세기** 손잡이(전에는 `ones_like`
  고정이라 손잡이가 없었다). 병렬 혼합 `(1-g)+g·H` 라 줄여도 대역이 안 파인다.
- `_dipole_jet_correction`: 8~13 kHz 를 지배하는 건 좁은 앞니 공진기가 아니라
  **소스 쪽 광대역 상승**(+10 dB/oct)이다. 기울기가 지수에 선형이라 `dip^(g-1)`
  로 보정한다. **RMS 정규화 필수** — 안 하면 기울기를 깎는 게 곧 /s/ 를 13 dB
  조용하게 만드는 일이 되고, 그러면 모음이 고역 정점을 가져간다(측정).
- `TONGUE_CV_A_MIN = 0.11`: 짧은 CV 는 목표 자세에 못 간다(undershoot).
  Po/Ps = 0.84 로 논문의 0.85~0.89 안에 남는다.

**다음 단계**: 봉우리를 실측처럼 5 kHz 대로 내리려면 `teeth_gain` 을 더 낮추거나
`OBSTACLE_JET_EXP`(현재 1.0)를 올린다. 레벨이 8 dB 움직이므로
`SYLLABLE_FRICATIVE_CAL_DB` 를 반드시 다시 재라(25.0 -> 17.0 으로 이미 한 번 옮겼다).

### 6.1c 모듈레이션 — **현재로선 문제가 아니다 (측정 완료)**

사용자 지적("치찰음도 모듈레이션이 필요하다")을 재 봤다. 오히려 우리가 더 크다.

| | 변조 깊이 (고역 포락선 std/mean) |
|---|---|
| 실측 사 / 긴 /s/ | 0.179~0.239 / 0.266 |
| 합성 사 / 긴 /s/ | 0.379 / 0.295 |

변조 **스펙트럼**(어느 속도로 흔들리나)도 긴 /s/ 는 맞는다:

| | 2-10Hz | 10-30 | 30-80 | 80-200 | 200-400 |
|---|---|---|---|---|---|
| 실측 긴 /s/ | 9.7 | 7.9 | 20.9 | **39.9** | 21.6 |
| 합성 긴 /s/ | 16.3 | 8.3 | 17.9 | **35.3** | 22.3 |
| 합성 사 | 12.2 | **30.7** | 20.4 | 21.6 | 15.2 |

음절 쪽만 10~30 Hz 가 과하다(30.7 vs 실측 18.7). 짧은 구간이라 제스처 포락선

### 6.1b (완료) 음절 경로를 혀 제스처로 바꿨다

`drive="tongue"` 이 이제 음절에도 적용된다. 최소 면적 순간이 곧 마찰음 정점이자
해제 시작이고, 그 하나가 포먼트 전이·내전·구강내압 방전을 함께 촉발한다.

CV 는 독립 마찰음과 **정점 공식이 다르다**. 해제가 a_rest 가 아니라 모음 면적
까지 열리므로 로그 거리가 한쪽만 길다(L_close 2.48 vs L_open 4.09). 같은
close_frac 을 쓰면 정점이 75 % 로 밀린다. `aeroacoustic.cv_gesture_times` 가
가청 길이·정점 위치에서 폐쇄/해제 시간을 유도한다.

또 `ag_ref` 를 0.12 에 박아 두면 개대를 넓힐 때 내전 램프가 뒤로 압축돼 기식
구간이 안 생겼다 — 이제 그 구간의 실제 최대 성문 면적을 쓴다.

측정 (44.1 kHz, m01_sa):

| | 합성 | 실측 |
|---|---|---|
| 마찰음 길이 | 121.9 ms | 139 / 154 ms |
| 정점 위치 | 62 % | 42 / 57 % |
| 모음 세기 상승 | 81.3 ms | 87.1 / 81.3 ms |
| 모음 개시 H1-H2 | +10.4 dB | +11.8 / +12.6 dB |

### 6.2 ★ 잡음 보정 상수가 샘플레이트에 딸려 온다

`band_shelf` 가 0~나이퀴스트를 n_bands 로 나누기 때문. 24 kHz 는 밴드당 300 Hz,
44.1 kHz 는 551 Hz.

| 상수 | 24 kHz | 44.1 kHz |
|---|---|---|
| `BREATH_NOISE_GAIN` | 2.7 | 7.8 |
| `ASPIRATION_GAIN` | 6.3 | 10.0 |
| `SYLLABLE_FRICATIVE_CAL_DB` | 25.0 | 27.0 |

지금은 `gen_me_sibilant.py` 의 `CAL_44K` 가 44.1 kHz 값을 **실행 시 덮어쓴다**.
`AudioConfig.sample_rate` 기본값은 24000 그대로다 — 44100 으로 바꾸면 테스트
**17 개가 깨진다**(hop 240, 밴드 인덱스, 프레임 크기가 24 kHz 전제).

**제대로 된 해법**: 셸프를 **활성 밴드 수로 정규화**해 샘플레이트 불변으로 만들고,
그 다음 기본값과 테스트를 함께 44.1 kHz 로 옮겨라.

**왜 44.1 kHz 여야 하나**: 이 화자의 앞니 공명이 10015 Hz 인데 24 kHz 는
나이퀴스트가 12 kHz 다 — 봉우리 바로 위 1.2 kHz 에서 벽에 부딪힌다.
봉우리도 위로 밀린다(24 kHz 10266~10289, 44.1 kHz 9905~9948, 실측 9905~9991).

**그리고 치찰음 지문을 원본 44.1 kHz 녹음에서 다시 뽑아야 한다.**
`me.json` 의 `meta.source` 가 "44.1k**→24k**" 다 — 12 kHz 천장에서 적합해서
10 kHz 공명의 위쪽 스커트가 2 kHz 밖에 안 보였고, 대역폭이 넓게 치우쳤다.
`teeth_bw` 를 912.6 → 600 으로 손으로 되돌렸지만 근사다.

### 6.3 음절 레벨 보정 상수가 프로파일마다 15 dB 다르다

마찰음 세기를 **소스 진폭**으로 기준화하는데 유성음 세기에는 성도 캐스케이드
이득이 곱해져 있다. 마찰음은 그 캐스케이드를 우회하므로(`noise_entry=K+6`)
화자마다 어긋난다. 해법: 기준을 **렌더된 모음 세기**로 옮긴다.
> 한 번 시도했다 되돌렸다. 손대려면 §8 측정 도구를 먼저 갖추고 한 번에 끝내라.

### 6.4 무게중심 이동 방향이 반대다

실측 긴 /s/ 는 **7350 → 9008 → 7194 Hz** (양끝이 낮다).

| | 개시 | 정점 | 끝 |
|---|---|---|---|
| 실측 | 7350 | 9008 | 7194 |
| 호흡 구동(협착 고정) | 9765 | 8365 | 9970 |
| **혀 제스처** | **12166** | **8792** | **11989** |

혀 제스처로 이동폭은 커졌는데(1400 → 3374 Hz) **방향이 틀렸다**. 협착이 넓어질 때
앞공동 극이 내려가면서 **고정된 앞니 공명 10 kHz 의 상대 비중이 커져** 무게중심이
오히려 올라간다.

시도했다 실패한 것:
- `sib.mix` 를 협착 조임으로 게이트(제트 없으면 다이폴도 없다) → 방향 안 바뀜
- `SOURCE_TILT_DB_PER_OCT` 1.5 → 7.5 → 개시 무게중심 9543 → 9425 뿐

**남은 용의자**: `dsp/sibilant.py` 의 `floor_db` — 피크 대비 −25.6 dB 의 **평탄한**
병렬 방사 경로가 tilt 로 깎인 고역을 도로 채운다. 소스와 함께 기울어지는 경로로
바꿔야 tilt 가 무게중심에 반영된다.

### 6.5 리액턴스는 페이드 인의 원인이 아니다 (확인 완료, 재시도 금지)

`oral_cavity_reactive` 로 관성(음향 질량)을 제대로 넣어 봤다:
`dU/dt = (ΔP − ½ρU|U|/A²)/M`, `M = ρL/A`, `dPm/dt = (U_g−U_c)/C`.
심플렉틱 적분 + 적응 부분단계(전진 오일러는 해제에서 NaN — 헬름홀츠가 협착
0.10 cm² 227 Hz 에서 모음 3 cm² 1246 Hz 로 **올라간다**).

| | 준정상 | 리액턴스 |
|---|---|---|
| 대칭 압력 아치 정점 (0.6 s) | 49.1 % | 50.0 % |
| 실제 음절 U_g − U_c 최대 | 0 | 유량의 0.03 % |
| Pm/Ps | 0.590 | 0.590 |

**시간 규모가 두 자릿수 다르다**: τ = Lc·Ac/U 로 0.5~20 ms 인데 페이드는
100~900 ms 다. τ = R·C 를 100 ms 로 맞추려면 등가 체적 6,125 cm³(폐 크기),
900 ms 는 55,125 cm³(어떤 폐보다 크다).

함수는 남겨 뒀다(테스트로 준정상 극한 일치를 고정). 기본 경로엔 안 물린다.

> 남은 리액턴스 자리 하나: `constriction_transmission` 이 지금 **주파수 무관**이다.
> 관성을 넣으면 `T(ω) = T(0)/(1+jωM_c/Z_load)` 로 약 557 Hz 위를 깎는 저역통과가
> 된다. 아직 안 해 봤다.

### 6.6 잡음에 구강 공명을 더 싣는 건 현재 실측과 충돌한다

시도 셋 다 실측을 악화시켰다:
1. 기식 대역폭 축소 → F1/F2 돌출 **안 늘고**(10.1/10.0 그대로) F4/F5 만 울려
   모음 4~6 kHz 가 2.1 → 12.8 %
2. `noise_back_leak` 0.25 → 0.55 → `_oral_leak` 이 **덧셈이 아니라 크로스페이드**라
   비중을 올리면 치찰음 봉우리를 내주는 거래가 된다
3. `BREATH_NOISE_HZ` 3500 → 1500 → 속삭임 500~2k 비중 0 → 59 %(효과 있음)이지만
   모음 1~2 kHz 4.1 → 8.4 %(실측 5.0)

**근본 원인**: 기식 스펙트럼 **하나가 둘을 겸한다** — 유성 모음의 기식성 바닥
(하모닉 위에 얹히므로 고역 셸프가 맞다)과 속삭임(광대역이라야 포먼트를 싣는다).
**발성 여부로 소스 스펙트럼을 가르는 게** 구조적 해법이다.

### 6.7 추출기의 tilt 가 재현되지 않는다

`analysis/extract.fit_source_rd_tilt` 가 낸 `tilt=+8.747` 로 합성하면 1~2 kHz 가
36.8 %(실측 4.2 %). 합성기는 tilt 를 **H1 기준** 옥타브당 dB 로 가산하는데
F0=124 Hz 면 1~2 kHz 가 +29 dB 부푼다. 닫힌고리로 −1.0 을 넣었고 경위는
`meta.tilt_refit` 에 있다. **추출기 자체는 아직 안 고쳤다.**

## 7. 다음 음소 계획 (사용자 지정 순서)

**ㅈ·ㅊ → ㄹ·ㅎ·ㄱ·ㄷ → "이"(구개음화)**

**§6.1(음절 혀 제스처)을 먼저 끝내라.** ㅈ·ㅊ·ㄱ·ㄷ 가 전부 "협착 궤적의 다른
시간 상수" 로 나오므로, 그 전에 음소를 늘리면 음소마다 손으로 맞춘 상수가 쌓인다.

- **ㅈ, ㅊ (파찰음)**: `tongue_constriction` 의 시간 상수만 바꾸면 된다 —
  폐쇄 → 급해제 → 짧은 마찰. 근거: 파찰음은 압력 변화 기울기가 마찰음의
  **1.5~2 배**(§3.3: [ts] 14~18 vs [ʃ] 8~9), 지속이 짧고, 지각의 1 차 단서가
  **지속시간**(§3.4). 3 항 대립(ㅈ/ㅊ/ㅉ)은 §3.2 의 [±s.g.]/[±tense] 틀.
- **ㅎ**: 성문 마찰. `PRESETS["h"]` 자리가 있고 `aspiration_bands` 경로(성도 전체
  통과)가 맞는 경로다. §6.6 의 속삭임 문제와 같은 구조.
- **ㄱ, ㄷ (파열음)**: Ac → 0 인 극단이라 같은 방정식이다. **ㄱ 은 `ORAL_VOLUME` 이
  더 작아야 한다** — 조음 위치가 뒤일수록 협착 뒤 공동이 작아 압력이 빨리 오른다
  (§3.3). 파열음은 조음 속도가 마찰음보다 **빠르고** 성문 개대는 **작고 늦다**(§3.3).
- **ㄹ**: 탄설음/설측음. 협착이 아니라 **접촉과 우회 통로**라 성도 형상 쪽 작업이다.
  이 순서에서 가장 이질적이다.
- **"이" 와 구개음화**: /i/ 앞에서 ㅅ→[ɕ], ㅈ→[ʥ], ㅎ→[ç]. **협착 위치**가 앞뒤로
  옮겨가는 것이라 `pole_f`(앞공동 길이)와 `LOCUS` 가 모음과 **함께** 움직여야 한다.
  §6.1 을 끝내면 협착 위치가 이미 1 급 변수가 되므로 그때 붙이는 게 맞다.

## 8. 측정 도구 — **작업 전후로 반드시 돌려라**

귀가 없으므로 이게 유일한 판단 근거다. `/tmp` 스크립트로 만들어 쓴다.

```python
win, hop = 1024, 256
f = torch.linspace(0, fs/2, win//2+1)
S = torch.stft(x, win, hop, window=torch.hann_window(win), return_complex=True).abs()
hi = (S[f > 4000]**2).sum(0).sqrt(); hi /= hi.max()      # 마찰음 포락선
lo = (S[(f > 200) & (f < 1000)]**2).sum(0).sqrt(); lo /= lo.max()   # 유성
pk = hi.argmax(); on = (hi > 0.1).float().argmax()
# 음절이면 off = lo 가 0.5 를 넘는 첫 프레임, 아니면 마지막 0.1 교차점
frac = (pk - on) / (off - on)                    # 정점 위치. 목표 0.52~0.63
ratio = (pk - on) / (off - pk)                   # 상승/하강. 목표 1.09~1.67
flat3 = mean(hi[on:off+1] > 10**(-3/20)) * 100   # 평탄도. 아치면 ~21%, 고원이면 30%+
```

**`flat3` 을 반드시 같이 봐라.** 정점 위치와 상승/하강비만 보면 고원형과 아치형이
구분되지 않는다 — 그게 이번 세션에 발견한 3 개월짜리 오류의 원인이다(§0).

- **치찰음 봉우리**: 정점 **한 프레임**의 1.5~12 kHz 최댓값. 목표 9905~9991 Hz.
  **프레임을 평균하지 마라** — 음절에서 옆 프레임이 이미 모음이라 1.6 kHz 로 잡힌다.
- **모음−마찰음 세기**: `L(0.30,0.57) − L(0.03,0.11)` (m01 기준). 목표 +11~13 dB.
- **전이가 비지 않는지**: `hi[정점:유성개시].min()`. 목표 ≥ 0.13.
- **스펙트럼 평탄도**(1~11 kHz, 기하평균/산술평균): 사람 /s/ 는 0.2~0.4.
  우리는 0.49~0.51 — 아직 퍼져 있다.
- **공기역학 직접 보기**:
  ```python
  d = aero_drive(seg, t, frame_rate)
  d["env"]      # 마찰음 포락선
  d["cent"]     # 면적에서 나온 공진 배율
  d["src_tilt"] # 속도에서 나온 소스 기울기
  d["pm_frac"]  # Po/Ps — 목표 0.85
  ```

## 9. 지뢰밭 — 겪은 것들

- **Stevens 의 속도-무게중심을 성도 공진에 걸지 마라.** 소스 스펙트럼 얘기다.
  걸면 /s/ 가 /ʃ/ 로 시작한다. 기하는 `area_centroid_scale`, 소스는 `source_tilt_shift`.
- **`aspiration_source_amp` 를 제 최대값으로 정규화하면 직렬 배분이 지워진다.**
  그러면 /s/ 구간에서 치경 F2 가 마찰음 위에 얹힌다.
- **전이 기식을 제어신호 비율로 검사하지 마라.** `aspiration_bands` 의 구간 최대는
  **모음의 기식성 바닥**이라 전이 기식만 줄어도 비율이 떨어진다. **소리를 직접 재라.**
- **`transition_s` 하나가 세 조음기관을 끌고 있었다.** 지금은 혀끝 `release_s`,
  후두 `adduction_s`, 혀몸 `transition_s` 로 분리돼 있다. **다시 합치지 마라.**
- **포먼트 전이를 발성 개시에 묶지 마라.** 후두 타이밍을 건드릴 때마다 포먼트가
  딸려 와 "사" 가 "야" 로 들린다. 지금은 **협착 해제 시점** 기준이다.
- **내전을 마찰음 중간에 시작하면 /s/ 가 죽는다.** 성문이 좁아지면 직렬 저항의
  무게중심이 성문으로 옮겨가 협착 뒤 압력이 무너진다(마찰음 0.79 → 0.18).
- **기식을 `(1-v_frac)` 로 끄면 성문파열음이 된다.** 발성은 난류를 없애지 않는다.
- **정적 성문 면적은 주기적 완전폐쇄를 표현 못 한다.** 성문 제트속도는
  `v=sqrt(2Ps/ρ)` 로 압력만이 정해서, 0.004 cm² 까지 조여도 기식이 안 준다.
- **레벨/질감 통계는 고원부에서 재라.** 전체 RMS 는 페이드 모양이 섞인다.
- **테스트 임계값을 낮춰서 통과시키지 마라.** 낮춘 적이 두 번 있는데 둘 다
  "무엇을 재는지" 가 바뀌었기 때문이고 그 이유를 테스트 안에 적어 뒀다.
  이유를 못 적겠으면 그건 회귀다.
- **`test_voice.py` 의 `PROF` 는 기본 프로파일이다.** 화자 프로파일로 재야 하는
  검사는 `_me_profile()` 을 쓴다.
- **PDF 는 `pdftotext -layout` 로 읽어라.** 프록시가 출판사 도메인을 막으므로
  논문은 사용자에게 받아야 한다. `apt-get update && apt-get install -y poppler-utils`.
- **`pip install torch` 는 PyPI 로 해라.** `download.pytorch.org` 는 프록시가 막는다.
