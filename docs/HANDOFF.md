## 0. 이 작업의 원칙 (가장 중요)

**우리는 귀가 없다.** 사용자가 "이상하다" 고 하면 추측해서 손잡이를 돌리는 게
아니라, **재고 숫자를 비교**한 다음 그 차이를 물리로 설명하고 고친다. 지금까지
진짜 원인은 **한 번도** 처음 짐작한 곳에 있지 않았다.

**파라미터가 아니라 구조를 고친다.** 곡선을 손으로 그려 맞추면 다음 요청에서
반드시 무너진다.

**측정이 underdetermined 인지 늘 의심하라.** 이번 세션의 가장 큰 실수가 그것이다.
호흡 구동 상수를 "정점 위치 57 %, 상승/하강비 1.3" 에 맞춰 적합했는데, **그 두
숫자는 평탄한 고원형과 아치형을 구분하지 못한다.** 그래서 3 개월간 틀린 구조가
"실측과 맞는다" 는 상태로 남아 있었다. 지표를 하나 더 찾아라(여기서는 정점 -3 dB
이내 비율).

## 2. 물리 구조 (무엇이 무엇을 만드는가)

```
폐압 Ps (거의 일정!) ──┐
                       │   ┌── 성문 Ag ──┐
                       └──>│   직렬 유량 U │──> 구강 협착 Ac ──> 입술
                           └── (기식)   ──┘      (마찰음)
                                  │                │
                                  │          Po 구강내압 (혀가 만든다)
                                  │                │
                            (Ps − Po) ──> 발성 역치 ──> 유성
```

**핵심 인과 사슬** — 이걸 깨뜨리면 소리가 무너진다.

1. **마찰음 포락선은 혀가 만든다. 호흡압이 아니다.** (§3.1, §5.1) Ps 는 마찰음
   내내 거의 일정하고, 변하는 건 협착이 만드는 Po 다.
2. **정점 위치 = 폐쇄시간/(폐쇄시간+해제시간).** Ps 가 일정하면 협착부 속도가
   Ac 의 단조감소 함수라 포락선 정점이 협착 최소와 **정확히** 일치한다.
   실측 상승/하강비 1.3 은 곧 "혀가 닫을 때가 열 때보다 1.3 배 느리다" 는 뜻이다.
3. **구강내압이 발성 개시를 정한다.** /s/ 동안 Po 가 Ps 의 85 % 를 먹어
   (Ps−Po) 가 역치에 못 미친다. 협착이 열려 Po 가 빠져야 떨기 시작한다.
   VOT 를 손으로 박지 않는다.
4. **마찰음을 끝내는 건 혀다. 후두가 아니다.** /s/ 는 성문을 벌린 채 낸다.
5. **마찰음과 목소리를 잇는 건 기식이다.** 마찰음 꼬리가 아니다.
6. **앞니 공명은 순수 기하다.** 기류 속도로 그 주파수를 옮기면 /s/ 가 /ʃ/ 로
   시작한다(§5.2).

## 3. 논문 요약 — **원본이 없어도 여기서 작업할 수 있게 적었다**

### 3.1 Signorello, Hassid & Demolin (2018) — 가장 중요

> *Toward an aerodynamic model of fricative consonants.*
> J. Acoust. Soc. Am. 143(5), EL386–EL392. doi:10.1121/1.5038123

**방법**: 벨기에 프랑스어 4 명(남 2 여 2). 성문하압 Ps 를 **기관 천자**(윤상연골
아래 바늘)로 **직접** 측정 — 추정이 아니다. 구강내압 Po 는 비강으로 넣은 관을
연구개 뒤 인두에 두고, 구강 유량 Oaf 는 실리콘 마스크로. VCV 무의미어
[f,v,s,z,ʃ,ʒ] × [i,a,u], 5 회 반복. 마찰음의 **개시(Fs) / 중간(Fm) / 종료(Fr)**
세 점에서 측정.

**/s/ 의 값** (hPa; 1 hPa = 1.019 cmH₂O = 1019 dyn/cm²):

| | 맥락 | 개시 Fs | 중간 Fm | 종료 Fr |
|---|---|---|---|---|
| **Ps** (성문하압) | i / a / u | 10.6 / 8.0 / 10.1 | 10.2 / **8.9** / 10.2 | 9.9 / 8.4 / 9.7 |
| **Po** (구강내압) | i / a / u | 4.8 / 2.5 / 4.6 | 8.7 / **7.6** / 9.1 | 6.3 / 5.6 / 6.0 |
| **ΔPs/Po** | i / a / u | 5.8 / 5.5 / 5.5 | 1.5 / **1.3** / 1.2 | 3.6 / 2.8 / 3.7 |
| **Oaf** (dm³/s) | i / a / u | 0.3 / 0.5 / 0.4 | 0.3 / **0.3** / 0.3 | 0.3 / 0.5 / 0.5 |
| **Int** (dB) | i / a / u | 59 / 61 / 61 | 59 / 57 / 57 | 54 / 58 / 61 |

**Po/Ps (중간점)**: [isi] 0.85, [asa] 0.85, [usu] 0.89.

**결정적 문장** (본문 4.2):
> *"Audible voiceless frication was sustained by a substantial decrease in ΔPs/Po
> and an increased Po which resulted from **constant high Ps** and a substantial
> increase in Po."*

전체 통계: 개시에서 Ps 평균 10.06 hPa (범위 4.37~16.93), Po 평균 3.31 hPa
(범위 0.41~8.74), Oaf 범위 0.06~1.05 dm³/s (n=336).

**읽어야 할 것 세 가지**:
1. **Ps 는 마찰음 내내 거의 일정하다** (8.0 → 8.9 → 8.4). 아치가 아니다.
2. **Po 는 낮게 시작해 크게 올랐다가 내려온다** (2.5 → 7.6 → 5.6).
3. **유량은 U 자다** — 양끝이 높고 가운데가 낮다 (0.5 → 0.3 → 0.5).
   개시는 협착이 아직 없어서, 종료는 **쌓인 Po 가 열린 협착으로 방전**돼서다
   (파열음 버스트와 같은 원리).

또: 무성 마찰음은 성문 개대가 크고 **선행 모음에서 이미 시작**된다. 그래야
후두 저항이 낮아져 Po 가 쌓인다.

### 3.2 Kim, Hwang, Ahn, Honda, Maeda (2022) — 한국어

> *External photoglottography, intra-oral air pressure, airflow and acoustic data
> on the Korean fricatives /s', s/.* Phonetics and Speech Sciences 14(3), 11–25.

**방법**: 서울 한국어 4 명(남 2 여 2). ePGG(외부 광성문촬영) + Pio + 유량 + 음향
**동시** 녹음. 문맥 /_a_a/, /_ama/, /ma_a/ (예: /sasa/, /sama/, /masa/).

**결정적 문장**:
> *"the duration of a **high Pio plateau**, which is **the aerodynamic counterpart
> of the acoustic frication duration** during oral constriction of a fricative"*

즉 한국어 /s/ 의 구강내압은 **올라가서 고원을 유지하다 내려온다**. 그 고원 길이가
곧 마찰음 길이다.

**측정된 값**:
- **유량 정점**: 0.08~0.12 L/s (= 80~120 cm³/s)
- **기식 지속(TASP)**: /s/ 30~50 ms. 어중 /s/ 에서 유의하게 짧아진다(어두 /s/ 대비).
- **성문 개대 개시(TGOO)**: 유량 정점보다 **80~120 ms 앞선다**
- **성문 개대 정점(GOP)**: /s/ 가 /s'/ 보다 **크다**(더 벌어진다)
- **Pio 고원 길이**: /s/ 가 /s'/ 보다 **유의하게 길다**
- **기류 저항 R = Pio/U**: /s'/ 가 /s/ 보다 유의하게 높다
- **Pio 정점, F0**: 두 마찰음 간 유의차 **없음**

**음운 자질 결론**: /s/ 와 /s'/ 둘 다 [−spread glottis]. 차이는 [±tense] 다
(/s/ 는 [−tense], /s'/ 는 [+tense]). 성문 개대 정점과 유량 정점에 유의차가
없다는 게 근거다.

**3 항 대립 (Kim et al. 2018, 파열음)** — ㅈ/ㅊ/ㅉ, ㄱ/ㅋ/ㄲ 작업에 그대로 쓰인다:
- 성문 개대 **위상**(이른 순): 평음(fortis) < 경음(lenis) < 격음(aspirated)
- 성문 개대 **정점 크기**: 같은 순서로 낮음 → 높음
- Pio 정점, Pio 고원 길이, 폐쇄 길이, F0 는 **성문 개대와 독립**이고
  평음 < 격음·경음 순으로 커진다

### 3.3 Koenig & Fuchs (2006) — 구강내압의 시간 미분

> *The time course of intraoral pressure changes during the formation and release
> of consonants and consonant clusters of German.* ISSP 2006.

**방법**: 독일어 화자 8 명 중 2 명(JD, DP) 분석. EPG 구개에 압력 트랜스듀서를
붙여 Pio 를 1859 Hz 로 기록. 단자음 [t], [ʃ] 와 군/파찰 [tʃ], [ts], [ʃt], [st].
Pio 의 **1 차·2 차 미분**으로 상승 개시·최대 속도·정점을 잡았다.

**Pio 정점 크기**: 그림 축이 0~1400 Pa (= 0~14 hPa). §3.1 의 Po 범위와 일치한다.

**어두, 모음에 마찰음이 붙는 경우** (압력 **하강** 기울기·최대속도):

| | [ʃa] | [tʃa] | [tsa] |
|---|---|---|---|
| Slopes (DP/JD) | 9 / 8 | 10 / 10 | **14 / 18** |
| PkVel (DP/JD) | 11 / 10 | 12 / 12 | **17 / 21** |

→ **파찰음 [ts] 의 압력 변화가 마찰음 [ʃ] 보다 훨씬 가파르다.** ㅈ·ㅊ 작업의
직접 근거다.

**어두, 모음에 파열음이 붙는 경우** (압력 상승):

| | [tʰa] | [sta] | [ʃta] |
|---|---|---|---|
| Slopes (DP/JD) | 15 / 18 | 30 / 22 | 32 / 27 |
| PkVel (DP/JD) | 18 / 20 | 36 / 26 | 39 / 33 |
| MinFall (Pa) | **324 / 472** | 118 / 119 | 95 / 96 |

**서론이 정리한 문헌 사실** (모형에 바로 쓰인다):
- **조음 속도·변위는 파열음이 마찰음보다 크다** (Gracco & Löfqvist 1994)
- **성문 개대 진폭은 마찰음이 파열음보다 크다** (Löfqvist & Yoshioka 1984)
- **성문 개대 시점은 마찰음이 파열음보다 이르다**
- **전체 길이는 마찰음이 파열음보다 길다** (Hoole et al. 2003)
- **조음 위치가 뒤일수록 압력이 빨리 오른다** — 협착 뒤 공동 부피가 작아서
  (Ohala 1983). → ㄱ(연구개)은 ㄷ(치경)보다 `ORAL_VOLUME` 이 **작아야** 한다.
  지금은 60 cm³ 상수다.

### 3.4 Chang (2013) / Yoon (1999) — **한국어 /s/ 대 /s'/ 의 지각 단서**

> Chang, C. B. (2013). *The production and perception of coronal fricatives in
> Seoul Korean: The case for a fourth laryngeal category.* Korean Linguistics
> 15(1), 7–49. (원문 PDF 는 프록시가 막는다 — 아래는 초록·인용에서 확인한 것)

- 어두 위치에서 두 마찰음은 **무게중심, 마찰 지속, 기식 지속, 뒤따르는 모음
  길이**, 그리고 **모음 개시의 세기 프로파일·스펙트럼 기울기·F1 개시**에서 다르다.
- **모음 문맥에 따라 다르고, /a/ 에서 차이가 가장 크다.** 저모음 환경에서는
  마찰 지속·기식 지속·F1 개시·**세기 상승(intensity buildup)**·성구(voice
  quality) 가 모두 갈린다. 고모음에서는 F1·세기 차이가 사라진다.
- **H1-H2 가 /sʰa/ 에서 /s'a/ 보다 훨씬 높다** — /a/ 에서 그 차이가 가장 크고
  /ɯ/ 보다 2~3 dB 더 크다. 즉 **평음 ㅅ 뒤의 모음 개시는 기식성**이다.

> Yoon, K. (1999). 합성 자극 실험. 마찰음의 **기식 구간을 줄이면 지각이 평음에서
> 경음으로 넘어가고, 그 경계가 약 37 ms** 다. 중·저모음 앞에서는 **기식 구간
> 길이가 두 마찰음의 유일하게 일관된 차이**여서 "그것만으로 1 차 단서가 된다".

**우리 작업에 주는 것**: "사" 가 "싸" 로 안 들리려면 기식 구간이 충분해야 하고,
모음 개시가 **기식성**(H1-H2 높음)이어야 하며 세기가 **서서히** 올라야 한다.
실측 이 화자: 모음 개시 H1-H2 +11.8/+12.6 dB, 세기 10→90 % 상승 87/81 ms.

> **측정 주의**: "기식 구간"(마찰음 종료 → 발성 개시)은 포락선 임계값으로는
> 못 잰다. 이 화자의 모음은 고역 에너지가 살아 있어서 "고역이 10 % 아래로
> 내려가는 점" 이 안 잡히고, 같은 함수로 실측을 재면 58 ms / −424 ms 처럼
> 발산한다. 논문의 37 ms 는 사람이 스펙트로그램에서 손으로 자른 값이다.
> 대신 **H1-H2 와 세기 상승**을 쓰라 — 둘 다 안정적으로 재진다.

### 3.5 마찰음/파찰음 지각 (검색으로 확인, 원문 미확보)

- 파찰음/마찰음 구분의 **1 차 단서는 마찰 지속시간**, 2 차가 **상승 기울기**이고,
  기울기의 영향은 지속 **150 ms 부근에서 최대**다.
- 파찰음은 마찰음보다 **지속도 짧고 상승시간도 짧다**.
- 치경 마찰음의 포락선은 *"gradually rising or arching"* 이다 — **고원이 아니다**.
- /s/–/ʃ/ 판별은 **개시가 아니라 수십 ms 들어간 지점에서 최대**가 된다
  (그래서 개시의 무게중심이 좀 낮은 건 정상이다. 다만 /ʃ/ 영역까지 내려가면 안 된다).

## 5. 이번 세션에 고친 것

### 5.1 마찰음 구동을 뒤집었다 — 혀 제스처가 포락선을 만든다 ★

`aeroacoustic.tongue_constriction` + 세그먼트 옵션 `drive="tongue"`.
그 모드에서 폐압은 **일정**하고 포락선은 전부 협착에서 나온다.

수학: Ps 가 일정하면 `v = sqrt(2Ps/ρ)/sqrt(Ac²/Ag²+1)` 로 Ac 의 단조감소 함수라
포락선 정점이 **협착 최소와 정확히 일치**한다. 로그 면적에서 일정 속도로 닫고
열면 `가청 정점 위치 = 폐쇄/(폐쇄+해제)` 가 **정확히** 성립한다.

| 긴 /s/ (44.1 kHz) | 가청 | 정점 | 상승/하강 | 평탄(−3dB) | 봉우리 |
|---|---|---|---|---|---|
| 기존 (호흡, 협착 고정) | 1091 ms | 56 % | 1.29 | 30 % | 10121 Hz |
| **혀 제스처** | **1103 ms** | **55 %** | **1.21** | **21 %** | **9991 Hz** |
| 실측 | 1097 ms | 56.1 % | 1.28 | — | 9905~9991 |

포락선 통계는 둘 다 맞지만 혀 제스처가 **공기역학까지** 맞고(Po/Ps 0.77~0.85,
유량 U 자 447→222→447) **덜 평평하다**. 부수 효과로 m04 토큰 간 레벨이 저절로
맞았다(모음이 긴 /s/ 보다 +11.0 dB, 실측 +11~13).

### 5.2 /s/ 가 /ʃ/ 로 시작하던 문제 — 소스/필터 분리

`_scale_sib_center` 가 입자속도 배율을 `teeth_f` 에까지 곱하고 있었다.
Stevens(1971) 는 난류 **소스** 얘긴데 성도 **공진**에 건 것이다.

| | 개시 봉우리 | 2~4 kHz(/ʃ/) | 8~12 kHz(/s/) |
|---|---|---|---|
| 이전 | 2812 Hz | 36.1 % | 8.5 % |
| **현재** | **10125 Hz** | **0.3 %** | **78.8 %** |

셋으로 나눴다: `teeth_f`(순수 기하) = 안 곱함 / `pole_f`,`zero_f` =
`area_centroid_scale`(면적) / `tilt` = `source_tilt_shift`(속도).

### 5.3 기식이 마찰음 위에 치경 F2 를 얹던 문제

"사" 마찰음 정점의 1~2 kHz 가 에너지의 36 % 였다(독립 마찰음은 0.01 %).
빠져 있던 물리 둘 다 순수 기하:
- `glottal_drop_fraction` = `Ac²/(Ac²+Ag²)` — 직렬 저항 배분
- `constriction_transmission` = `(Lc+Lf)·Ac/(Lc·A0+Lf·Ac)` — 협착 통과 전달

결과: 1~2 kHz 36 % → 0.1 % 미만, 8~12 kHz 38 % → 80 %.

### 5.4 "침묵" 이 침묵이 아니었다

`silence` 세그먼트가 `aspiration_bands` 를 안 껐다. m02 토큰 사이 **−3 dB**,
m04 **−19~−21 dB** 의 기식 잡음. 이제 −70/−77 dB.

### 5.5 그 밖

- `BREATH_NOISE_GAIN` 3.6 → 2.7 재적합 (모음 4~6 kHz 3.7 % → 2.1 %)
- 44.1 kHz 렌더 (§6.2)
- /z/ 에 `breath_sustain` — 마찰음이 65 % 에서 죽던 것을 96 % 까지
- `oral_cavity_reactive` 추가 (리액턴스 검증용, 기본 경로엔 안 물림 — §6.5)

### 5.6 (2026-09-04) 두 가지 지적 — "사각파" 와 "치찰음 중반부 파열음"

사용자 지적: (1) 음원이 너무 사각파에 가깝다, (2) 치찰음 중반부에 파열음 같은
소리가 난다. **둘 다 스펙트로그램을 그려서 원인을 찾았다** — 요약 수치로는
세 턴 동안 못 찾았던 것들이다(§0, §6.0 의 교훈).

스펙트로그램에서 합성 /s/ 는 **수직 모서리를 가진 직사각형 블록**이었다:
145 ms 에 갑자기 켜지고, 5~22 kHz 가 120 ms 동안 고르게 밝고, 268 ms 에 수직
으로 끊긴다. 실측은 같은 자리가 부드러운 혹이고 꼬리가 모음과 겹친다.
그 수직 모서리가 곧 임펄스이고, 그게 "파열음" 이다.

#### 5.6a 후두 제스처가 계단이었다 → 매끄러운 열고-닫기

`glottal_area` 를 꺾은점 5 개(개대 0.25 로 고정 → 해제 시점에 급강하)로 그리고
있었다. 꺾은점이 곧 유량의 꺾은점이다. Löfqvist & Yoshioka 의 성문도(Pgg)는
무성 마찰음에서 **단일한 종 모양**이고 정점이 마찰음 중간 근처다.
`aeroacoustic.devoicing_gesture` 로 바꿨다 — 최소 저크, **선형 면적**(성문은
피열연골 변위에 비례하고 Pgg 자체가 면적 신호다. 혀끝 협착이 로그 면적인 것과
다르다). 두 단계 내전(0.03 → 0.004)은 종 모양이 내려오면서 저절로 지나간다.

`aeroacoustic.min_jerk` 도 같이 넣어 혀 제스처의 조각별 선형 램프를 바꿨다.
변위가 조각별 선형이면 꺾은점에서 가속도가 무한대다.

#### 5.6b 폐압 램프를 되살렸다 (발화 개시)

혀 제스처로 옮기면서 폐압을 **완전히 일정**하게 두었는데(Signorello),
그건 이미 말이 진행 중인 구간의 관찰이지 **발화 개시**가 아니다. 게다가
Ps 일정 + Ac ≪ Ag 면 진폭이 Ps/(1+Ac²/Ag²) 로 **포화**하므로, 협착이 다
만들어진 뒤의 포락선은 아무것도 아닌 평평한 고원이 된다. 측정: 60 ms 동안
−40.45 dB 가 여섯 프레임 연속 **완전히 동일**했다.

`UTTERANCE_PS_RISE_S = 0.15` (Draper/Ladefoged/Whitteridge 1959; Hixon)
로 두고, 예전의 "램프를 폐쇄 완료에 맞춰 뒤로 민다" 를 **없앴다**. 압력과
협착이 나란히 오른다. 그동안 성문은 아직 거의 닫혀 있어(5.6a) 앞쪽에 /h/ 가
안 생긴다. 결과: 고역 10→90 % 상승 18 → 48 ms (실측 47~76).

#### 5.6c 해제 시간을 조음기 속도에서 낸다 ★

`cv_gesture_times` 는 "포락선 정점 = 최소 면적 순간" 을 전제로 정점 위치에서
해제 시간을 거꾸로 풀었다. 5.6b 로 그 전제가 깨졌다(정점은 압력이 정한다).
그 풀이가 내놓은 값은 **혀끝이 폐쇄보다 2.6 배 빨리 움직이는** 속도였고
(80.0 vs 31.1 nepers/s), 그래서 해제 구간에서 진폭이 **10 ms 에 26 dB**
떨어졌다(실측 45 ms 에 15 dB). 그게 스펙트로그램의 수직 모서리다.

`aeroacoustic.release_from_speed` 로 바꿨다: 같은 혀끝이 한 속도로 움직이고
(해제가 `TONGUE_RELEASE_SPEEDUP=1.4` 배 빠르다), 정점 위치는 압력·면적이
알아서 정하게 둔다. 요구값이 하나 줄었다.

#### 5.6d 모음이 6 kHz 위로 죽어 있었다 — 포먼트 추출기의 구멍

프로파일 포먼트가 5420 → 8129 Hz 로 뛴다. 균일관은 c/(2L)=1 kHz 마다 극이
하나이므로 그 사이에 극이 둘 있어야 한다. 캐스케이드에서 그 구멍은 조용한
게 아니라 **절벽**이다 — 아래 극 여섯이 각각 −12 dB/oct 로 떨어지는데 막아
줄 극이 없다. `voice.fill_pole_gaps` 로 메운다.

**주의: 저역에는 걸면 안 된다.** /아/ 의 F2–F3 는 1292 → 2604 Hz 로 실제로
벌어져 있다. 거기 극을 끼웠더니 2.5~4 kHz 가 실측 대비 +18 → **+34 dB** 가
됐다. 그래서 `POLE_FILL_ABOVE_HZ = 5000`.

**극 개수의 상한도 있다.** 캐스케이드가 DC 정규화(Klatt)라 나이퀴스트 근처의
극은 이득이 1 을 크게 넘는다. 44.1 kHz 에서 극을 22 개까지 늘렸더니 모음
50~300 Hz 가 **−87.5 dB** 로 붕괴했다(15 개면 정상). `gen_me_sibilant.py` 는
`len(prof.formants) + 2` 로 잡는다.

#### 5.6e 하모닉 사이가 비어 있었다 = "사각파"

`aspiration_bands` 셸프의 `floor` 가 **0** 이었다. 성문 난류는 광대역인데
3.5 kHz 아래에서 소스가 아예 침묵했던 셈이다. 결과: 합성 모음의 하모닉 사이
바닥이 −58.6 dB(실측 −38.1) — 거의 선 스펙트럼이다. 그게 사각파로 들린다.

`BREATH_NOISE_FLOOR = 0.30`, 셸프 모서리 3500 → 4800 Hz(3.5 kHz 모서리가
실측이 골짜기인 F3–F4 사이 2.5~4 kHz 를 메워 +18 dB 였다), 44.1 kHz 게인
7.8 → 16.0. `NOISE_BACK_LEAK` 0.25 → 0.70 으로 /s/ 의 저역 치마도 살렸다
(80 Hz 실측 대비 −8.2 dB → −1.4 dB).

결과는 §1b 표다 — 9 kHz 위를 빼면 전 대역 2 dB 이내.

#### 5.6f 발성 기동이 20 주기였다 (버그 두 개)

`ONSET_CYCLES` 를 "e 배로 자라는 데 걸리는 주기 수" 로 해석하고 있었다.
씨앗이 2 % 라 95 % 까지 6.83 배의 e 배 시간이 필요해서, `cycles=3` 이 실제로는
**20 주기(150 ms)** 였다. 측정: 구동압과 내전이 210 ms 에 이미 1.0 인데
harmonic_amp 는 430 ms 까지 자랐다 — 목소리가 켜지는 게 아니라 부풀어 오른다.
`cycles` 를 **총 주기 수**로 다시 정의하고(σ 를 씨앗과 함께 푼다) 6.0 으로
뒀다(모음 저역 10→90 % 47.7 ms, 실측 49.5~50.0).

그리고 `oscillation_buildup` 의 `started` 래치가 **한 번 켜지면 안 풀렸다**.
목표가 0 으로 돌아가도 씨앗이 심긴 것으로 남아, /s/ 앞의 준비 자세에서 목표가
잠깐 살아났다 꺼지면 **뒤따르는 모음이 통째로 무음**이 됐다.

#### 5.6g `score.params` 전역 오버라이드가 무시되고 있었다

`apply_overrides(merged | {...}, ...)` — `|` 는 새 dict 를 만든다. 거기 덮어쓴
값은 `merged` 에 안 남는다. `sib_*` 만 통했다(객체라 제자리 변경).


### 5.7 (2026-09-04, 이어서) "두 개의 파열음" — 둘 다 **전이 기식**이었다

§5.6 을 끝낸 뒤에도 사용자가 스펙트로그램에서 두 곳을 짚었다: /s/ 가
펄스처럼 켜지는 것과, 그 직후 300 ms 부근의 강한 신호.

**경로별로 따로 렌더해서** 범인을 특정했다(이 방법을 기억해라 — 마찰음·기식·
목소리를 각각 0 으로 만들어 네 벌을 렌더하면 어느 경로가 무엇을 만드는지
한눈에 나온다).

| 시각 | 대역 | 전체 | 기식 뺌 | 마찰음 뺌 |
|---|---|---|---|---|
| 125 ms | 0.9~2k | −43.8 | **−154.8** | −43.8 |
| 140 ms | 4~12k | −49.0 | **−149.5** | −49.1 |
| 285 ms | 0.9~2k | −11.7 | **−59.8** | −11.7 |

즉 /s/ **앞**(110~160 ms)도 **뒤**(285 ms)도 통째로 기식이었다. 마찰음은
165 ms 에야 들어온다. /s/ 앞뒤에 /h/ 가 하나씩 붙어 있었던 것이다.

#### 5.7a 전이 기식이 900 Hz 셸프였다 → 기식성 바닥과 통일

같은 성문 제트 난류인데 전이 기식만 900 Hz 셸프를 쓰고 있었고, 그게 성도
캐스케이드를 통째로 지나며 F1/F2 를 때렸다. §5.6 에서 고역 골을 메우려고
ASPIRATION_GAIN 을 6.3 → 26 으로 올린 게 그 셸프를 타고 저역으로 쏟아졌다.
`G.BREATH_NOISE_HZ`(4800, floor 0.30)로 통일하니 같은 게인이 고역만 메운다.
전이 F2 대역 / 모음 정상부: 2.9~3.5 → **0.99** (실측 0.81 / 1.06).

#### 5.7b 성문 개대가 혀보다 **늦게** 시작했다 ★

마찰음 개시의 dB 기울기를 인자별로 분해했다(10 ms 당):

| 시각 | Ac | Ag | Δ전체 | Δ압력 | Δ면적항 | Δ게이트 |
|---|---|---|---|---|---|---|
| 50 ms | 0.336 | 0.029 | +38.2 | +3.6 | **+27.9** | +6.7 |
| 60 ms | 0.199 | 0.061 | +37.3 | +2.8 | **+21.3** | +13.2 |
| 70 ms | 0.137 | 0.103 | +19.1 | +2.3 | +12.5 | +4.4 |

압력이 아니라 **면적항 1/(1+Ac²/Ag²)** 이 만든다. 혀가 좁히는 **동안**
성문이 같이 열려서 Ac/Ag 가 20 ms 만에 11.6 → 1.3 (9 배) 변하고, 제곱해서
19 dB/10 ms 가 된다. Löfqvist & Yoshioka: 무성 마찰음의 성문 개대는 구강
협착이 만들어지기 **전에** 시작한다 — 우리는 `GLOTTIS_ABDUCT_S` 를 100 ms
상수로 두어 정점(고원 중앙)에서 거꾸로 세니 폐쇄 시작보다 25 ms **늦게**
출발했다. 순서가 거꾸로였다. 개대 시간을 "정점까지의 시간" 으로 잡아
**혀의 폐쇄와 같이 출발**시키면 같은 구간이 +6.8 / +3.3 dB 다.

#### 5.7c 발화 개시 폐압 램프가 짧았다

`breath_onset` 은 raised cosine 이라 **0~1 전체 길이**를 받고 10→90 % 는
그 0.58 배다. 0.15 s 로 두면 마찰음이 켜지기 전에 이미 압력이 45 % 라,
성문이 벌어지는 동안 성문 난류가 크게 나서 /s/ 앞에 −33 dB 짜리 30 ms
**고원**이 생긴다. 그 고원 뒤에 마찰음이 따로 올라오니 개시가 2 단이 된다.
0.25 s (= 상승 145 ms, 문헌 100~200 안)로:

| | 선행 기식 | 골 | 차 |
|---|---|---|---|
| 실측 #1 / #2 | −43.7 / −45.8 | −15.6 / −15.4 | 28.1 / 30.4 |
| rise 0.15 | −32.8 | −17.6 | 15.3 |
| **rise 0.25** | **−44.6** | −16.9 | 27.6 |

−30 dB 교차점에 정렬해 겹쳐 그리면 합성 곡선이 실측 두 토큰 위에 거의
포개진다(상승·돔·하강·골·회복 전부).

### 5.8 (2026-09-04, 이어서) 긴 /s/ 가 "사람 소리 같지 않다"

사용자 지적: 마지막 두 치찰음이 사람 소리 같지 않고, 어느 정도 모음이 느껴져야
하는데 그렇지 않고 너무 강하고 둔탁하다. 그리고 **실제 치찰음은 고역이 중간에서
피크고 완만히 떨어지는데 우리 건 처음부터 고역이 확 튀어나온다**.

측정으로 전부 확인됐다. 무게중심 궤적(가청 구간의 5/50/95 %):

    실측 #1   6521 -> 8770 -> 7339 Hz   (아치)
    실측 #2   7867 -> 9201 -> 6651 Hz   (아치)
    합성      12228 -> 8300 -> 12218    (**정확히 반대**)

그리고 스펙트럼 **모양**이:

| 6~11 kHz 기준 | 5 % | 50 % | 95 % |
|---|---|---|---|
| 실측 0.5–2.5 kHz | −10.9 | −15.5 | −12.3 |
| 합성 0.5–2.5 kHz | **+2.9** | **−24.5** | **+1.9** |

실측은 레벨만 변하고 **음색은 거의 고정**인데(2.5~6 kHz 가 12/50/88 % 에서
−1.6/−2.8/−1.2 dB) 합성은 20 dB 넘게 요동친다. 그게 "사람 소리 같지 않다" 다.

#### 5.8a 독립 마찰음 경로에서 다이폴이 제트에 안 묶여 있었다 ★

`_dipole_jet_correction` 이 **음절 경로에만** 걸려 있었다. 그래서 긴 /s/ 는
첫 프레임부터 앞니 다이폴(+10 dB/oct)이 만땅이고, `noise_bands` 의 모양이
전 구간 **완전히 동일**했다(무게중심 15245 Hz 고정). 같은 보정을 마찰음 경로
에도 걸었다. 이것만으로 무게중심이 아치가 된다(5916 → 8780 → 6093).

#### 5.8b 지속 마찰음에서 혀가 쉬지 않고 움직이고 있었다 ★

`tongue_constriction` 은 고원 없는 삼각형이었다. 그러면 앞공동 극
(`area_centroid_scale`)과 앞니 다이폴 세기가 토큰 내내 따라 움직여 음색이
요동친다. 실제 지속 마찰음은 자세를 잡고 **유지**하고, 포락선은 호흡이 만든다.

  * `TONGUE_SUSTAIN_HOLD = 0.62` — 고원을 넣었다.
  * `ps_drive` 를 도입했다. 폐압을 **일정하게** 두는 건 말이 진행 중인 구간의
    관찰이고(Signorello), 독립 지속 마찰음은 토큰 하나가 발화 전체라 폐압이
    올랐다 내려야 한다. 마찰음 경로는 `"breath"`, CV 음절은 `"constant"`.

가설 검증(협착 고정 + 호흡으로 돌려 보니): 모양이 실측처럼 안정된다
(0.5~2.5 kHz −9.9 / −13.5 / −10.0, 실측 −10.9 / −15.5 / −12.3).

#### 5.8c `tilt_response` 의 −40 dB 클램프가 고역에 선반을 만들었다

1 kHz 피벗에서 22 kHz 는 4.46 옥타브다. 기울기가 −9 dB/oct 보다 가파르면
나이퀴스트 전에 클램프에 걸려 **고역이 −40 dB 짜리 평평한 선반**이 된다.
치찰음 기울기는 −5 ~ −12 dB/oct 라 거의 항상 걸렸고, 기울기가 가팔라질수록
선반이 넓어져 **어두워야 할 구간이 오히려 밝아졌다**. 감쇠 쪽만 −90 dB 로 넓혔다
(부스트 쪽은 이득이 폭발하는 방향이라 +40 유지).

#### 5.8d 병렬 바닥(floor_db)이 소스 기울기를 안 받고 있었다

`floor_db` 는 "입 구멍에서 직접 방사되는 광대역 성분" 이다. 같은 난류원의
다른 경로이므로 소스의 색(tilt)을 **같이 받아야** 하는데 평탄하게 더해지고
있었다. 그래서 고역에서 필터를 뚫고 나와 스펙트럼이 −25.6 dB 에서 하강을
멈췄고(18~22 kHz 가 실측 대비 12~23 dB 과다), 제트가 느린 양 끝에서 바닥이
상대적으로 커져 **무게중심이 거꾸로 올라갔다**(8682 → 8387 → 10308).

**기울기를 바닥에만 건다.** 필터 전체에 걸면(= tilt 를 맨 뒤로 옮기면) 긴 /s/ 는
더 좋아지지만 추출기가 적합한 `pole_f` 가 복원되지 않는다(3500 → 1914).
분석/합성 왕복은 지켜야 하는 불변량이라 좁은 쪽을 택했다.

### 5.9 (2026-09-04, 이어서) 위상 조사 — 결론: **정상부에서는 관측 불가능**

사용자 질문: "노이즈가 공명하면 주파수 응답 특성이 있을 텐데, 실측과 우리
음성의 위상차를 조사해봐. 노이즈 자체가 잘 맞물리지 못하는 느낌이다."

**먼저 알아야 할 것: 정상(stationary) 잡음에서 필터의 위상은 출력만으로
관측할 수 없다.** 정상 과정은 시간 이동에 대해 통계가 불변이라, 필터가 신호를
τ 만큼 늦춰도 창을 씌운 조각의 통계가 그대로다. 프레임 평균 군지연 추정기
(τ = Re(X_ramp·conj X)/|X|², |X|² 가중)를 만들어 재 봤더니:

    실측 긴 /s/     1~16 kHz 전 구간 ±0.03 ms
    합성           전 구간 ±0.06 ms
    **검증**: 이론 정점 군지연 1.06 ms 인 공진기(10 kHz, bw 600)에 백색잡음을
             통과시켜도 추정기가 **-0.02 ms** 를 돌려준다 — 도구가 아니라 원리다.

그래서 "정상부의 위상차" 는 재도 나올 게 없다. 관측 가능한 건 **인과성**
(프리에코)이고, 그건 개시·해제·변조 같은 **비정상 구간**에서만 드러난다.

#### 찾은 것: 응답 체인이 혼합위상이었다

`tilt_response` 와 `skirt_response` 가 **순수 실수(영위상)** 를 돌려준다.
영위상 필터의 임펄스응답은 t=0 대칭이라 비인과적이고, `response_to_ir` 이
ir_size//2 만큼 롤한 뒤 `ltv_filter` 가 그 지연을 보정하므로 대칭인 절반이
프리에코로 남는다. 정점보다 앞에 오는 임펄스응답 에너지:

| 성분 | 선행 에너지 | −20 dB 선행 |
|---|---|---|
| 극·영점 (최소위상) | 0.0 % | 0.00 ms |
| 앞니 공진기 (최소위상) | 0.0 % | 0.00 ms |
| **tilt (영위상)** | **46.7 %** | 2.24 ms |
| 치찰음 필터 전체 | 37.2 % | 0.52 ms |
| 노이즈 경로 전체 | 26.0 % | 0.16 ms |

(주의: `skirt` 의 21.3 % 는 지표의 허수다 — 원형 IR 을 롤할 때 **꼬리가
감겨 들어온** 것이지 프리에코가 아니다. 롤 전 원형 IR 의 음의 시간 에너지는
0.00 % 다. 이 지표를 다시 쓸 때 주의하라.)

#### 고쳐 봤지만 되돌렸다 (§6.12)

`min_phase_from_log_mag` 를 만들어 둘 다 최소위상화했다. tilt 46.7 → 2.1 %,
치찰음 필터 37.2 → 4.6 %. 그런데:

* 위상은 **곱셈에서는 크기에 영향이 없지만 병렬 덧셈에서는 있다**
  (치찰음 필터의 `floor_db`, `_oral_leak`, 앞니 병렬 혼합이 전부 덧셈이다).
* 프로파일의 `floor_db` 와 포먼트 추출기가 지금의 혼합위상 모델에 맞춰
  적합돼 있어서, 분석/합성 왕복이 깨진다(pole_f 3500 → **4266**, 임계 15 %).
* 실측 대비 개선은 무시할 수준이었다(무게중심 아치 7862→8549→8010 vs
  7513→8476→7468, 밴드 표는 1 dB 이내).

`min_phase_from_log_mag` 는 헬퍼로 남겨 두고(`bands_to_response` 가 쓴다)
호출부만 되돌렸다. 적용하려면 `floor_db` 재적합과 추출기 수정이 같이 가야 한다.

#### 부수적으로 고친 잠재 버그

`sibilant_response` 의 `teeth_gain` 이 없을 때 `ones_like(teeth_f)` 로 만들어져
있었다. 그건 단 축을 접은 뒤 곱하는 **혼합 가중치**라 (B,T,1) 이어야 하는데,
K=1 일 때만 우연히 맞았고 앞니 공진을 두 개 주면 터졌다. 회귀 테스트 추가.

## 6. 미해결 (우선순위 순)

### 6.0 (해결) 목소리의 페이드 — 진동 기동 모형의 **모양이 반대**였다

`oscillation_buildup` 이 **1 차 지연**이었다. 1 차 지연은 t=0 에서 가장 빠르게
오르는 **오목한** 곡선이다. 그런데 성대 진동은 스위치가 아니라 자라나는
불안정이라(Titze 1988), 작은 요동에서 지수적으로 커지다 포화하는 **볼록한**
S 자다 — t=0 부근이 가장 느려야 한다.

**측정으로만 드러났다.** 잡음을 전부 끄고 하모닉만 남겨도 발성 개시 후 50 ms 의
최대진폭이 정상부의 76 % 였다(실측 27 %). 주기별로 보면

    실측  27 25 19 11 16 16 | 50 79 92 ...   여섯 주기를 낮게 끌다 솟는다
    1차지연 (첫 주기부터 곧장 오른다)

로지스틱으로 바꿨다: dA/dt = σ·A·(1 − A/A_target), σ = f0/cycles.
포화항이 있어야 목표에서 멈춘다(순수 지수는 발산). 씨앗 2 %.

    cycles 3.0 -> 50 ms 26 %, 90 % 도달 128 ms
    실측       -> 50 ms 18~45 %, 90 % 도달 118~131 ms

그리고 **전이 구간의 기식이 너무 컸다**. 포락선으로 보니 마찰음에서 목소리로
넘어가는 창에 **모음보다 큰 스파이크 버스트**가 있었다(전이/모음 1.08).
`ASPIRATION_GAIN` 10.0 -> 2.5 (44.1 kHz). 50 ms 최대 83 % -> 28 %.

> **교훈**: 이 두 개는 스펙트럼 지표로는 안 잡혔다. 포락선을 그려야 보였다.
> `10->90 % 상승시간` 같은 요약 수치는 **모양이 반대인 두 곡선을 구분하지
> 못한다** — 1 차 지연과 로지스틱이 같은 81 ms 를 낸다. §0 의 "underdetermined
> 를 의심하라" 가 여기서도 그대로였다.

### 6.1 (해결) "ksa" 의 /k/ = 발화 개시의 기식 버스트

**파형을 직접 그려서** 잡았다. 숫자만 보다가 세 턴을 헛돌았다 — 이 절의 교훈은
"포락선을 그려 봐라" 다.

경계에서 파형이 ±0.95 로 순간 튀었다가 30 ms 에 걸쳐 감쇠했다(감쇠 진동 =
포먼트 울림 = 파열음 버스트). 제어를 프레임 단위로 찍어 보니

    t(ms)   noise_bands(마찰음)   aspiration_bands(기식)
     70          0.0000                0.0000
     80          0.0000                0.0000
     90          0.0001                0.1024   <- 한 프레임에 계단

범인은 **마찰음이 아니라 기식**이었다. 혀 제스처 모드는 폐압을 상수로 두는데,
발화 개시에는 혀가 아직 협착을 안 만들었고(성도가 열려 있고) 성문도 마찰음용
으로 크게 벌어져 있다. 직렬 저항이 양쪽 다 낮아 **유량이 첫 프레임에 최대**가
되고, 그 잡음이 성도 전체를 통과하며 계단 입력으로 들어간다.

Signorello et al.(2018) 의 "Ps 는 마찰음 내내 거의 일정" 은 마찰음 **구간 안**의
관찰이지, 발화 시작에 압력이 계단으로 선다는 뜻이 아니다.

고친 것 셋:
1. `breath_onset(t, fr, onset_s, delay_s)` — 폐압 상승 램프(45 ms).
2. **램프를 늘리지 말고 늦춘다.** 처음엔 "협착 형성에 맞춘다"를 "폐쇄 시간만큼
   늘린다"로 잘못 구현해서 램프가 200 ms 가 됐고, 마찰음 앞 130 ms 가 통째로
   안 들리게 됐다. 압력이 서는 시간은 생리적으로 40~60 ms 고정이다.
3. 발화 앞에 무음 세그먼트(`lead`). 파일 첫 1 ms 0.34 -> 0.0002.

결과: 첫 1 ms 0.0002, 경계 직후 1 ms 0.0002 (실측 개시 0.0054).
포락선 최대 상승률 341 /s (실측 377 /s) — 더 이상 계단이 아니다.

### 6.1b (해결) 마찰음에 몸통이 없었다 — 고원을 넣었다

`tongue_constriction_cv` 가 **삼각형**이었다(닫자마자 바로 열림). Kim et
al.(2022) 이 못박은 "높은 Pio 고원 = 음향 마찰음 길이" 가 빠져 있었다.
게다가 Ps 가 일정하면 진폭이 1/(Ac²/Ag²+1) 이라 Ac ≪ Ag 에서 **포화**하므로,
고원이 없으면 가청 구간이 짧고 가파른 상승 하나로 뭉친다.

    고원 없음: 가청 80 ms, 정점 위치 26~32 %, 상승 20 ms
    고원 있음: 가청 136 ms, 정점 64 %, 상승 43.5 ms
    실측     : 가청 139~154 ms, 정점 42~49 %, 상승 49~76 ms

`hold_s` 를 추가했다(기본 = onset_s). 반환하는 기준점은 **고원의 끝**(해제
시작)이고, 그게 포먼트 전이·내전의 앵커다.

### 6.1b ★ 구강공명 비중이 아직 모자라다

사용자 지시: "구강공명 비중을 무조건 더 높여야 한다".

| | 봉우리 | 2-4k | 4-6k | 6-8k | 8-10k | 10-13k |
|---|---|---|---|---|---|---|
| 실측 사 #1 | 5556 Hz | 11.8 | **44.2** | 28.4 | 7.8 | 6.8 |
| 실측 사 #2 | 4673 Hz | 13.1 | **48.1** | 22.6 | 8.8 | 6.7 |
| 합성 사 (전) | 10207 Hz | 5.0 | 18.8 | 10.9 | 27.7 | 24.2 |
| **합성 사 (현재)** | 10088 Hz | 8.6 | **37.0** | 18.9 | 22.6 | 11.4 |

4~6 kHz 를 18.8 -> 37.0 % 로 두 배 올렸다(실측 44~48). 봉우리는 아직 앞니
공명이 근소하게 이긴다.

무엇을 했나 — **장애물 다이폴을 협착 기하에 묶었다**:
- `obstacle_strength(area)`: 앞니 다이폴 세기 0~1. **속도로 재면 안 된다** —
  성문이 넓어(0.25 cm²) Ac ≪ Ag 인 동안 v 가 압력에만 묶여서, 협착을 두 배로
  넓혀도 속도비가 0.897 밖에 안 움직인다(측정). 실제로 변하는 건 제트의
  기하라서 면적비 `(a_ref/Ac)^exp` 로 잡는다.
- `SibilantParams.teeth_gain`: 앞니 공진의 **세기** 손잡이(전에는 `ones_like`
  고정이라 손잡이가 없었다). 병렬 혼합 `(1-g)+g·H` 라 줄여도 대역이 안 파인다.
- `_dipole_jet_correction`: 8~13 kHz 를 지배하는 건 좁은 앞니 공진기가 아니라
  **소스 쪽 광대역 상승**(+10 dB/oct)이다. 기울기가 지수에 선형이라 `dip^(g-1)`
  로 보정한다. **RMS 정규화 필수** — 안 하면 기울기를 깎는 게 곧 /s/ 를 13 dB
  조용하게 만드는 일이 되고, 그러면 모음이 고역 정점을 가져간다(측정).
- `TONGUE_CV_A_MIN = 0.11`: 짧은 CV 는 목표 자세에 못 간다(undershoot).
  Po/Ps = 0.84 로 논문의 0.85~0.89 안에 남는다.

**다음 단계**: 봉우리를 실측처럼 5 kHz 대로 내리려면 `teeth_gain` 을 더 낮추거나
`OBSTACLE_JET_EXP`(현재 1.0)를 올린다. 레벨이 8 dB 움직이므로
`SYLLABLE_FRICATIVE_CAL_DB` 를 반드시 다시 재라(25.0 -> 17.0 으로 이미 한 번 옮겼다).

구간이 안 생겼다 — 이제 그 구간의 실제 최대 성문 면적을 쓴다.

### 6.2 ★ 잡음 보정 상수가 샘플레이트에 딸려 온다

`band_shelf` 가 0~나이퀴스트를 n_bands 로 나누기 때문. 24 kHz 는 밴드당 300 Hz,
44.1 kHz 는 551 Hz.

| 상수 | 24 kHz | 44.1 kHz |
|---|---|---|
| `BREATH_NOISE_GAIN` | 2.7 | 7.8 |
| `ASPIRATION_GAIN` | 6.3 | 10.0 |
| `SYLLABLE_FRICATIVE_CAL_DB` | 25.0 | 27.0 |

지금은 `gen_me_sibilant.py` 의 `CAL_44K` 가 44.1 kHz 값을 **실행 시 덮어쓴다**.
`AudioConfig.sample_rate` 기본값은 24000 그대로다 — 44100 으로 바꾸면 테스트
**17 개가 깨진다**(hop 240, 밴드 인덱스, 프레임 크기가 24 kHz 전제).

**제대로 된 해법**: 셸프를 **활성 밴드 수로 정규화**해 샘플레이트 불변으로 만들고,
그 다음 기본값과 테스트를 함께 44.1 kHz 로 옮겨라.

**왜 44.1 kHz 여야 하나**: 이 화자의 앞니 공명이 10015 Hz 인데 24 kHz 는
나이퀴스트가 12 kHz 다 — 봉우리 바로 위 1.2 kHz 에서 벽에 부딪힌다.
봉우리도 위로 밀린다(24 kHz 10266~10289, 44.1 kHz 9905~9948, 실측 9905~9991).

**그리고 치찰음 지문을 원본 44.1 kHz 녹음에서 다시 뽑아야 한다.**
`me.json` 의 `meta.source` 가 "44.1k**→24k**" 다 — 12 kHz 천장에서 적합해서
10 kHz 공명의 위쪽 스커트가 2 kHz 밖에 안 보였고, 대역폭이 넓게 치우쳤다.
`teeth_bw` 를 912.6 → 600 으로 손으로 되돌렸지만 근사다.

### 6.3 음절 레벨 보정 상수가 프로파일마다 15 dB 다르다

마찰음 세기를 **소스 진폭**으로 기준화하는데 유성음 세기에는 성도 캐스케이드
이득이 곱해져 있다. 마찰음은 그 캐스케이드를 우회하므로(`noise_entry=K+6`)
화자마다 어긋난다. 해법: 기준을 **렌더된 모음 세기**로 옮긴다.
> 한 번 시도했다 되돌렸다. 손대려면 §8 측정 도구를 먼저 갖추고 한 번에 끝내라.

### 6.4 무게중심 이동 방향이 반대다

실측 긴 /s/ 는 **7350 → 9008 → 7194 Hz** (양끝이 낮다).

| | 개시 | 정점 | 끝 |
|---|---|---|---|
| 실측 | 7350 | 9008 | 7194 |
| 호흡 구동(협착 고정) | 9765 | 8365 | 9970 |
| **혀 제스처** | **12166** | **8792** | **11989** |

혀 제스처로 이동폭은 커졌는데(1400 → 3374 Hz) **방향이 틀렸다**. 협착이 넓어질 때
앞공동 극이 내려가면서 **고정된 앞니 공명 10 kHz 의 상대 비중이 커져** 무게중심이
오히려 올라간다.

시도했다 실패한 것:
- `sib.mix` 를 협착 조임으로 게이트(제트 없으면 다이폴도 없다) → 방향 안 바뀜
- `SOURCE_TILT_DB_PER_OCT` 1.5 → 7.5 → 개시 무게중심 9543 → 9425 뿐

**남은 용의자**: `dsp/sibilant.py` 의 `floor_db` — 피크 대비 −25.6 dB 의 **평탄한**
병렬 방사 경로가 tilt 로 깎인 고역을 도로 채운다. 소스와 함께 기울어지는 경로로
바꿔야 tilt 가 무게중심에 반영된다.

### 6.5 리액턴스는 페이드 인의 원인이 아니다 (확인 완료, 재시도 금지)

`oral_cavity_reactive` 로 관성(음향 질량)을 제대로 넣어 봤다:
`dU/dt = (ΔP − ½ρU|U|/A²)/M`, `M = ρL/A`, `dPm/dt = (U_g−U_c)/C`.
심플렉틱 적분 + 적응 부분단계(전진 오일러는 해제에서 NaN — 헬름홀츠가 협착
0.10 cm² 227 Hz 에서 모음 3 cm² 1246 Hz 로 **올라간다**).

| | 준정상 | 리액턴스 |
|---|---|---|
| 대칭 압력 아치 정점 (0.6 s) | 49.1 % | 50.0 % |
| 실제 음절 U_g − U_c 최대 | 0 | 유량의 0.03 % |
| Pm/Ps | 0.590 | 0.590 |

**시간 규모가 두 자릿수 다르다**: τ = Lc·Ac/U 로 0.5~20 ms 인데 페이드는
100~900 ms 다. τ = R·C 를 100 ms 로 맞추려면 등가 체적 6,125 cm³(폐 크기),
900 ms 는 55,125 cm³(어떤 폐보다 크다).

함수는 남겨 뒀다(테스트로 준정상 극한 일치를 고정). 기본 경로엔 안 물린다.

> 남은 리액턴스 자리 하나: `constriction_transmission` 이 지금 **주파수 무관**이다.
> 관성을 넣으면 `T(ω) = T(0)/(1+jωM_c/Z_load)` 로 약 557 Hz 위를 깎는 저역통과가
> 된다. 아직 안 해 봤다.

### 6.6 잡음에 구강 공명을 더 싣는 건 현재 실측과 충돌한다

시도 셋 다 실측을 악화시켰다:
1. 기식 대역폭 축소 → F1/F2 돌출 **안 늘고**(10.1/10.0 그대로) F4/F5 만 울려
   모음 4~6 kHz 가 2.1 → 12.8 %
2. `noise_back_leak` 0.25 → 0.55 → `_oral_leak` 이 **덧셈이 아니라 크로스페이드**라
   비중을 올리면 치찰음 봉우리를 내주는 거래가 된다
3. `BREATH_NOISE_HZ` 3500 → 1500 → 속삭임 500~2k 비중 0 → 59 %(효과 있음)이지만
   모음 1~2 kHz 4.1 → 8.4 %(실측 5.0)

**근본 원인**: 기식 스펙트럼 **하나가 둘을 겸한다** — 유성 모음의 기식성 바닥
(하모닉 위에 얹히므로 고역 셸프가 맞다)과 속삭임(광대역이라야 포먼트를 싣는다).
**발성 여부로 소스 스펙트럼을 가르는 게** 구조적 해법이다.

### 6.10 ★ 긴 /s/ 의 11~18 kHz 가 13 dB 얇다

실측 긴 /s/ 는 6~11 kHz 기준 11~18 kHz 가 **−2.6 dB** 다(8~13 kHz 가 평평한
고원이고 13~14 kHz 에서 절벽처럼 떨어진다: 10 kHz −3.6, 12 kHz −8.2,
14 kHz −25.5 dB). 합성은 −16.2 dB — 10 kHz 봉우리 위가 곧바로 꺼진다.

원인은 앞니 공진기의 폭이다: 10015 Hz / bw 912.6 이면 12 kHz 에서 −12.8 dB,
600 이면 더 깊다. 실측의 "고원" 은 공진기 모양이 아니라 **다이폴 상승과
소스 컷오프가 만나는 평평한 구간**으로 보인다.

시도한 것과 결과는 §5.8 의 표에 있다 — `teeth_bw`, `f_max_boost`,
소스 컷오프 셋 다 이걸 못 푼다. **여기 있던 후보 두 개도 조사했고 둘 다
기각됐다**(2026-09-04):

**(a) 앞니 다이폴에 고역 모서리를 준다** — 13 kHz 위로 −20/−35/−50 dB/oct 를
걸어 봤다. 실측과의 진짜 차이인 **12 kHz 구멍은 전혀 안 움직이고**(합성
−31.6 dB 그대로, 실측 −4.7/−10.7) 18~22 kHz 만 −40 → −62/−78/−93 로 더
내려갔다(실측 −32). 구멍은 다이폴이 아니라 앞니 공진기의 대역폭이 만든다.

**(b) 앞니 공진을 두 개로** — 목표 대역은 확실히 고친다: 11~18 kHz 가
−16.1 → **−8.0 dB**(실측 −2.6/−8.1), 12 kHz 가 −31.6 → −16.4. 그런데
**무게중심 아치를 잃는다**: 아치 높이 554 → 151~212 Hz(실측 1431/2572).
그리고 2.5~6 kHz 가 −6.4 → −12~−14 로 같이 내려간다. 밴드+무게중심 결합
비용으로 재면 공진 1 개(13.62)가 모든 2 개 변형(16.8~18.2)보다 낫다.

  * 다시 시도한다면 **두 번째 공진에 자기 게인**을 줘라. 지금은 `teeth_gain`
    하나가 둘을 함께 섞어서, 약하게 만들 수가 없다. (모양이 깨지던 잠재 버그는
    고쳐 뒀다 — §5.9, `tests/test_dsp.py`.)
  * 또는 아치를 만드는 쪽(`_dipole_jet_correction`, `source_tilt_shift`)을
    강화해서 두 번째 공진이 붙어도 무게중심이 움직이게 한다.

**먼저 실측 스펙트럼을 log 축에 겹쳐 그려라**(§8.0c). 밴드 합만 보면 이 고원의
존재가 안 보인다. 그리고 **실측 두 토큰이 이 대역에서 5 dB 넘게 다르다**
(11~18 kHz −2.6 vs −8.1) — 한 토큰에 과적합하지 마라.

### 6.12 응답 체인이 혼합위상이다 (tilt / skirt 가 영위상)

측정과 되돌린 이유는 §5.9 에 있다. 요약: 노이즈 경로 임펄스응답의 26 % 가
정점보다 **앞에** 온다(−20 dB 기준 0.16 ms). `min_phase_from_log_mag` 로
고치면 4.6 % 가 되지만, 위상이 병렬 덧셈(`floor_db`, `_oral_leak`, 앞니 혼합)
을 통해 크기에 영향을 주기 때문에 **프로파일의 `floor_db` 와 추출기가 같이
바뀌어야** 한다(안 바꾸면 왕복이 깨진다: pole_f 3500 → 4266).

우선순위는 낮다 — 정상 잡음에서 위상은 들리지 않고(§5.9), 실측 대비 개선도
1 dB 이내였다. 다만 **개시·해제의 프리에코**는 남아 있으므로, 마찰음 개시가
아직 부자연스럽다면 여기를 의심하라.

### 6.11 무성 마찰음의 성문 기식을 어떻게 넣을 것인가

/s/ 는 성문을 크게 벌린 채 내는 소리라 성문에도 기류가 지나가고 난류가 난다.
물리적으로는 있어야 하는데, `asp_n * asp * asp_share` 로 넣었더니 마찰음이
작아지는 **가장자리를 광대역 잡음이 지배해** 무게중심이 6359 → 2353 Hz 로
무너졌다. 지금은 넣지 않는다(마찰음 경로는 `aspiration_bands = 0`).

세기를 무엇에 묶어야 하는지가 문제다. 후보: 마찰음 포락선 `env` 에 비례시켜
가장자리에서 같이 줄이거나(그러면 "기식이 따로 존재한다" 는 성질이 사라진다),
성문 제트의 레이놀즈 게이트를 더 엄격히 걸거나.

### 6.8 ★ 모음의 9~13 kHz 가 34 dB 모자란다

§1b 표에서 유일하게 큰 구멍이다(실측 −26.3, 합성 −60.1 dB). 실측 목소리는
20 kHz 까지 −80 dB 언저리의 잡음 바닥을 유지한다.

원인은 **DC 정규화 캐스케이드의 고역 한계**다. 극을 더 얹으면 나이퀴스트 근처
극의 이득이 1 을 크게 넘어 응답 전체를 지배하고 저역이 붕괴한다(§5.6d 측정:
극 22 개에서 50~300 Hz 가 −87.5 dB). 그래서 지금은 극을 13+2 개로 막아 뒀다.

제대로 된 해법은 **하모닉 경로도 peak 정규화**하는 것이다
(`filters.gated_cascade_response` 가 노이즈 경로에 대해 이미 그렇게 한다 —
그 docstring 에 이유가 적혀 있다). 그러면 극을 나이퀴스트까지 얹을 수 있다.
다만 전체 레벨 규약이 바뀌므로 `FRICATIVE_CAL_DB` / `SYLLABLE_FRICATIVE_CAL_DB`
를 다시 맞춰야 한다(테스트 두 개가 잡아 준다).

**감쇠 우선순위는 낮다**: 실측에서도 9~13 kHz 는 전체 에너지의 0.00 % 다.
"공기감" 정도의 차이다.

### 6.9 모음 고역의 **주기적 골**이 없다

실측 /아/ 의 4 kHz 이상 포락선에는 F0 마다 **12~15 dB 깊이의 골**이 규칙적으로
난다(성문 펄스가 F4/F5 를 때리고 사이에서 울림이 잦아든다). 합성은 같은 자리가
매끈하다 — 우리 고역이 거의 전부 **잡음**이고 하모닉이 아니기 때문이다.

두 갈래가 있다. (a) 소스 tilt 를 덜 가파르게 해서 하모닉을 고역까지 올린다
(프로파일 tilt 는 §6.7 때문에 신뢰도가 낮다), (b) `noise_am`(성문동기 잡음
변조)을 키운다 — 실제 기식 잡음은 성문이 열린 동안에만 난다(Klatt). 지금은
`breathiness`(0.16)를 그대로 쓴다. **먼저 실측에서 골의 깊이를 재라.**

### 6.7 추출기의 tilt 가 재현되지 않는다

`analysis/extract.fit_source_rd_tilt` 가 낸 `tilt=+8.747` 로 합성하면 1~2 kHz 가
36.8 %(실측 4.2 %). 합성기는 tilt 를 **H1 기준** 옥타브당 dB 로 가산하는데
F0=124 Hz 면 1~2 kHz 가 +29 dB 부푼다. 닫힌고리로 −1.0 을 넣었고 경위는
`meta.tilt_refit` 에 있다. **추출기 자체는 아직 안 고쳤다.**

## 7. 다음 음소 계획 (사용자 지정 순서)

**ㅈ·ㅊ → ㄹ·ㅎ·ㄱ·ㄷ → "이"(구개음화)**

**§6.1(음절 혀 제스처)을 먼저 끝내라.** ㅈ·ㅊ·ㄱ·ㄷ 가 전부 "협착 궤적의 다른
시간 상수" 로 나오므로, 그 전에 음소를 늘리면 음소마다 손으로 맞춘 상수가 쌓인다.

- **ㅈ, ㅊ (파찰음)**: `tongue_constriction` 의 시간 상수만 바꾸면 된다 —
  폐쇄 → 급해제 → 짧은 마찰. 근거: 파찰음은 압력 변화 기울기가 마찰음의
  **1.5~2 배**(§3.3: [ts] 14~18 vs [ʃ] 8~9), 지속이 짧고, 지각의 1 차 단서가
  **지속시간**(§3.4). 3 항 대립(ㅈ/ㅊ/ㅉ)은 §3.2 의 [±s.g.]/[±tense] 틀.
- **ㅎ**: 성문 마찰. `PRESETS["h"]` 자리가 있고 `aspiration_bands` 경로(성도 전체
  통과)가 맞는 경로다. §6.6 의 속삭임 문제와 같은 구조.
- **ㄱ, ㄷ (파열음)**: Ac → 0 인 극단이라 같은 방정식이다. **ㄱ 은 `ORAL_VOLUME` 이
  더 작아야 한다** — 조음 위치가 뒤일수록 협착 뒤 공동이 작아 압력이 빨리 오른다
  (§3.3). 파열음은 조음 속도가 마찰음보다 **빠르고** 성문 개대는 **작고 늦다**(§3.3).
- **ㄹ**: 탄설음/설측음. 협착이 아니라 **접촉과 우회 통로**라 성도 형상 쪽 작업이다.
  이 순서에서 가장 이질적이다.
- **"이" 와 구개음화**: /i/ 앞에서 ㅅ→[ɕ], ㅈ→[ʥ], ㅎ→[ç]. **협착 위치**가 앞뒤로
  옮겨가는 것이라 `pole_f`(앞공동 길이)와 `LOCUS` 가 모음과 **함께** 움직여야 한다.
  §6.1 을 끝내면 협착 위치가 이미 1 급 변수가 되므로 그때 붙이는 게 맞다.

### 8.0c 개시 기울기는 **−30 dB 교차점에 정렬해서 겹쳐 그려라**

절대 시간으로 보면 무음 리드인·압력 램프 길이 때문에 어긋나서 모양 비교가
안 된다. 4~12 kHz 포락선(12 ms RMS)을 각자의 정점으로 정규화하고 −30 dB
교차점을 0 으로 놓으면 실측 두 토큰과 합성이 한 그림에 겹친다. 상승·돔·
하강·골·회복이 한꺼번에 보인다.

```python
win, hop = 1024, 256
f = torch.linspace(0, fs/2, win//2+1)
S = torch.stft(x, win, hop, window=torch.hann_window(win), return_complex=True).abs()
hi = (S[f > 4000]**2).sum(0).sqrt(); hi /= hi.max()      # 마찰음 포락선
lo = (S[(f > 200) & (f < 1000)]**2).sum(0).sqrt(); lo /= lo.max()   # 유성
pk = hi.argmax(); on = (hi > 0.1).float().argmax()
# 음절이면 off = lo 가 0.5 를 넘는 첫 프레임, 아니면 마지막 0.1 교차점
frac = (pk - on) / (off - on)                    # 정점 위치. 목표 0.52~0.63
ratio = (pk - on) / (off - pk)                   # 상승/하강. 목표 1.09~1.67
flat3 = mean(hi[on:off+1] > 10**(-3/20)) * 100   # 평탄도. 아치면 ~21%, 고원이면 30%+
```

**`flat3` 을 반드시 같이 봐라.** 정점 위치와 상승/하강비만 보면 고원형과 아치형이
구분되지 않는다 — 그게 이번 세션에 발견한 3 개월짜리 오류의 원인이다(§0).

- **치찰음 봉우리**: 정점 **한 프레임**의 1.5~12 kHz 최댓값. 목표 9905~9991 Hz.
  **프레임을 평균하지 마라** — 음절에서 옆 프레임이 이미 모음이라 1.6 kHz 로 잡힌다.
- **모음−마찰음 세기**: `L(0.30,0.57) − L(0.03,0.11)` (m01 기준). 목표 +11~13 dB.
- **전이가 비지 않는지**: `hi[정점:유성개시].min()`. **목표 0.122~0.123**
  (재측정. 예전 주석의 0.13~0.14 는 다른 창/대역이었다). 너무 메워도 안 된다 —
  전이가 실측보다 밝으면 /h/ 처럼 들린다.
- **스펙트럼 평탄도**(1~11 kHz, 기하평균/산술평균): 사람 /s/ 는 0.2~0.4.
  우리는 0.49~0.51 — 아직 퍼져 있다.
- **공기역학 직접 보기**:
  ```python
  d = aero_drive(seg, t, frame_rate)
  d["env"]      # 마찰음 포락선
  d["cent"]     # 면적에서 나온 공진 배율
  d["src_tilt"] # 속도에서 나온 소스 기울기
  d["pm_frac"]  # Po/Ps — 목표 0.85
  ```

## 9. 지뢰밭 — 겪은 것들

- **Stevens 의 속도-무게중심을 성도 공진에 걸지 마라.** 소스 스펙트럼 얘기다.
  걸면 /s/ 가 /ʃ/ 로 시작한다. 기하는 `area_centroid_scale`, 소스는 `source_tilt_shift`.
- **`aspiration_source_amp` 를 제 최대값으로 정규화하면 직렬 배분이 지워진다.**
  그러면 /s/ 구간에서 치경 F2 가 마찰음 위에 얹힌다.
- **전이 기식을 제어신호 비율로 검사하지 마라.** `aspiration_bands` 의 구간 최대는
  **모음의 기식성 바닥**이라 전이 기식만 줄어도 비율이 떨어진다. **소리를 직접 재라.**
- **`transition_s` 하나가 세 조음기관을 끌고 있었다.** 지금은 혀끝 `release_s`,
  후두 `adduction_s`, 혀몸 `transition_s` 로 분리돼 있다. **다시 합치지 마라.**
- **포먼트 전이를 발성 개시에 묶지 마라.** 후두 타이밍을 건드릴 때마다 포먼트가
  딸려 와 "사" 가 "야" 로 들린다. 지금은 **협착 해제 시점** 기준이다.
- **내전을 마찰음 중간에 시작하면 /s/ 가 죽는다.** 성문이 좁아지면 직렬 저항의
  무게중심이 성문으로 옮겨가 협착 뒤 압력이 무너진다(마찰음 0.79 → 0.18).
- **기식을 `(1-v_frac)` 로 끄면 성문파열음이 된다.** 발성은 난류를 없애지 않는다.
- **정적 성문 면적은 주기적 완전폐쇄를 표현 못 한다.** 성문 제트속도는
  `v=sqrt(2Ps/ρ)` 로 압력만이 정해서, 0.004 cm² 까지 조여도 기식이 안 준다.
- **레벨/질감 통계는 고원부에서 재라.** 전체 RMS 는 페이드 모양이 섞인다.
- **테스트 임계값을 낮춰서 통과시키지 마라.** 낮춘 적이 두 번 있는데 둘 다
  "무엇을 재는지" 가 바뀌었기 때문이고 그 이유를 테스트 안에 적어 뒀다.
  이유를 못 적겠으면 그건 회귀다.
- **`test_voice.py` 의 `PROF` 는 기본 프로파일이다.** 화자 프로파일로 재야 하는
  검사는 `_me_profile()` 을 쓴다.
- **PDF 는 `pdftotext -layout` 로 읽어라.** 프록시가 출판사 도메인을 막으므로
  논문은 사용자에게 받아야 한다. `apt-get update && apt-get install -y poppler-utils`.
- **`pip install torch` 는 PyPI 로 해라.** `download.pytorch.org` 는 프록시가 막는다.
