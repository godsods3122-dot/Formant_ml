## 2. 물리 구조 (무엇이 무엇을 만드는가)

```
호흡 신경구동 ──2단 근육지연──> 폐압 Ps(t)          aeroacoustic.breath_drive
                                   │
                    ┌──────────────┴──────────────┐
                    │  직렬 유량 U (성문 + 구강)   │  aeroacoustic.series_flow
                    └──────────────┬──────────────┘
        ┌──────────────────────────┼──────────────────────────┐
        │                          │                          │
   구강 협착 난류              구강 공동 적분              성문 난류
   = 마찰음 /s/               Pm (되밀림)                = 기식
   ∝ ½ρ(U/Ac)²·게이트         oral_cavity()             aspiration_source_amp
        │                          │
        │                    (Ps − Pm) ──> 발성 역치 ──> 진동 기동 관성 ──> 유성
        │                                              (ONSET_CYCLES, 주기 수)
   앞니 다이폴 + 치찰음 극-영점 필터
```

**핵심 인과 사슬 네 개** — 이걸 깨뜨리면 소리가 무너진다.

1. **페이드는 호흡 압력에서 나온다.** 협착은 고정이다. 대칭 압력 아치로는
   정점이 49.5 % 에 남는다(진폭이 Ps 의 단조함수라 게이트·제곱법칙이 정점을
   못 옮긴다). 비대칭은 호흡 구동 자체에 있다 — 올릴 때가 내릴 때보다 느리다.
   시상수는 초가 아니라 **구간 길이 대비 비율**이다(길이가 13 배 달라도 정점
   위치가 56~57 % 로 같다).
2. **구강내압이 발성 개시를 정한다.** /s/ 동안 Pm 이 Ps 의 59 % 를 먹어
   (Ps−Pm) 이 역치에 못 미친다. 협착이 열려 Pm 이 빠져야 떨기 시작한다.
   VOT 를 손으로 박지 않는다.
3. **마찰음을 끝내는 건 혀다. 후두가 아니다.** /s/ 는 성문을 벌린 채 내는
   소리다.
4. **마찰음과 목소리를 잇는 건 기식이다.** 마찰음 꼬리가 아니다.

## 4. (완료) 앞니 다이폴이 /s/ 개시부터 있다 — 소스/필터 분리

이전 세션의 최우선 과제였고, 이번에 고쳤다. **구조를 바꿨고 상수를 돌리지
않았다.**

### 무엇이 문제였나

`_scale_sib_center()` 가 입자속도에서 나온 배율 `cent` 를 `pole_f`, `zero_f`,
**`teeth_f` 에까지** 곱했다. Stevens(1971) 가 말하는 건 난류 **소스** 스펙트럼의
무게중심인데 그걸 **성도 공진**에 건 것이다. 개시에는 압력이 낮아 속도가 느려
배율이 0.62 까지 내려가고, 앞니 공명 10.0 kHz 가 6.2 kHz(= /ʃ/ 영역)에 놓였다.
게다가 페이드 인 구간은 협착 면적이 **고정**이다 — 기하가 안 변하는데 공진만
움직이는 건 자기모순이었다.

### 어떻게 바꿨나 (세 갈래로 나눴다)

| 물리량 | 무엇이 정하나 | 어디로 갔나 |
|---|---|---|
| 앞니 공명 `teeth_f` | 혀끝-앞니 간극 = **순수 기하** | **아무것도 안 곱한다** |
| 앞공동 극 `pole_f`, 반공진 `zero_f` | 최협착점 위치 = **협착 면적** | `aeroacoustic.area_centroid_scale` |
| 난류 소스 기울기 `tilt` | 입자속도 (Stevens) | `aeroacoustic.source_tilt_shift` |

`area_centroid_scale` 은 그 궤적의 **최소 면적**을 기준으로 하므로 배율이 항상
≤ 1.0 이고, 협착이 가장 좁을 때 화자 지문이 **그대로** 나온다. 정점 정규화 같은
보정이 필요 없어졌다(예전엔 속도로 재느라 그게 필요했고, 그 정규화가 개시를
/ʃ/ 로 만들었다). 협착이 고정인 페이드 인 구간에서는 정확히 1.0 이다.

### 결과 (개시 프레임부터의 스펙트럼)

| **현재 "사"** | **10125 Hz** | **0.3 %** | **78.8 %** |

## 4b. (완료) 기식이 /s/ 를 어둡게 만들던 두 번째 커플링

위를 고치고 재 보니 **또 하나**가 나왔다. "사" 의 마찰음 정점 스펙트럼에서
**1~2 kHz 가 에너지의 36 %** 였다(독립 마찰음은 0.01 %). 실제 /s/ 에는 거의 없는
성분이고, 봉우리가 10 kHz 가 아니라 1.7 kHz 로 잡혔다.

정체는 **성문 기식**이다. 기식은 성도 캐스케이드를 통과하므로 치경 F2(1750 Hz)
가 그대로 나온다. 그게 /s/ 구간 내내 제 세기로 나오고 있었다. 빠져 있던 물리가
둘이고, 둘 다 **순수 기하**다:

1. `aeroacoustic.glottal_drop_fraction` — 직렬 저항 배분. 이 파일 머리의 직렬
   모형 그대로 `Ac²/(Ac²+Ag²)` 다. /s/ 는 구강 협착(0.10)이 성문(0.12)보다 좁아
   압력강하의 **41 % 만** 성문에 걸린다. `aspiration_source_amp` 를 제 최대값으로
   정규화하면서 이 배분이 지워지고 있었다.
2. `aeroacoustic.constriction_transmission` — 성문에서 **난** 소리가 협착을 지나
   얼마나 **나오는가**. 저역에서 관성 임피던스 분배로
   `T = (Lc+Lf)·Ac / (Lc·A0 + Lf·Ac)`, Ac=0.10 이면 0.079(≈ -22 dB), Ac→A0 이면
   정확히 1. 뒤공동 공진이 협착 **뒤에 갇혀 있다**는 게 이 항이다.

단순 면적비 `Ac/A0` 도 써 봤는데, 해제 중반을 과소평가해서(0.23 vs 0.42) 마찰음이
꺼지는 창을 기식이 늦게 메웠다. 임피던스 분배 쪽이 물리도 맞고 전이도 낫다.

**전이는 안 빈다.** 발성이 아니라 **혀**가 여는 것이라, 협착이 풀리면 배분과
전달이 함께 1 로 가고 기식이 제 세기를 되찾는다 — 그 시점은 발성보다 **앞선다**
(구강내압이 빠져야 성대가 떨므로). 렌더된 고역 포락선 최저 0.24 (실측 0.14,
이전 코드 0.42 — 오히려 실측에 가까워졌다).

결과: 마찰음 정점의 1~2 kHz 가 **36 % → 0.1 % 미만**, 8~12 kHz 가 38 % → 80 %.

## 5. 알려진 결함 (고치지 않고 남겨둔 것)

### (a) 음절 레벨 보정 상수가 프로파일마다 15 dB 다르다

`SYLLABLE_FRICATIVE_CAL_DB = 25.0` 은 `me.json` 기준이다. 기본 프로파일에
쓰면 15 dB 어긋난다.

**원인**: 마찰음 세기를 **소스 진폭**(`harmonic_amp`)으로 기준화하는데, 유성음의
실제 세기에는 성도 캐스케이드 이득이 곱해져 있다. 마찰음은 그 캐스케이드를
우회하므로(`noise_entry = K+6`) 화자마다 캐스케이드 이득만큼 어긋난다.

**제대로 된 해법**: 기준을 소스가 아니라 **렌더된 모음 세기**로 옮긴다.

> 한 번 시도했다가 되돌렸다. 다이폴을 RMS 정규화하고 캐스케이드 이득을 곱해
> 봤는데, 프로파일 의존은 안 사라지고(/s/ 구간이 기식 지배로 넘어가면서)
> `FRICATIVE_CAL_DB` 까지 줄줄이 흔들렸다. 손대려면 §6 측정 도구를 먼저 갖추고
> 한 번에 끝내라.

### (b) 추출기의 tilt 가 재현되지 않는다

`analysis/extract.fit_source_rd_tilt` 가 낸 `tilt=+8.747` 로 합성하면 1~2 kHz 가
에너지의 36.8 % 가 된다(실측 4.2 %). 합성기는 tilt 를 **H1 기준** 옥타브당 dB 로
가산하는데(`dsp/glottal.py:184`), F0=124 Hz 면 1~2 kHz 가 +29 dB 부풀기 때문이다.
닫힌고리로 다시 맞춘 값 −1.0 을 `profiles/me.json` 에 넣고, 경위를
`meta.tilt_refit` 에 적어 뒀다. **추출기 자체는 아직 안 고쳤다.**

### (b2) 긴 /s/ 의 무게중심 오르내림이 사라졌다  ← **다음 세션이 볼 것**

실측 긴 /s/ 는 무게중심이 **7350 → 9008 → 7194 Hz** 로 진폭과 함께 오르내린다.

| | 개시 | 정점 | 끝 |
|---|---|---|---|
| 실측 | 7350 | 9008 | 7194 |
| 이전 코드 | 6393 | 9446 | 6343 |
| **현재** | **9543** | **9467** | **9707** |

이전 코드는 이 오르내림을 재현했지만 **그 방법이 곧 §4 의 버그였다** — 공진
자체를 끌어내려서 만든 것이고, 그래서 /s/ 가 /ʃ/ 로 시작했다. 지금은 공진이
제자리에 고정돼 있어 오르내림이 거의 없다.

제대로 된 자리는 **소스 기울기**(`source_tilt_shift`)다. 실제로 tilt 는 개시
-6.91 → 정점 -5.22 dB/oct 로 잘 움직이고 있다. 그런데 무게중심이 안 따라온다:
`dsp/sibilant.py` 의 `floor_db`(피크 대비 -11 dB 의 **평탄한** 병렬 방사 경로)가
tilt 로 깎인 고역을 도로 채워서, 필터 무게중심이 8689~8827 Hz 로 갇힌다.
`SOURCE_TILT_DB_PER_OCT` 를 1.5 → 7.5 로 올려도 개시 무게중심이 9543 → 9425 밖에
안 움직인다(그래서 **상수를 안 올렸다**. 효과가 없는 데다 2~4 kHz 만 0.3 → 1.1 %
로 지저분해진다).

즉 남은 건 상수가 아니라 **구조**다: `floor_db` 를 피크 대비 고정 비율이 아니라
소스와 함께 기울어지는 경로로 두어야 tilt 가 무게중심에 반영된다.

> 주의: 실측 7350 이 정말 소스 물리인지, 아니면 개시가 -20 dB 라 **녹음 바닥
> 소음**이 저역을 끌어내린 것인지 확인이 안 됐다(원본 녹음이 이 세션엔 없다).

## 5b. (완료) "침묵" 이 침묵이 아니었다 — 잡음이 안 꺼지던 진짜 원인

사용자: "발성이 끝났음에도 계속 노이즈가 안 꺼지고 계속 나오는 건 왜 그런 거지?
전체적으로 다 그래."

`silence` 세그먼트가 `harmonic_amp` 와 `noise_bands` 만 끄고
**`aspiration_bands` 를 안 껐다.** `base()` 가 그걸 상수 셸프로 깔아 두기 때문에,
"침묵" 구간이 사실은 최대 **-3 dB 의 기식 잡음**이었다.

| | 이전 | 현재 |
|---|---|---|
| m02 두 '사' 사이 | **-3 dB** | **-70 dB** |
| m04 토큰 사이 | **-19~-21 dB** | **-77 dB** |

침묵은 **기류가 없다는 뜻**이다. 잡음은 전부 기류에서 나오므로 세 경로를 다
꺼야 한다. `base()` 의 주석은 기식이 "발성 중에만 난다"고 이미 적어 두었는데,
그 불변량이 음절 분기에서만 지켜지고 있었다.

## 5c. (완료) /z/ 가 뒤쪽 3 분의 1 에서 마찰음을 잃었다

m05 는 협착을 구간의 90 % 까지 잡고 있는데 마찰음이 **65 % 에서 죽었다** —
기본 호흡 제스처가 40 % 만 누르고 힘을 놓아서, **혀가 아직 안 열었는데 압력이
먼저 빠진** 것이다. 남은 3 분의 1 이 마찰 없는 맹숭한 유성음이었다.
`breath_sustain=0.95` 를 주면 96 % 까지 산다. 마찰음을 끝내는 건 혀다(§2 #3) —
압력이 먼저 빠지면 그 순서가 뒤집힌다.

## 5e. 잡음에 구강 공명을 더 싣는 건 실측과 **충돌**한다  ← 판단 필요

사용자: "노이즈 자체가 구강 공명의 영향을 더 많이 받는 게 좋을 거 같아.
속삭이는 소리들도 알아들을 수 있듯이."

세 가지를 재 봤고 셋 다 실측을 악화시킨다.

1. **기식 경로 대역폭을 좁힌다** (`noise_bw_scale` 3.0 -> 1.6, 기식 전용으로
   분리해서). F1/F2 돌출은 **안 늘고**(10.1/10.0 그대로) F4/F5 만 울려서
   모음 4~6 kHz 가 2.1 -> 12.8 % 로 터졌다. 손잡이는 지웠다.
2. **구강 결합을 키운다** (`noise_back_leak` 0.25 -> 0.4/0.55). F1/F2 돌출은
   3.5 -> 3.1 로 오히려 줄고 마찰음만 조용해진다([D] +12.6 -> +16.9). 두 경로를
   RMS 정규화해서 레벨을 맞춰 봐도 같다. `_oral_leak` 은 **덧셈이 아니라
   크로스페이드**라, 비중을 올리면 치찰음 봉우리를 내주는 거래가 된다.
3. **기식 셸프를 내린다** (`BREATH_NOISE_HZ` 3500 -> 1500). 이건 실제로 먹힌다
   (속삭임의 500~2k 비중 0 % -> 59 %). 대신 모음 1~2 kHz 가 4.1 -> 8.4 %
   (실측 5.0), 0-1k 가 92.9 -> 87.8 % (실측 92.6) 로 어긋난다.

**근본 원인**: 기식 스펙트럼 하나로 두 가지를 겸하고 있다.
  * *유성 모음의 기식성 바닥* — 하모닉 위에 얹히므로 고역 셸프가 맞다(실측이
    그렇게 말한다).
  * *속삭임/무성 구간* — 하모닉이 없으니 잡음이 포먼트를 직접 실어야 하고,
    그러려면 광대역이어야 한다.
지금은 둘 다 3500 Hz 셸프를 쓴다. **발성 여부에 따라 기식 소스 스펙트럼이
갈라지도록** 나누는 게 구조적 해법이다. 상수를 옮기는 걸로는 한쪽이 반드시
깨진다.

> 지금 상태는 **실측 모음 분포와 일치**한다(92.9 / 4.1 / 2.1 vs 92.6 / 5.0 / 2.1).
> 여기서 공명을 더 실으면 측정에서 멀어진다. 그러므로 이건 귀로 판단할 문제다 —
> 사용자에게 "측정과 맞는 지금" 과 "공명이 더 실리지만 측정과 어긋나는 쪽" 중
> 무엇을 원하는지 물어라. 우리는 귀가 없다(§0).

## 5f. 리액턴스(관성)를 넣어 봤다 — 페이드 인의 원인이 **아니다**

사용자 가설: "페이드 인이 잘 안 생기는 이유 중 가장 큰 이유가 리액턴스 아니냐.
기식이 치찰음에 에너지를 싣는 게 아니라 구강 내압을 증가시키는 케이스를
고려 안 한 거겠지."

**타당한 지적이었다.** `oral_cavity` 는 공동을 순수 컴플라이언스로만 보고 협착을
저항성 오리피스로 뒀다 — 1 차 RC 이고 **음향 질량이 어디에도 없었다.** 그래서
유량이 압력의 순간값으로만 정해져(기억이 없다) "진폭이 Ps 의 단조함수라 정점이
안 옮겨간다" 는 §2 의 결론이 나왔다. 그건 관성이 없어서 생긴 결론이다.

그래서 제대로 넣었다 — `aeroacoustic.oral_cavity_reactive`:

    dU_g/dt = (Ps − Pm − ½ρ·U_g|U_g|/Ag²) / M_g,   M_g = ρ·Lg/Ag
    dU_c/dt = (Pm      − ½ρ·U_c|U_c|/Ac²) / M_c,   M_c = ρ·Lc/Ac
    dPm/dt  = (U_g − U_c) / C,                     C   = V/(ρc²)

U_g ≠ U_c 인 구간이 생기므로 **성문 기류가 협착을 통과하는 대신 공동을 부풀리는**
바로 그 케이스가 표현된다. 심플렉틱 적분 + 적응 부분단계를 쓴다(전진 오일러는
해제에서 NaN 이 난다 — 헬름홀츠가 협착 0.10 cm² 227 Hz 에서 모음 3 cm² 1246 Hz
로 **올라가기** 때문이다).

### 측정 결과 — 가설은 기각된다

| 검사 | 준정상(현재) | 리액턴스 | 실측 |
|---|---|---|---|
| 대칭 압력 아치, 정점 위치 (0.6 s) | 49.1 % | **50.0 %** | 56~57 % |
| 대칭 압력 아치, 정점 위치 (1.5 s) | 49.6 % | **49.6 %** | 56~57 % |
| 실제 음절에서 U_g − U_c 최대 | (정의상 0) | **유량의 0.03 %** | — |
| Pm/Ps | 0.590 | **0.590** | 0.59 |

**왜 안 되는가 — 시간 규모가 두 자릿수 다르다.** 관성 시상수는

    τ = M_c/R = Lc·Ac/U

로 U=200 cm³/s 에서 **0.5 ms**, 개시의 U=5 에서도 **20 ms** 다. 페이드는
100~900 ms 다. 유량이 압력을 준정상으로 따라가므로 포락선이 안 바뀐다.
공동 충전 구간(U_g ≠ U_c)은 **실재하지만 몇 ms 라 한 프레임 안에서 끝난다.**

**얼마나 큰 리액턴스여야 되는가.** 시상수 τ = R·C 를 관측값에 맞추려면:

| 목표 τ | 필요한 등가 체적 (U=200) |
|---|---|
| 100 ms | 6,125 cm³ |
| 600 ms | 36,750 cm³ |
| 900 ms | 55,125 cm³ |

구강은 **60 cm³** 다. 100 ms 를 내려면 폐(3,000~6,000 cm³)가 필요하고, 긴 /s/ 의
600~900 ms 는 **어떤 폐보다도 크다**. 즉 이 시상수는 성도 안의 수동 리액턴스로는
나올 수 없다.

**결정적 증거는 §3 에 이미 있었다.** 수동 RC/리액턴스는 시상수가 **고정**이다.
그런데 실측은 /s/ 길이가 122 ms 든 1649 ms 든(13 배) 정점이 56~57 % 로 **같다** —
즉 시상수가 구간 길이에 **비례**한다. 수동 물리는 그럴 수 없다. 화자가 의도한
길이에 맞춰 힘 주는 속도를 조절하는 **계획된 운동 제스처**만 그럴 수 있다.
지금의 `breath_drive`(신경 구동 -> 근육 2단 지연)가 맞는 자리에 있다.

### 코드는 남겨 둔다

`oral_cavity_reactive` 와 `test_reactive_cavity_matches_quasistatic_and_is_stable`
을 남겼다. 기본 경로에 **안 물린다** — 프레임률에서 차이가 없는데 계산량만

## 6. 측정 도구 — **작업 전후로 반드시 돌려라**

귀가 없으므로 이게 유일한 판단 근거다. 아래를 `/tmp` 스크립트로 만들어 쓴다.

### 포락선 모양 (페이드 인 비율, 상승/하강비)

```python
win, hop = 1024, 256
f = torch.linspace(0, fs/2, win//2+1)
S = torch.stft(x, win, hop, window=torch.hann_window(win), return_complex=True).abs()
hi = (S[f > 4000]**2).sum(0).sqrt(); hi /= hi.max()      # 마찰음 포락선
lo = (S[(f > 200) & (f < 1000)]**2).sum(0).sqrt(); lo /= lo.max()   # 유성
pk = hi.argmax(); on = (hi > 0.1*hi.max()).argmax()
# 음절이면 off = 유성이 0.5 를 넘는 첫 프레임, 아니면 마지막 0.1 교차점
frac = (pk - on) / (off - on)       # 페이드인 비율. 목표 0.52~0.63
```

### 치찰음 봉우리 / 대역 분포

정점 근처 몇 프레임의 평균 스펙트럼에서 1.5~12 kHz 최댓값 위치. 목표 ~9.9 kHz.
대역별 에너지 비율도 같이 본다.

### 모음−마찰음 세기 (이게 제일 잘 드리프트한다)

```python
L = lambda a, b: 20*log10(rms(x[int(a*fs):int(b*fs)]))
L(0.30, 0.57) - L(0.03, 0.11)     # m01_sa.wav 기준. 목표 +11 dB
```

### 전이가 비지 않는지

`hi` 포락선이 마찰음 끝~발성 사이에서 얼마까지 떨어지는가. 목표 ≥ 0.13.
0 에 가까우면 성문파열음으로 들린다.

### 제어 신호 직접 보기 (원인 추적용)

```python
c = build_segment({...}, prof, cfg)
c["noise_bands"].sum(-1)      # 마찰음
c["aspiration_bands"].sum(-1) # 기식
c["harmonic_amp"]             # 유성
c["formant_freq"]             # 포먼트 궤적 (활음 확인)
```

## 7. 지뢰밭 — 겪은 것들

- **`transition_s` 하나가 세 조음기관을 끌고 있었다.** 지금은 혀끝
  `release_s`, 후두 `adduction_s`, 혀몸 `transition_s` 로 분리돼 있다.
  다시 합치지 마라.
- **포먼트 전이를 발성 개시에 묶으면 안 된다.** 후두 타이밍을 건드릴 때마다
  포먼트가 딸려 오고 "사" 가 "야" 로 들린다. 지금은 **협착 해제 시점** 기준이다.
- **내전을 마찰음 중간에 시작하면 /s/ 가 죽는다.** 성문이 좁아지면 직렬 저항의
  무게중심이 성문으로 옮겨가 협착 뒤 압력이 무너진다(Ac 는 그대로인데
  마찰음이 0.79 → 0.18). 겹침을 늘리고 싶어도 여기를 당기지 마라.
- **기식을 `(1-v_frac)` 로 끄면 성문파열음이 된다.** 발성은 난류를 없애지
  않는다. 다만 **전이 기식**은 발성에 반비례하고 **기식성 바닥**은 발성에
  비례한다 — 둘은 별개다.
- **정적 성문 면적은 주기적 완전폐쇄를 표현 못 한다.** 성문 제트속도는
  `v=sqrt(2Ps/ρ)` 로 압력만이 정해서, 성문을 0.004 cm² 까지 조여도 기식
  진폭이 /s/ 때와 거의 같다. 그 몫을 발성 비율로 대신 주고 있다.
- **레벨/질감 통계는 고원부에서 재라.** 전체 RMS 로 재면 페이드 모양이 레벨에
  섞여서, 페이드를 만질 때마다 음량이 따라 움직인다.
- **Stevens 의 속도-무게중심을 성도 공진에 걸지 마라.** 그건 난류 **소스**
  스펙트럼 얘기다. 공진에 걸면 압력이 낮은 개시에서 앞니 공명이 /ʃ/ 영역으로
  내려가 **/s/ 가 /ʃ/ 로 시작한다**(§4). `velocity_centroid_scale` 에 경고를
  달아 뒀다. 기하는 `area_centroid_scale`, 소스는 `source_tilt_shift`.
- **`aspiration_source_amp` 를 제 최대값으로 정규화하면 직렬 배분이 지워진다.**
  그러면 /s/ 구간에서 기식이 제 세기로 나오고, 성도 캐스케이드를 지나 치경 F2
  가 마찰음 위에 얹힌다(§4b). 배분은 `glottal_drop_fraction` 으로 따로 살린다.
- **전이 기식을 제어신호 비율로 검사하지 마라.** `aspiration_bands` 의 구간
  최대는 **모음의 기식성 바닥**이라, 전이 기식만 줄어도 비율이 떨어진다 —
  그게 성문파열음을 뜻하지는 않는다. 실제로 비율이 0.16 으로 떨어졌을 때 렌더된
  고역 최저는 0.23 이었다(실측 0.14). **소리를 직접 재라**
  (`test_frication_and_voicing_overlap_instead_of_switching` 을 그렇게 바꿨다).
- **테스트 임계값을 낮춰서 통과시키지 마라.** 두 번 낮춘 적이 있는데 둘 다
  "무엇을 재는지" 가 바뀌었기 때문이고, 그 이유를 테스트 안에 적어 뒀다.
  이유를 못 적겠으면 그건 회귀다.
- **`test_voice.py` 의 `PROF` 는 기본 프로파일이다.** 화자 프로파일로 재야 하는
  검사는 `_me_profile()` 을 쓴다.

## 8. 계정 두 개로 병렬 작업할 때

실제로 두 세션이 같은 파일을 동시에 고친 적이 있고, 한 번은 같은 문제
(마찰음 페이드)를 서로 다른 방법으로 고쳐서 충돌했다(`6d2dc73` 병합).

- **push 전에 항상 `git fetch origin main` 하고 확인한다.**
- `git merge-base --is-ancestor origin/main <branch>` 로 fast-forward 가능
  여부를 먼저 본다.
- **force-push 금지.** 상대 세션의 커밋을 지운다. 충돌하면 병합하고, 어느
  쪽을 택했는지 커밋 메시지에 남긴다.
- 상대가 이미 고친 것을 다시 고치지 말고, 근거(측정값)가 있는 쪽을 택한다.
  실제로 저쪽이 실측 LPC 로 F1/F2 전이 속도를 바로잡은 적이 있다(`b86f2a4`).
- `claude/voice-generation-physics-model-kuty1l` 브랜치는 별개의 실험 라인이다.
  건드리지 않는다.
