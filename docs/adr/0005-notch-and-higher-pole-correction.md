# ADR 0005 — 영점은 극-영점 노치로, 고차 극은 0.7·fs/2 까지 고정 배치

상태: 채택 (v0.2.0)

## 맥락 (측정)
* DC 정규화 영점쌍(v1 `antiresonator_response`)은 먼 대역을 들어올린다: 3.3 kHz 측지 영점이
  44.1 kHz 에서 고역 +25 dB, 1.3 kHz 뒤공동 영점이 +40 dB. 첫 v2 렌더에서 /s/ 에너지가
  13~20 kHz 에 몰린 원인이었다.
* 이산 공명기는 θ→π 에서 이득이 (1−r)⁻² 로 뛴다(19.8 kHz 극 +58 dB).
* K=8 로 자르면 9~13 kHz 가 30 dB 이상 죽는다(v1 §6.8).

## 결정
`notch_coeffs(f, bw_z, pole_ratio)`: 같은 각도의 더 넓은 극쌍으로 나눠 노치 밖 응답 1.
고차 극은 균일관 위치 (2n−1)c/4L 로 `0.70·fs/2` 까지만 고정 배치, 대역폭은 `bw_floor + bw_slope·f`
에 학습 배율.
