# ADR 0008 — 음소 제스처의 목표값은 화자 프로파일(녹음 계측)에서만 온다

상태: 채택 (v0.2.1)

## 맥락
v1 은 30 여 개 상수를 손으로 적합했고 상수끼리 서로를 가렸다(AUDIT B1). v2 첫 판도
`phones.py` 안에 여성 일반값을 박아 두었다. 사용자가 여성 화자 문장과 본인의
비음/치찰음 녹음을 주었다.

## 결정
* `engine/profile.py::SpeakerProfile` — 관 길이, F0 범위, 모음 F1~F3, 유음 자세·골 깊이·길이,
  치찰음 정점·레벨·길이, 비음 극/영점/레벨/전이, 음절 길이. JSON 한 장.
* `phones.Builder(profile)` 는 **구조만** 가진다(무엇이 언제 움직이나). 숫자는 프로파일.
* 프로파일의 모든 값은 `docs/MEASUREMENTS.md` 의 표에 근거를 둔다. 문장에 없는 소리는
  다른 화자 녹음의 **구조**(모양·시간)를 가져오고 주파수는 관 길이 비로 옮긴다.
* 제3자 코퍼스 파일은 저장소에 넣지 않는다(`data/`). 숫자는 문서에 다 옮긴다.

## 이번 계측이 바꾼 것
| 항목 | 이전 (가정) | 계측 | 결과 |
|---|---|---|---|
| 탄음 골 | 5 dB (남성) | 여성 9~11 dB, 35~45 ms | 프로파일 값 (dip_db, gain) |
| 음절 길이 | 300 ms | 140 ms | `timing` |
| ㅆ | — | 70 ms, 정점 8~12 kHz, 모음 −4.6 dB | `sibilant.peak_hz` → 앞공동 0.92 cm |
| 탄음 과도음 | 템플릿 클릭 | 고역 버스트 없음 | `transient_amp = 0` (기본) |
| 비음 머머 | 극 280 + 영점 1000/1700 | 극 250, **2~3 kHz 골 −40**, 모음 −6 dB | 극-영점 봉우리 + 2.4~2.5 kHz 노치 + 3 kHz 저역통과 |
| ㅈ/ㅊ | 없음 | 개시 10 ms 에 −70→−30 dB, 100 ms 감쇠, 정점 5 kHz | 구강압 저장/방전 버스트 물리 (`noise.py`) |
| /s/ 중 성문 기식 | (1−add)²√Ps | 협착이 압력을 먹는다 | (1−add)²√ΔPg, ΔPg = Ps·Ac²/(Ac²+Ag²) |
