# ADR 0002 — 성문 소스는 압력·근육 좌표로 구동하고 F0/진폭/Rd 는 결과다

상태: 채택 (v0.2.0)

## 맥락
목표는 "성대와 주변부의 압력으로 원음 생성" 이고, 최종적으로 LLM 이 ms 단위 물리 factor 를
조정한다. F0·진폭을 직접 주면 발성 개시/소멸·기식·음질의 상호관계가 스크립트 작성자 몫이 된다.

## 결정
입력: `p_sub`, `adduction`, `tension` (+ `f0_target` 로 직접 지정 가능).
역치압(Titze) → 로지스틱 기동(v1 §6.0 검증) → 진폭 ∝ sqrt 초과압, F0 는 긴장 + 압력,
Rd 는 내전, 기식 포락선은 (1−내전)²·sqrt(Ps) × 개방기 AM. 파형은 LF 하모닉 가산합성.

## 결과
+ 한숨·속삭임·압착·기동/소멸이 손잡이 세 개의 조합으로 나온다(감정 토큰의 델타 공간이 작고 읽기 쉽다).
− 2 질량 자가진동 ODE 의 분기(이중음)는 없다. 필요하면 v1 `dsp/vocalfold.py` 를 소스 대안으로 얹는다.
