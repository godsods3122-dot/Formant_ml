# ADR 0011 — 마찰음 소스는 광대역이고, 성문 제스처는 협착과 다른 시간축을 갖는다

상태: 채택 (v0.2.3)

## 맥락
사용자 지적: "치찰음도 성대 진동과 완전히 따로 논다."

두 가지가 겹쳐 있었다.

1. **소스 스펙트럼.** 0.2.2 는 Strouhal 정점에 2 차 대역통과(Q 0.5)를 걸어 정점을 만들었다.
   그러면 정점 아래가 −6 dB/oct 로 떨어져 1~3 kHz 가 실측보다 15 dB 낮다. 마찰음이
   순수한 고역 히스가 되고, 뒤따르는 모음(저역 지배)과 스펙트럼이 78 dB 벌어진다 —
   두 개의 다른 소리를 이어 붙인 것처럼 들린다. 실측의 벌어짐은 39 dB 다.
2. **시간축.** 성문 개대를 마찰 구간에 맞춰 열고 닫았다. 실측은 그렇지 않다
   (`docs/MEASUREMENTS.md` §6.3): 유성도가 마찰 진입에서 **35 ms** 에 걸쳐 꺼지고,
   마찰 뒤 발성은 15~20 ms 만에 돌아오는데 **고역은 50~70 ms 더 이어진다.**

## 결정
1. 난류 소스는 **광대역**이다: 백색 → 1 kHz 모서리 고역 셸프(−9 dB) → 정점의 1.4 배에서
   2 차 저역통과. **스펙트럼 정점은 앞공동 극이 만든다**(Stevens: 소스는 광대역).
   실측 남성 ㅅ ×3 의 7 대역에 대해 rms **3.2 dB** (이전 9~15 dB).
2. 성문 제스처가 협착보다 **35 ms 먼저 열리고 55 ms 늦게 닫힌다**(격음은 110 ms).
   Löfqvist & Yoshioka 가 무성 마찰음에서 관찰한 순서이고, 기식 꼬리는 우리가 그리지 않는다 —
   성문이 아직 열린 채 협착이 풀리면 ΔPg 가 커지므로 `glottis` 의 기식 항이 저절로 낸다.
3. 마찰 세기의 기준점을 `phones.SIB_REF_DB` 한 곳에 두고, 프로파일은 **모음 대비 dB** 로만
   적는다. 소스를 바꿀 때마다 이 상수 하나만 다시 잰다.
4. `fric_gain` 상한 4 → 64. 파찰음이 10 dB 잘리고 있었다.

## 되돌린 판단
켑스트럼 포락선만 보면 실측 /s/ 의 저역이 정점 대비 −15 dB 라 "저역 바닥이 필요하다" 로
읽힌다. 절대 레벨로 재면 그 저역은 **방 잡음 바닥에 있거나 그 아래**다(§6.4). 넣지 않았다.
