# ADR 0013 — 난류는 통계로 채점한다: 실현 잡음을 뺀 일치율

상태: 채택 (0.3.7)
날짜: 2026-09-08

## 맥락

0.3.1 의 목표는 사용자 지시에서 왔다 — **"스펙트럼이 95 % 이상 일치할 때까지 ms 간격으로
파라미터를 추적해라."** 그 뒤 모든 판이 `포락 일치` 와 `정밀 일치` 두 값으로 진척을
보고했다. 둘 다 스펙트럼 수렴도다:

```
100 · (1 − ‖|S_t| − |S_p|‖_F / ‖|S_t|‖_F)
```

0.3.1 이 포락 94.5 % / 정밀 88.1 % 를 냈고, 그 뒤로 정밀은 좀처럼 안 올랐다. 마찰이
든 구간에서 특히 그랬다.

**그 자는 난류에 대해 틀린 것을 재고 있었다.**

마찰 잡음의 표본 하나하나는 미시적 소용돌이가 정한다. 완벽한 물리 모형이라도 그 *실현*은
재현하지 못한다 — 재현할 수 있는 것은 통계뿐이다. 그런데 위 식은 실현을 직접 뺀다.

같은 스펙트럼의 **두 독립 실현**을 서로 채점해 봤다. 이것이 완벽한 모형이 받을 점수다:

| 두 독립 실현 | 정밀 일치 | 포락 일치 |
|---|---|---|
| 백색 잡음 | **33.3 %** | 46.6 % |
| /s/ 모양 대역잡음 | **33.3 %** | 53.7 % |

이론값도 같다. STFT 빈의 크기는 레일리 분포이므로

```
E‖|S₁|−|S₂|‖² = 2·Var|S| = σ²(4−π),  E‖|S₁|‖² = 2σ²
SC = √((4−π)/2) = 0.6551  ->  일치 34.49 %
```

즉 **치찰음에서 95 % 는 도달 불가능한 목표가 아니라, 틀린 자에 걸린 목표**였다.
"정밀 88 %" 도 나쁜 값이 아니었다 — 그 구간에서 자가 바닥에 눌린 것이다.

그리고 자가 틀린 것에서 끝나지 않았다. **손실도 같은 오류를 안고 있었다.**

## 결정

### 1. 채점: 실현 잡음의 바닥을 재서 뺀다

같은 파라미터를 **시드만 바꿔** 한 번 더 합성한다. 그 둘의 거리가 곧 "완벽한 모형이라도
남는" 양이다. `|S| = m + n` (기대값 + 실현 잡음) 으로 쓰면

```
E‖|S_t|−|S_p|‖²  = ‖m_t−m_p‖² + V_t + V_p
E‖|S_p|−|S_p'|‖² = 2·V_p
```

모형이 옳으면 V_t ≈ V_p 이므로 둘째 식이 첫 식의 잡음 항 전체를 준다. 빼면 **편향**
‖m_t−m_p‖² 만 남는다. 분모도 V_t = D_pp'/2 를 빼서 보정한다.

대조군 (`engine/turbulence.corrected_sc`):

| 대조군 | 원래 정밀 | **보정 정밀** |
|---|---|---|
| 완벽 (스펙트럼 같음, 시드만 다름) | 33.9 % | **97.2 %** |
| 치찰 대역이 1 kHz 어긋남 | 29.4 % | 72.6 % |
| 크게 어긋남 (/ʃ/ 쪽으로) | −5.7 % | 6.9 % |
| 합성이 6 dB 조용함 | 31.6 % | 38.5 % |
| 같은 하모닉 | 100.0 % | 100.0 % |
| F0 가 3 % 틀린 하모닉 | 53.6 % | 53.6 % |

세 가지가 동시에 성립한다.

* **완벽한 모형이 97 % 로 수렴한다** — 이제 "95 %" 를 말할 수 있는 자다.
* **판별 여유가 5 배 넓어졌다** (4.5 → 24.6 %p). 상한에 눌려 있던 것이 펴진 것이다.
* **결정적 신호에 무해하다.** 하모닉에서는 D_pp' ≈ 0 이라 값이 안 바뀐다.

레벨 오차(6 dB 조용함)는 보정해도 낮게 남는다. 옳다 — 잡음량도 물리 파라미터다.

### 2. 손실: 위상 항은 난류를 보지 않는다

복소 잔차 `|S_t − S_p|` 는 위상이 상관된 곳에서는 옳지만, 무상관인 곳에서는
`E|S_t−S_p|² = |S_t|² + |S_p|²` 이라 **|S_p| = 0 이 최소**다. 합성 진폭 g 스윕:

| g | 예전 위상항 |
|---|---|
| 0.0 | **0.9992 ← 최소** |
| 1.0 | 1.4109 |

`fit_staged` 는 이 항을 기본 **800 회** 돌린다. 0.3.5 에서 "위상 예산이 모자랐다" 며
200 → 800 으로 늘린 그 변경이, 유성 구간에서는 옳았고 마찰 구간에서는 **800 회 내내
소리를 끄는 방향**으로 쓰였다.

바꾼 형태는 단위 크기로 정규화한 복소 잔차를 목표 크기로 가중한 것이다:

```
d(t,f) = w(t,f) · |S_t/|S_t| − S_p/|S_p||
```

`|S_p|` 에 대한 편미분이 항등적으로 0 이라 어떤 구간에서도 소리를 끄지 않는다. 크기는
크기 항이, 위상은 위상 항이 맡는 깨끗한 분해다.

가중 `w` 는 목표의 **조화 우세도** `|STFT(조화)|/(|STFT(조화)|+|STFT(잔차)|)` 다
(`waveform.decompose` 로 갈라 낸다). 난류 빈에서 0 이므로 재도 뜻이 없는 양은 아예
안 본다.

### 3. 손실: 마찰의 크기는 기대 스펙트럼으로 본다

난류의 STFT 크기는 확률변수다. 프레임별 실현을 맞추라고 하면 기울기 대부분이 그
잡음이고, 최적해도 실현마다 다르다. 난류 우세 빈 `(1−w)` 만 25 ms 시간 평활한
**기대 스펙트럼**으로 비교한다. 목표와 합성에 똑같이 걸리므로 편향은 없고 분산만 준다
(시간축 표준편차 0.290 → 0.060, 이론 √19 = 4.36 배).

### 4. 치찰음의 조음 위치는 따로 잰다

스펙트럼 수렴도 하나로는 "/s/ 인가 /ʃ/ 인가" 를 못 읽는다. 문헌이 조음 위치를 가른다고
확인한 양들을 따로 낸다 — 스펙트럼 봉우리 위치와 네 모멘트(무게중심·표준편차·왜도·첨도)
[Jongman, Wayland & Wong (2000), JASA 108(3):1252]. 저분산 추정에는 DPSS 멀티테이퍼를
쓴다 [Reidy (2015), JASA 137(4):EL248].

## 대안과 기각 이유

**(a) 그냥 시간 평균 스펙트럼만 비교한다.** `spectrum_match` 로 남겨 두었지만 주
지표로는 못 쓴다. 시간 구조를 통째로 버리므로 "마찰이 언제 시작하는가" 를 못 본다.
편향 보정은 시간 해상도를 유지하면서 실현 잡음만 뺀다.

**(b) 난류 구간을 채점에서 뺀다.** 가장 쉽지만 최악이다. 이 화자 코퍼스의 4~9 % 가
마찰 프레임이고, 치찰음은 화자 동일성의 핵심 단서다. 안 재면 안 고쳐진다.

**(c) 지각 손실(PESQ/ViSQOL 류)로 간다.** 미분 불가능하거나 학습된 모형이 필요하다.
이 프로젝트의 전제는 "물리가 파형을 만든다" 이므로, 채점도 물리량으로 설명되어야 한다.
편향 보정은 레일리 통계 한 줄로 유도된다.

## 남은 문제

`analyze.py` 의 마찰 판정(무성 + 고역/저역비 > 0 dB)이 치찰음과 호흡·기식을 못 가른다.
코퍼스 실측: 그대로 쓰면 무게중심 중앙값 5175 Hz (프로파일 실측 8100 Hz), 치찰도
> 8 dB 이고 무게중심 > 6 kHz 로 거르면 7997 Hz. 이 마스크는 `tract_gain` 고정과
`fric_gain` 보정에 쓰이므로 초기값에 직접 영향을 준다. **문턱을 실측으로 정하기
전에는 건드리지 않는다.**
