# ADR 0001 — 필터를 주파수영역 LTV-FIR 에서 시간영역 시변 IIR 로 바꾼다

상태: 채택 (2026-09-06, v0.2.0)

## 맥락
v1 은 프레임별 주파수응답 → 유한 IR → 블록 OLA 로 필터링했다(길이에 병렬, 학습 친화).
"라" 의 타격 지점에서 주파수별 위상 계단·프리에코·과도응답 부재가 측정됐다
(`docs/AUDIT_v1.md` A1~A4). 사용자의 가설("현존 TTS 가 스펙트럼만 맞추다 위상이
일그러진다") 과 같은 현상이 우리 합성기 안에서도 일어나고 있었다.

## 결정
모든 필터를 **샘플 단위로 계수가 보간되는 2차 재귀 필터(TDF-II)** 로 구현한다.
학습 경로는 상태 점화식 s[n]=A[n]s[n−1]+v[n] 을 **결합 스캔**으로 풀어 O(N log N)
병렬·정확 미분가능. 실시간 경로는 같은 방정식의 numba 샘플 루프.

## 결과
+ 위상 계단·프리에코가 구조적으로 불가능. 과도응답은 방정식이 낸다.
+ 스트리밍 = 오프라인 (상태 zi 하나로).
+ scipy.lfilter 와 상태 규약이 같아 검증이 쉽다.
− 스캔 비용: biquad 하나에 1 초 오디오당 ~30 ms (2 스레드). 엔진 전체 ~3 s/s. 실시간은 numba 경로.
− 시변 계수의 TDF-II 는 매우 빠른 스윕에서 이득 과도가 있을 수 있다 (샘플 보간이라 실제로는 무시할 수준; 테스트 `test_phase_continuity_at_abrupt_parameter_jump`).

## 대안
* 창 있는 OLA (교차 페이드): 이음매만 부드럽게 할 뿐 과도응답·인과성은 못 고친다.
* 시간영역 도파관(KL): 물리적으로 가장 정확하지만 학습·실시간 비용이 크고, 유음의 실패 원인이 아니었다. 나중에 궤적 생성기로 얹는다.
