# ADR 0006 — 제어열 규약: 파라미터별 독립 시간축, 0 = 기본/끔, 기본값 대치는 프레임률에서

상태: 채택 (v0.2.0)

## 결정
* 키프레임에 없는 파라미터는 **자기 키프레임들 사이에서만** 보간된다 → 대역별 시차(F3 가 먼저)를 그대로 적는다.
* 첫 키프레임 이전은 기본값, 마지막 이후는 유지.
* 로그 파라미터에서 0 은 "끔/기본" 이다. 0 ↔ 양수 사이는 보간하지 않고 영차 유지한다.
* 0 → 기본값 대치는 **프레임률에서** 한 뒤 샘플률로 보간한다.

## 이유 (사고 기록)
대역폭이 110 → 0 으로 선형 보간되며 0.5 Hz 를 지나 극이 단위원에 붙어 출력이 3×10¹⁰ 이 됐고,
포먼트 0 → 459 가 샘플률에서 보간되며 F1 이 10 Hz 를 지나갔다. 둘 다 규약 문제였다.
