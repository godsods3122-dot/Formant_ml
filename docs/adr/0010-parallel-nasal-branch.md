# ADR 0010 — 비강은 캐스케이드에 얹는 필터가 아니라 병렬 분기다

상태: 채택 (v0.2.3)

## 맥락
사용자 지적: "비강에서 구강으로의 연결이 뚝뚝 끊어져 있다."

0.2.2 까지 비음은 **구강 포먼트 캐스케이드 뒤에 극·영점 필터를 얹고** `tract_gain` 으로 세기를
낮추는 방식이었다. 그러면 구강이 닫힐 때 저역까지 같이 죽는다.

실측(같은 화자 5 ms, `docs/MEASUREMENTS.md` §6.1): 모음↔머머 사이에서 **80~500 Hz 는 ±2 dB
로 연속**이고 0.8~2.5 kHz 만 11 dB 떨어진다. 소리가 나가는 **구멍이 바뀌는 사건**이지
소리가 작아지는 사건이 아니다.

## 결정
성문 소스에서 두 분기가 갈라진다.

    구강 분기: 포먼트 캐스케이드 + 고차 극 + 앞공동   → 입술로 방사   (게이트 `oral_open`)
    비강 분기: 비강 극 3 개 + 나이퀴스트까지의 꼬리 극 + 구강 측지 영점 → 콧구멍으로 방사 (게이트 `velum`)

* 두 분기는 **유량을 나눠 갖는다**: `oral = oral_open/(oral_open+velum)`, `nas = velum/(…)`.
  머머(구강 폐쇄)에서는 전부 비강으로, 비음화 모음에서는 절반씩 간다.
* 게이트는 **입력에** 건다. 출력에 걸면 닫힌 동안에도 분기가 소스를 받아 울리고, 열리는
  순간 저장된 에너지가 통째로 튀어나온다(측정: 12 배 클릭).
* 측지 영점 주파수만 폐쇄 위치를 담는다 (ㅁ 1100 / ㄴ 1500 / ㅇ 2400 Hz, 문헌 범위 안).
* **모음의 비음화를 따로 만들지 않는다.** 연구개와 구강이 함께 열려 있으면 두 분기가 더해지고
  그 간섭이 F1 부근의 극-영점 쌍이 된다.
* 시간축도 둘이다: 연구개는 폐쇄보다 60 ms 먼저 열리고 90 ms 늦게 닫힌다(선행·후행 비음화).
  구강은 35 ms 에 닫히고 18 ms 에 열린다 (실측: 중역이 45 ms 에 내려가고 15 ms 에 돌아온다).

## 결과
같은 화자 A/B 에서 머머 레벨 −7.0 / −3.8 dB (실측 −6.2 / −3.4). 머머 스펙트럼 적합 rms 2.3 dB.
