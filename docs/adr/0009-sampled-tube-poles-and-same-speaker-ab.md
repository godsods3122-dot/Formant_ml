# ADR 0009 — 성도는 나이퀴스트까지의 극으로 완결한다; 검증은 같은 화자 A/B 로 한다

상태: 채택 (v0.2.2)

## 맥락 (사용자: "리을 빼면 다 문제, 노이즈, 장치 자체 문제")
같은 화자 A/B(사용자 본인 녹음 나/마/사/자/차 vs 그 프로파일로 합성) 1/3 옥타브 비교에서
**모음의 4~8 kHz 가 실측보다 35~60 dB 어두웠다.** 원인: DC 정규화 공명기 N 개(8+3)의 곱은
N 번째 극 위에서 (F_n/f)² 씩 떨어진다 — L=17 cm 에서 6 kHz −27 dB, 10 kHz −85 dB (계산).
무손실관 |H| = 1/|cos(πf/2F₁)| 은 ≥ 1 이다. 그 차이(고차 극 보정)를 FIR 로 되돌리려면 12 kHz 에서
+160 dB 가 필요해 켑스트럼 최소위상 설계가 성립하지 않았다(1024 탭에서 2 kHz 가 +45 dB 로 틀림).

## 결정
1. **표본화된 관은 나이퀴스트까지의 극으로 완결된다.** 균일관 위치 (2n−1)c/4L 의 극을
   0.98·fs/2 까지 전부 둔다(L=17 cm, 48 kHz 에서 8+15 개). 그 위의 극은 표본화에서 접혀 들어오므로
   따로 보정하지 않는다. 고차 극의 대역폭은 `bw_floor + 0.20·f` (≥ 800 Hz) — 벽·점성·방사·횡모드 손실.
   실측 남성 /아/ 와 1~16 kHz 1/3 oct rms 오차 **4.1 dB** (이전 30~60 dB). HPC FIR 코드는 남기되 끈다.
2. 성도 전체를 float64 로 계산한다 (캐스케이드 중간이 −85 dB 까지 내려가므로).
3. 기식 세기 = (1−add)²·(ΔPg/Ps)·√Ps, 기본 0.3 (실측 HNR 22 dB, 4~8 kHz 대역 적합).
   √ΔPg 로 두면 /s/ 중 성문 기식이 1~3 kHz 를 10 dB 채운다(A/B 로 특정).
4. 마찰 소스 혹은 자유 제트 Strouhal(0.2·v/d)이 아니라 장애물 소스로 더 높고 넓게 (0.5·v/d, Q 0.5).
   앞공동 극 대역폭 500 + 0.10·f. 소스 절벽은 정점의 8 배.
5. 비음: 연구개가 열리면 구강 유량·구강압 축적은 (1−velum) 배 (머머 중 Re 3700 짜리 마찰과
   해제 버스트가 나던 것). 머머의 극은 무겁게 감쇠(bw 300/400/500), 비강 봉우리 +3.5 dB @200 Hz,
   넓고 얕은 노치(ㄴ 2.5 kHz, ㅁ 3 kHz, −4 dB), 저역통과 없음. ㅁ 은 ㄴ 보다 +9 dB.

## 검증 방법 (앞으로의 규칙)
목표 화자(여성)로 바로 가지 않는다. **같은 화자 A/B** (`scripts/ab_male.py`): 사용자 본인 녹음 조각과
그 프로파일로 합성한 같은 음절을 1/3 옥타브·HNR·고역 포락선으로 나란히 재고, wav 를 짝으로 낸다.
장치가 같은 화자에서 맞아야 다른 화자로 옮길 자격이 생긴다.
