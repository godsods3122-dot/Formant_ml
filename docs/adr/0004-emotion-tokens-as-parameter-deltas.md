# ADR 0004 — 감정 토큰은 물리 파라미터 델타이며 마커로 추적된다

상태: 채택 (v0.2.0)

## 맥락
학습 중 감정별 토큰이 동적으로 생겨야 하되, 우리가 식별·통제·후처리 분리를 할 수 있어야 한다.

## 결정
토큰 = P 차원 델타(파라미터 단위, 로그 파라미터는 로그 비율) + 메타(감정, 사유, 지원, 사용 수,
frozen, excluded, tags). 적용은 제어열에 더하기만 하고 **마커를 남긴다**; `strip` 이 정확히 되돌린다.
학습 측 `TokenTable` 은 행을 동적으로 늘리고 frozen 행은 기울기를 끊는다.
`TokenDiscovery` 가 잔차 큰 문맥의 델타를 감정별로 군집해 후보를 제안한다(budget, min_support, allowed_params 로 통제).

## 결과
+ 토큰 내용이 사람이 읽는 숫자다("p_sub+1.5, adduction−0.2, tilt−3" = 한숨).
+ 후처리에서 마커로 구간을 찾아 제거·교체할 수 있다.
− 파라미터 델타로 표현 못 하는 감정 표현(예: 새로운 템플릿 소리)은 템플릿 뱅크 추가로 처리한다.
