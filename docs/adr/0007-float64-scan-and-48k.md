# ADR 0007 — 스캔은 float64, 기본 샘플레이트는 48 kHz, 스트리밍은 선행 1 프레임

상태: 채택 (v0.2.0)

## 측정
* float32 결합 스캔: 스트리밍(20 ms 청크)과 오프라인이 최대 0.3 % 어긋났다. 원인은 스캔
  트리의 반올림이 고 Q 공명기 이득 1/(1−r)² 만큼 증폭되는 것. float64 로 1e-6 이하.
* 44.1 kHz 에서 1 ms 프레임은 44.1 샘플이라 hop=44 로 두면 프레임 시각이 0.23 % 씩 밀려
  이벤트(과도음)의 샘플 위치가 청크 경계에 따라 달라졌다. 48 kHz 는 1 ms = 48 샘플.
* 마지막 프레임의 샘플 보간은 다음 프레임을 봐야 한다. 청크에 T+1 프레임을 주고 T 만
  내보낸다(`emit`). 지연 1 ms.

## 결정
`tviir.SCAN_DTYPE = float64` (입력 dtype 은 유지), `EngineConfig.sample_rate = 48000`,
`VoiceEngine.forward(..., emit=)`, 잡음은 `rng.NoiseBank` 위치 기반, 모든 재귀 상태는
내보낸 마지막 프레임 기준으로 갱신한다.
