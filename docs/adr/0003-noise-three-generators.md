# ADR 0003 — 노이즈는 세 생성기: 마찰(물리), 기식(성문), 과도음(템플릿+변조)

상태: 채택 (v0.2.0)

## 결정
* **마찰/치찰음은 직접 구현**한다: 직렬 오리피스 유량 → 협착 레이놀즈 수 → (Re²−Re_c²)^1.5,
  Strouhal 정점 소스, 장애물 다이폴, 앞공동 극 + 뒤공동 노치. 학습 단에 맡기지 않는다.
* 기식은 성문 물리(glottis)가 포락선을 주고 색만 입힌다.
* 혀 접촉·해제·입 바닥·침·입술 같은 **짧은 결정론적 사건은 템플릿 뱅크**(학습 가능 텐서)
  + 변조(속도·세기·기울기·미세 난수)로 낸다. 잔차 학습의 노이즈도 이 뱅크의 혼합으로 제한한다.

## 이유
사용자 판단과 일치: 통계 학습은 잡음을 '평균' 으로 뭉갠다. 기저가 있는 소리(템플릿)와
물리가 있는 소리(마찰)는 그 방식으로 만들고, 학습은 **혼합 계수와 템플릿 파형**만 고친다.
