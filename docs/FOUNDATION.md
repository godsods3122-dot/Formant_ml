# 기반 재설계 (0.4 계열) — 무엇이 화자에 불변이고, 무엇을 귀가 듣는가

사용자(2026-09-11): *"교재와 논문 가리지 말고, 여러 화자에 대하여 어떤 것이 불변하는 feature 이고 어떤 것이
종속되는지도 봐봐. 인지 음향 심리학도 참고해서 공진을 잘 인지하거나, 하모닉한 음성이 어떤 것인지도 보고…
구조 개편을 시작하자. 솔직히 이대로는 좀 안 될 거 같다. 기반부터 제대로 세우자."*

근거 자료는 `papers/INDEX.md` (신뢰층 0/A/B/C), 실측은 `docs/MEASUREMENTS.md` §50.

## 0. 근거의 서열

**목표 녹음의 실측 > 오래된 측정·물리·지각(A) > 공학 관례(B) > 최근 AI 논문(C).** 문헌이 목표와
부딪히면 목표를 따른다. 이번 세션의 예: 앞공동 Q 를 문헌·관례대로 2.5 로 막았더니 목표 ㅊ 의 봉우리
꼭대기가 Q 5.6 이었다 — 목표가 이겼다.

## 1. 화자에 불변인 것과 종속인 것

| | 불변 (말소리의 정체 — 발화마다 움직이는 제어) | 종속 (화자·녹음의 정체 — 화자당 한 번 적합) |
|---|---|---|
| 성도 공명 | 모음마다의 **상대** 포먼트 배치 — 화자 로그 평균 대비(Nearey), z 점수(Lobanov) 정규화 뒤에 남는 것 (Flynn 2011, A) | **성도 길이** → 포먼트 전체의 척도·간격(분산, Fitch 1997, A) |
| 고역 (2.5 kHz 위) | 마찰음 조음 위치의 순서(치조 > 경구개 봉우리), 스펙트럼 모멘트의 상대 관계 (Jongman 2024, A) | **하인두·이상와**: 모음에 무관하게 안정, 화자 간 차이가 크다 → 2.5 kHz 위 스펙트럼의 화자성, 이상와 영점 (Kitamura 2005, Delvaux 2014, A) |
| 마찰 | 협착 난류 = 압력 강하에 비례하는 등가 음원, 장애물 쌍극자, 앞공동이 봉우리를 만든다 (Stevens 1971, Shadle, Narayanan & Alwan 2000, A) | 앞니·혀끝 기하가 새기는 치찰음의 고정 미세 무늬 — 목표에서 서로 다른 치찰음끼리 미세구조 상관 +0.1~0.3 (층 0) |
| 음원 | 유성/무성의 대립, 유성 마찰의 성문 주기 맥동과 그 포화 (Jackson & Shadle 2000, Pincas & Jackson 2005, A) | 음원 기울기 넷(H1–H2, H2–H4, H4–2 kHz, 2–5 kHz)과 잡음 비 (Kreiman·Garellek, A), **MVF**(목표: s040 ≈ 6 kHz, s101 은 중역부터 덜 주기적), 지터·시머의 통계 (목표 ≈ 1.2~1.4 %, 8.7~9.2 %) |
| 시간 | 조음 운동 속도(대부분 20 Hz 아래), 음절 리듬 | F0 범위, 발성 습관 |
| 녹음 | — | 방·마이크 응답(고정 착색), 녹음 바닥 잡음(목표 −75 dB, 평평) |

**설계 귀결**: 제어를 세 층으로 가른다. (i) **화자 프로파일** — 여러 발화에 공통, 화자당 한 번 적합
(지금은 발화마다 전역 스칼라로 흩어져 있고, 적합이 파일마다 반대로 달아났다: 앞공동 대역폭 s040 하한 / s101
상한). (ii) **발화 제어** — 말소리의 정체, 조음 속도로 대역 제한. (iii) **확률 음원** — 통계로만 규정하고
실현은 맞추지 않는다.

## 2. 귀가 무엇을 얼마나 듣는가 (A 층 지각)

| 사실 | 수치 | 설계 귀결 |
|---|---|---|
| 청각 여파기 폭 | ERB = 24.7(4.37 f/kHz + 1) Hz (Glasberg & Moore 1990) | 손실의 주파수 축은 멜이 아니라 **ERB**. 고역일수록 넓게 본다 |
| 포먼트 주파수 식별 한계 | 3~5 % (Flanagan 1955), 높은 F0 에서 더 크다 (Karlsson 1999) | 포먼트 제어의 정밀도 목표. 그 아래의 떨림은 들리지 않는 대가로 인공물만 만든다 |
| 포먼트 대역폭 식별 한계 | 20~40 % (Flanagan) | 대역폭은 굵게 — 화자 프로파일 쪽에 |
| 중심 무게 효과 | 포먼트 간격 3~3.5 Bark 안이면 하나로 합쳐 들린다 (Chistovich & Lublinskaya 1979) | 가까운 포먼트 쌍은 개별 위치보다 합친 무게중심이 중요 |
| 배음 분해 | 약 8~10 번째 배음까지 분해, 그 위는 한 여파기에 여럿 → 시간 포락(주기성)으로 듣는다 (Plomp; Shackleton & Carlyon 1994) | F0 250 Hz 면 약 2.5 kHz 위는 **배음 줄이 아니라 성문 주기 포락**이 들린다. 목표 고역 포락의 F0 동기 0.83~0.84 (층 0) |
| 거칠기 | 20~150 Hz 진폭 변조가 거칠기로 들린다 (Zwicker & Fastl) | **제어가 20 Hz 넘게 움직여 잡음을 썰면 거칠게 들린다** — 사용자가 "지터" 라 한 것. 목표 모음 고역의 20~60 Hz 변조보다 적합이 3~12 dB 크다 (§50.17) |
| 잡음 질감 | 대역 포락의 분산·첨도, **대역 간 포락 상관**, 변조 전력 같은 통계로 지각 (McDermott & Simoncelli 2011) | 잡음 구간 손실은 실현이 아니라 **통계**로 |
| 숨소리 | 정상 잡음은 따로 떨어진 음원으로 들리고, 성문 주기에 동기한 고역 잡음이라야 목소리에 녹는다 (Hermes 1991, Mehta & Quatieri 2005) | 유성 고역 잡음은 **펄스 동기**여야 한다 |
| 고역의 무게 | 5 kHz 위가 음질·자연스러움(7~10.9 kHz)에 기여 (Monson 2014) | 고역을 버리지 않는다 |
| 합성음 판정 | 청자는 **인공물·불연속**에 가장 큰 무게를 준다 | 인공물(빗살·토막·클릭)은 손실의 평균 속에 묻히지 않게 따로 문다 |
| 자연스러움 | 약간의 거칠기(지터·시머)가 있어야 자연스럽다 | 지터·시머는 0 이 아니라 **화자 통계**로 |

## 3. 새 구조

### 3.1 제어 — 조음 속도로 대역을 묶는다
* 스펙트럼·조음 제어(포먼트·대역폭·앞공동·장애물·비강·음질 기울기)는 **20 ms 층까지만** — 3 차
  B-스플라인 20 ms 매듭이면 약 20 Hz 위를 깎는다. 협착·구강 개폐·폐압·내전은 폐쇄·유성 개시 때문에 10 ms.
  F0 는 운율·펄스 정렬 때문에 곱게 두되, 빠른 요동은 **지터 통계**가 낸다. (1 단계 판 `L48`)
* 20 Hz 보다 빠른 변화는 **확률 음원만** 낸다 — 제어가 실현을 좇지 못하게 한다(§50.6 실현 과적합, §50.9 20~60 Hz).

### 3.2 음원
* 배음: MVF 아래는 결맞은 배음. **MVF 위는 성문 주기마다 새로 뽑는 위상**(펄스 위치는 폐쇄에 남긴 채)
  — 지금의 1 ms 위상 흔들림은 한 주기 안을 뒤섞어 펄스 동기를 없앤다.
* 기식: 유성 정도로 가른다 (v2.1, 구현됨) — 유성분은 MVF 위 고역 잡음, 무성분은 전대역으로 정상 포먼트.
  목표의 무성 기식은 포먼트 구조를 가진다 (상관 +0.46/+0.31, 층 0).
* 마찰: 매끈한 문턱 + 샘플률 포락 (v2, 구현됨), 유성 마찰 AM 은 떨림 진폭 비례·포화.

### 3.3 필터
* F1~F4: 물리 공진, 샘플률 C¹ 궤적 (구현됨 — 1 kHz 빗살 제거).
* **고역(약 4 kHz 위)**: 지금의 1 차원 관 사다리(F4 에 매달린 극 열 개)를 걷고, **화자 고정 고역 구조** —
  넓은 공진 몇 개 + 이상와 영점 — 를 화자 프로파일로 둔다. 모음에 무관하게 안정하다는 실측(Kitamura)이 근거다.
  사다리는 F4 를 따라 흔들려 고역을 썰었고(§50.9), 좁아지면 평평한 줄을 세웠다(§50.5).
* 앞공동: 병렬 저~중 Q, Q 는 장애물에 묶는다 (v2.1, 구현됨).
* **녹음 경로**: 방·마이크 IR 을 세션당 하나 (`engine/room.py` 에 추정기가 있다) — 치찰음 사이 공통 미세
  무늬(+0.2)와 고정 착색을 여기서 낸다. 녹음 바닥 잡음은 고정 성분으로 (구현됨, `--floor`).

### 3.4 손실 — 귀가 듣는 것을, 실현이 아니라 통계로
* **ERB 척도 포락** (멜 대신), 수준 의존 가중.
* **분해 영역**(약 10·F0 아래): 배음 크기·위상(펄스·위상 항을 이 대역으로 한정).
* **비분해 영역**(그 위): 대역 포락의 성문 주기 동기와 **변조 스펙트럼**(거칠기 대역 20~150 Hz 포함)을 목표와 맞춘다.
* **잡음 질감**(마찰·기식 구간): 대역 포락 통계 + 대역 간 포락 상관 + 변조 전력 (McDermott 형).
* 잡음 씨앗은 늘 새로 뽑는다(기댓값 손실). 인공물 검출(빗살·토막·클릭)은 따로 문다.

## 4. 단계

| 단계 | 내용 | 상태 |
|---|---|---|
| 0 | 엔진 결함 수정: 성도 궤적 C¹(1 kHz 빗살), 고역 대역폭 가둠, hnr 치우침, 난수 채널 고정, 배음 난수 폭 | 끝 |
| 1 | 잡음 가지 v2.1 + 조음 대역 제한 (`--noise-v2`, `--slow`, `--base-smooth`) | 끝 — 모음 거칠기 +8.4 → +2.3 dB (§51.5, §51.10) |
| 2 | 고역 구조: 사다리 → 화자 고정 고역 공진·이상와 영점(`--hf-fixed`), **고차 극 꼬리 보정**(`--hpc`) | 끝 — 고역생존 23 → 100 % (§51.7, §51.14). 녹음 경로 IR 은 아직 |
| 3 | 지각 손실: ERB 포락, 분해/비분해 분리, 변조·질감 통계, 인공물 항 | 인공물 항만 먼저 (`--quiet`, §51.11). 나머지는 미착수 |
| 4 | 음원: 주기 동기 위상 분산(`--hjit-cycle`), 분산 세기 적합(`--hjit-fit`), **펄스 잠금**(`--pulse-lock`), **화자 음원 EQ**(`--src-eq`), 개방기 감쇠(`--open-damp`) | `L62`~`L67` 판정 중 (§51.16~51.18) |
| 5 | 화자 프로파일을 여러 발화에서 함께 적합 (s040 + s101 공동) — 불변/종속을 실제로 가른다 | 미착수 |

**자가 교정된 목표선**(§51.16): 같은 모델을 씨앗만 바꿔 렌더한 천장이 포락 **97.0 %** 이고, 포락은 0.33 ms 의
시간 어긋남에 6 점을 뗀다. 그래서 96 % 는 (i) 잡음 실현 천장 바로 아래이면서 (ii) 시간 정렬을 0.2 ms 안으로
맞춰야 하는 값이다. 오라클 분해(§51.18)로 남은 오차는 **타이밍 3.5 점 + 프레임별 대역 수준 5 점 + 대역 안
모양 3.3 점**으로 갈렸고, 4 단계의 세 손잡이가 정확히 그 세 자리다.

각 단계는 `census.py`(층층·고역생존·치찰토막·줄), `probe_sib_mod.py`, 모음 고역 변조(`out/_tmp/vowel_hfmod.py`),
모음 대역 주기성, 치찰음 음색, **1024 점 전대역 스펙트로그램**으로 판정한다. 척도가 좋아졌다는 것만으로
"해결" 이라 하지 않는다.
