# 조음 제약 — 혀가 낼 수 없는 움직임을 못 하게 만들기

이 문서는 네 가지를 다룬다.

1. **왜 치찰음과 모음이 따로 놀았는가** (§1) — 측정과 원인
2. **조음 속도 제한** (§2) — 페널티가 아니라 구조로
3. **포먼트 군집 / 저차원 부분공간** (§3)
4. **비강 결합과 성대 비선형성** (§4, §5)

---

## 1. /사/ 가 두 소리로 들렸던 이유

측정 (`scripts/analyze.py` 계열 진단, 0.6 초 /사/):

| | 이전 | 지금 |
|---|---|---|
| /s/ 구간 1.5 kHz 이하 에너지 비율 | 0.01 | 0.01 (마찰음은 원래 이게 맞다) |
| 자음 구간 F2 출발점 | 2290 Hz (/i/ 포먼트를 대신 씀) | **1750 Hz** (치경 locus) |
| 성도 전체를 통과하는 성분 | **없음** | 기식(aspiration) 경로 |
| 전이 프레임 수 | 3 (30 ms) | 5~9 (50~90 ms) |
| 치찰음 극 | 고정 6600 Hz | 6600 → 2500 Hz 로 활강 |

원인은 세 개였고, 전부 학습이 아니라 **구조** 문제였다.

**(1) 마찰 노이즈가 성도를 완전히 우회했다.** `noise_entry = K+6` 은 의도된
설계다(치찰음 극과 캐스케이드 극의 이중 계산을 피하려고). 그런데 그러면 /s/
구간에 성도 정보가 **하나도** 남지 않는다. 두 소리가 공명기를 공유한다는 증거가
신호 어디에도 없으니 크로스페이드로 들린다.

→ **기식(aspiration) 경로를 따로 만들었다.** 협착이 열리는 순간 압력이 성문으로
옮겨가며 나는 난류이고, 이건 **성도 전체**를 통과한다(Klatt 합성기의 AH 소스와
같은 위치). 마찰 노이즈(AF)와는 물리적으로 다른 소스이므로 난수도 따로 뽑는다
— 같은 신호를 두 경로로 보내면 콤필터가 생긴다.
`aspiration` 값 대비 유성 대비 레벨: 0.01 → −25 dB, 0.05 → −11 dB, 0.1 → −5.5 dB.

**(2) 자음 구간의 성도가 틀렸다.** /s/ 앞에 /i/ 포먼트를 썼는데 /i/ 의 F2(2290)는
경구개 위치다. 치경음 /s/ 의 F2 locus 는 ~1750 Hz 다. 자음→모음 포먼트 전이는
그 자체가 자음의 조음 위치를 알려주는 주된 단서(locus equation)라, 엉뚱한 데서
출발하면 두 소리의 인과관계가 끊긴다. → `presets.LOCUS`.

**(3) 앞공동 공진이 고정이었다.** 협착이 열리면 앞공동이 길어져 치찰음 극이
내려간다. `sib_pole_f` 를 6600 → 2500 Hz 로 활강시킨다.

### 학습으로 해결되는 문제였나

**부분적으로만.** 복사합성 경로에서는 인코더가 프레임마다 `noise_entry`,
포먼트, 진폭을 다 예측하므로 실제 /사/ 의 궤적을 흉내낼 수는 있다. 하지만

* 스크립트 경로(`score.py`)에는 학습이 관여하지 않는다 — 손으로 쓴 궤적이 전부다.
* 마찰 노이즈와 유성 진폭이 **독립 손잡이**인 한, 학습된 해는 그 음절에만 맞는
  값이고 새 음절로 일반화되지 않는다. 물리적으로는 둘 다 하나의 공기역학
  상태에서 나오는 결과다.
* 그 공기역학 상태(성문하압)를 넣으면 학습이 배워야 할 것이 훨씬 줄어든다 (§5).

## 2. 조음 속도 — 페널티가 아니라 구조로

혀는 순간이동하지 않는다. 그런데 제어 파라미터는 스크립트가 그린 꺾은선이거나
인코더가 프레임마다 자유롭게 낸 값이었다. 둘 다 **물리적으로 불가능한 조음
속도**를 허용하고, 그게 기계음의 전형적 원인이다.

Haskins 의 Task Dynamics (Saltzman & Munhall 1989) 는 각 조음 과제를
**임계감쇠 2차계**로 본다.

```
x'' + 2w x' + w²(x − target) = 0        →  h(t) = w² t e^{−wt},  ∫h = 1
t_rise(10~90%) = 3.357 / w
크기 dF 계단에 대한 최대 속도 = dF·w/e
```

목표에서 실제 궤적으로의 사상이 **선형 필터 한 번**이다. 프레임률 FFT 컨볼루션
한 번이면 되고, 미분가능하고, 인과적이며(미래를 안 본다), 무엇보다 **불가능한
속도가 표현 자체로 불가능해진다.** L2 평활처럼 모든 움직임을 같이 죽이지 않는다.

기본 상승시간 (`dsp/gestures_dynamics.RISE_TIME`):

| 조음기관 | t_rise | 담당 파라미터 |
|---|---|---|
| 성문 | 15 ms | `harmonic_amp`, `noise_am`, `aspiration` |
| 후두 | 30 ms | `f0`, `rd`, `tilt` |
| 혀끝 | 35 ms | 치찰음 파라미터, 노이즈 대역, F3 |
| 입술 / 혀몸통 | 60 ms | F2, F4 |
| 턱 | 80 ms | F1 |
| 연구개 | 100 ms | `velum_open` |

검증: 설정 60 ms → 측정 60 ms, 최대 속도 21.1 Hz/ms (이론 20.6). 문헌의 F2 전이
10~25 Hz/ms 와 일치한다. 연구개가 가장 느리다는 사실 하나에서 **비음화가 앞뒤
모음으로 번지는 현상**이 저절로 나온다.

스크립트에서 `coarticulation: false` 로 끄고, `speech_rate` 로 전체 속도를 바꾼다.
이제 `score.py` 는 전이 곡선을 그리지 않는다 — **계단 목표만 주고 곡선은 관성이
만든다.**

학습 경로에는 같은 제약을 손실로 건다(구조로 못 막는 부분).

```
articulatory_rate_loss = mean( relu(|dF/dt| − 상한) / 상한 )
상한 [Hz/s] = F1 12k, F2 30k, F3 25k, F4 12k, F5+ 8k
```

**hinge 라는 게 핵심이다.** 상한 아래의 빠른 전이는 전혀 벌하지 않는다.
측정: 동역학을 통과한 궤적 0.0000, 프레임 단위 난동 0.55.

## 3. 포먼트는 독립이 아니다

포먼트 5~12 개가 서로 독립적으로 움직이는 성도 형상은 존재하지 않는다. 성도는
(턱, 혀몸통, 혀끝, 입술) 정도의 소수 좌표로 결정되고, 포먼트는 그 결과일 뿐이다.

**Story 의 면적함수 실증 직교모드**: 화자 6명 × 모음 11개의 면적함수가
**평균 형상 + 2개 모드로 분산의 97% 이상**이 설명된다. 즉 모음 공간의 실제
자유도는 2~3 차원이다.

두 군데에 넣었다.

**(a) 구조 — 인코더** (`config.filt.formant_basis_dim`, 기본 4)

```
간격로짓 = mean + z·Bᵀ          z: (B, T, 4),  B: 학습되는 기저 (K, 4)
F_k = f_min + cumsum(softplus(간격로짓))
```

누적합이라 `F1 < F2 < …` 순서 보장은 그대로 유지되면서, 포먼트가 4차원
부분공간 안에서만 움직인다. 기저 초기값은 (전체 이동 = 성도 길이/화자 규모,
F1↔F2 대립 = 개구도, 전/후설, 나머지 난수). **0 으로 두면 예전처럼 독립이 된다.**

측정(학습 전 임의 입력): `basis_dim=0` 이면 실효 운동차원 5, `=4` 면 1.

**(b) 손실 — 스크립트/분석 경로**

```
formant_subspace_loss = 상위 n_modes 밖 특이값 에너지 비율
```

측정: 하나의 조음 좌표로 함께 움직이는 궤적 0.0000, 제각각 움직이는 궤적 0.53.

## 4. 비강 — "거의 상수인 필터 + 개도 하나" 가 맞다

비강은 근육이 없다. 부비동 포함 형상이 화자마다 고정이고 발화 중 변하지 않으므로
**전달함수가 사실상 상수**다. 변하는 건 연구개 포트의 열림뿐이다. 그래서
"화자마다 필터 하나 + 개도 하나"는 물리적으로 옳은 모델링이다.

다만 **구강 응답에 비강 응답을 더하는 것은 아니다.** 비강은 인두 분기점에
병렬 곁가지로 붙으므로, 그 입력 임피던스가 구강 쪽 전달함수 자체를 바꾼다.

1. 비강 극이 생긴다 (250~300 Hz, 화자 고정)
2. 구강 출력에 **영점**이 생긴다 (곁가지가 단락처럼 보이는 주파수)
3. **F1 이 넓어지고 약해진다** (곁가지로 에너지가 새고 비강 벽이 흡수)

비선형인가? **아니다.** 음향적으로는 선형계이고, 다만 '독립적으로 더해지지'
않을 뿐이다. 병렬 어드미턴스 합이라 정확히 계산 가능하다.

구현(`dsp/nasal.py`)은 Klatt(1980)의 방법이다. 극과 영점을 같은 주파수에 두면
정확히 상쇄되므로 **닫힌 상태에서 응답이 항등**이 된다(측정 편차 0.0000).
개도를 올리면 둘이 벌어진다: 극 270 Hz 고정, 영점 270 → 450 Hz.

측정 (개도 0 → 1, /a/ 기준):

| | 닫힘 | 개도 0.5 | 개도 1.0 |
|---|---|---|---|
| 380~600 Hz 스펙트럼 골 | 1.61 | 0.60 | 0.44 (−11 dB) |
| F1 봉우리 (650~820 Hz) | 12.8 | 5.1 | 2.3 (−15 dB) |

영점을 700 Hz 이상으로 올리면 /a/ 의 F1(730)을 통째로 지운다 — Klatt 의 450 Hz
공칭값을 지켜야 한다.

**도파관 모드에서는 근사가 필요 없다.** 분기점을 3-포트 산란 접합으로 두면
위 세 효과가 전부 저절로 나온다. 향후 작업.

## 5. 성대의 비선형 응답 — 이미 방정식 안에 있다

따로 넣을 필요가 없다. `dsp/vocalfold.py` 의 2질량 모델에는 비선형이 세 군데 있다.

1. 베르누이 압력이 면적의 **제곱**에 의존한다: `P₁ = Ps[1 − (a_min/a₁)²]`
2. 성대가 닿으면 강성이 스위치되는 **접촉(collision)** 항 — 가장 큰 비선형
3. 폐쇄 시 유량이 0 으로 잘리는 **정류**

그래서 **압력 하나만 움직여도** 사람 목소리의 비선형 특성이 따라온다.
측정 (`vocalfold.pressure_sweep`, 기본 파라미터):

| Ps [cmH₂O] | 진동 | 유량 rms | 상대 SPL |
|---|---|---|---|
| 1.0 | **없음** | 6 | — |
| 2.0 | 있음 | 29 | 0 dB |
| 4.0 | 있음 | 73 | +8.0 dB |
| 8.0 | 있음 | 158 | +14.7 dB |
| 16.0 | 있음 | 349 | +21.7 dB |

* **발성 역치압(PTP) = 1.35 cmH₂O** (이분법 측정). 이 아래에서는 아예 진동이 없다.
  말끝이 스러지는 소리, /ㅎ/ 뒤의 유성 시작, 속삭임과 발성의 경계가 전부 이
  문턱 하나다. **크로스페이드로 흉내내면 그 순간이 기계처럼 들린다.**
* 압력 2배당 약 **7 dB** (문헌 8~12 dB). 선형이 아니라 압축적이다.
* F0-압력 결합은 이 모델에서 약하다(문헌 +2~5 Hz/cmH₂O). 저차원 집중질량
  모델의 알려진 한계다.

### 빠른 학습 경로에 옮기는 법

2질량 ODE 는 파이썬 루프라 학습 본선에 못 쓴다. 대신 위 관계를 **파라미터 사이의
구속조건**으로 넣는다 (`vocalfold.pressure_to_source`).

```
amp      = 0                        (Ps ≤ PTP)
         = 10^(7·log₂(Ps/PTP)/20)   (Ps > PTP)
f0_shift = +3 Hz/cmH₂O
rd_shift = −0.06 /cmH₂O            (압력이 높을수록 pressed)
```

`harmonic_amp`, `f0`, `rd` 를 세 개의 자유로운 손잡이로 두지 않고 압력 하나에
묶는다. **이게 §2, §3 과 정확히 같은 발상이다: 자유도를 물리로 줄이는 것이 곧
정규화다.** 그리고 이 항 하나가 §1 의 /사/ 전이도 설명한다 — 협착이 열릴 때
성문하압이 성문으로 옮겨가는 것이 기식이고, 그 압력이 역치를 넘는 순간이
유성 시작이다.

## 6. 여성 성도 — 남성 값에 상수를 곱하면 안 된다

성도 길이는 남성 16.9~18 cm, 여성 14.1~14.5 cm (비율 ~0.82). 그래서 포먼트가
전체적으로 ~1.2 배 올라가지만 **균일 스케일이 아니다** — 인두가 구강보다 더 많이
짧아지므로 모음마다 배율이 다르다. 그래서 별도 표를 둔다 (`presets.VOWELS_FEMALE`,
Peterson & Barney 여성 평균 + 한국어 /ㅣ/ 실측 F1 414 / F2 2953).

`VoiceProfile.female()` 한 줄이 바꾸는 것:

| | 남성(기본) | 여성 |
|---|---|---|
| 성도 길이 | 17.5 cm | 14.1 cm |
| 포먼트 간격 c/2L | 1000 Hz | 1241 Hz |
| **포먼트 개수** | 12 | **9** |
| 도파관 단면 수 | 24 | 19 |
| F0 중앙값 | 120 Hz | 200 Hz |
| Rd / tilt | 1.1 / 0 | 1.25 / +3 dB/oct |
| 치찰음 극 | 6600 Hz | 8000 Hz |

**포먼트 개수가 성도 길이를 따라간다는 게 핵심이다.** 짧은 성도에 12 개를 억지로
끼우면 나이퀴스트 위에 극이 생겨 응답이 접힌다 (실측: 스펙트럼 무게중심이
1.3 kHz 에서 **10.5 kHz** 로 튀었다). 스크립트에서는 `voice: female` 한 줄.

### 저역에서 F0 가 포먼트보다 튀는 문제

여성 목소리에서 두드러지는 이유가 있다. F0 200 Hz 면 하모닉이 200 Hz 간격인데
/ㅣ/ 의 F1 은 410 Hz — **F1 봉우리를 짚는 하모닉이 사실상 없다.** 남성(F0 120,
F1 270)이면 H2/H3 가 F1 근처를 지나가지만, 여성은 H2 가 400 Hz 로 F1 을 스치고
지나간다. 측정한 H1−A1:

| | H1−A1 | A1 위치 |
|---|---|---|
| 남성 /a/ F0 120 | +5.5 dB | H6 |
| 여성 /a/ F0 200 | −1.3 dB | H4 |
| **여성 /i/ F0 200** | **+7.5 dB** | H2 |

세 가지가 함께 작용한다.

1. **소스 기울기.** Rd 를 올리면 H1 만 커진다(Rd 2.2 면 H1−H2 = +15 dB).
   기식성이 필요하면 Rd 를 올리되 `tilt` 로 고역을 되살려야 한다.
   측정: 여성 /a/ 기준 −1.3 dB 인데 `tilt=-6` 이면 +10.7, `tilt=+4` 면 −13.3.
   여성 프리셋이 `tilt=+3` 을 기본으로 갖는 이유다.
2. **F1 대역폭.** 넓으면 더 많은 하모닉이 F1 을 덮는다. 여성 프리셋 F1 BW 80 Hz
   (남성 60).
3. **소스-성도 상호작용** — 아래.

### 소스-성도 상호작용의 1차 효과는 구현할 수 있다

"성도 입력 임피던스가 성대 진동에 되먹임된다"는 완전한 상호작용은 시간영역
연립이 필요해서 학습 경로에 못 넣는다. 하지만 **들리는 것의 대부분은 F1 감쇠**다.
성문이 열려 있는 동안 성문하 계통이 성도에 붙어 F1 이 손실을 보고, 주기 평균하면
F1 대역폭이 개방지수에 비례해 넓어진다.

```
ΔB1 = 130 Hz × OQ(Rd)          OQ 는 LF 타이밍에서 직접 계산 (te + ta)
Rd 0.4 → OQ 0.42 → ΔB1  55 Hz
Rd 1.25 → OQ 0.75 → ΔB1  98 Hz     (문헌의 주기평균 50~100 Hz 와 일치)
Rd 2.2 → OQ 0.88 → ΔB1 115 Hz
```

느린 ODE 없이 정확히 같은 자리에 넣었다(`dsp/glottal.glottal_f1_damping`).
부수 효과로 위의 '하모닉이 F1 을 못 짚는' 문제도 완화된다.

## 7. 굽은 성도와 5 kHz 위

성도는 원통도 아니고 직선도 아니다. 그런데 **굽음 자체는 1차 문제가 아니다.**
1D 도파관에서 중요한 건 직선성이 아니라 **중심선 길이와 그 위의 단면적**이고,
MRI 면적함수는 애초에 굽은 중심선을 따라 측정한다. 굽음이 만드는 내벽/외벽 경로차는
면적함수 자체의 측정 불확실성보다 작다.

진짜 한계는 **평면파 근사가 깨지는 지점**이다. 단면 최대치수 d 에 대해
f < c/2d 까지만 유효하고, d≈3 cm 면 약 **5.8 kHz**다. 그 위에서는 횡모드가
전파하므로 1D 모델은 원리적으로 틀린다.

그 위에서 실제로 스펙트럼을 만드는 것들:

* **이상와(piriform fossa)** — 후두 출구의 곁가지. **4~5 kHz 에 스펙트럼 골**을
  만들고 아래쪽 공진들도 조금 낮춘다 (Dang & Honda 1997). 화자 고정.
* **후두강(epilarynx)** — 3 kHz 부근의 '가수 포먼트'.
* 치열·입술 방사 — 고정 해부.

전부 **혀 위치와 무관한 고정값**이다. 그래서 대응 전략이 나온다.

1. 알려진 곁가지는 화자 고정 극-영점으로 넣는다 (`piriform`, 비강과 같은 패턴).
   **반공명만 쓰면 안 된다** — DC 정규화된 반공명은 영점 위에서 이득이 계속 커져
   나이퀴스트에서 +7 dB 가 되고, /s/ 의 스펙트럼 피크를 나이퀴스트로 옮긴다
   (실측 3200 Hz → 11719 Hz). 물리적으로도 1/4 파장 곁가지는 극도 함께 갖는다.
   `filters.notch_response` 는 좁은 영점 + 넓은 극이라 홈 밖에서 응답이 1 로 돌아온다
   (측정: DC +0.7 dB, 홈 −8.6 dB, 나이퀴스트 +0.8 dB).
2. **5 kHz 위 포먼트는 프레임마다 움직이지 않게 한다** (`config.filt.formant_fixed_from`,
   기본 5). 어차피 고정 해부가 지배하는 영역이고, 움직이게 두면 모델이 잔차를
   그리로 흘려보낸다. 자유도를 줄이는 또 하나의 물리 제약이다.
3. 3D FEM/FDTD 는 미분가능한 속도로 못 돌린다. 하지 않는다.

## 8. 아직 안 된 것

1. 기식 레벨(`aspiration_peak`, 기본 0.08)은 **귀로 맞춰야 한다.** 계산으로
   고를 수 있는 값이 아니다.
2. 압력을 실제 제어 파라미터로 승격하지 않았다 — `pressure_to_source` 는
   있지만 `Controls` 에 `pressure` 필드는 아직 없다. 넣으면
   `harmonic_amp`/`f0`/`rd` 의 자유도가 줄어드는 파급이 있어서 별도 작업으로 둔다.
3. 성도-성문 상호작용(level-1 coupling)은 여전히 없다.
4. 비강의 3-포트 산란 접합(도파관 모드)은 미구현.
5. 조음 동역학의 시간상수는 문헌 추정치다. 실제 화자의 EMA/rt-MRI 로
   맞추면 화자 개성의 한 축이 된다.
