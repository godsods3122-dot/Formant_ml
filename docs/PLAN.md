# 계획서 — 물리 기반 음성 생성 모델

## 0. 가설에 대한 솔직한 평가

원래 아이디어:
> 실제 공명기 이론을 쓰면 노이즈 자체를 없앨 수 있다. 음성 생성은 물리적으로
> (성대 진동 모드 조절 가능), 치찰음·구강 노이즈, 포먼트+위상차 필터를 각각
> 학습시켜 합친다.

### 맞는 부분 (그대로 간다)

1. **"AI 특유의 잡음"의 큰 축은 위상 문제다.** 크기 스펙트럼만 맞추는 모델은
   위상이 자유롭게 흔들려 phasiness/버즈/메탈릭 음색이 남는다. 시간영역에서
   위상을 연속적으로 누적하며 합성하면 이 실패 모드는 *구조적으로* 생기지 않는다.
2. **소스/노이즈/필터를 분리하면 각 모듈의 표현공간이 좁아진다.** 신경망이
   만들 수 있는 것이 "물리 파라미터"뿐이면, 파라미터가 조금 틀려도 결과는
   여전히 '사람 소리처럼 생긴' 신호다. 실패가 잡음이 아니라 *억양/음색의 오차*로
   나타난다. 이건 매우 큰 실용적 이점이다.
3. **치찰음을 따로 다뤄야 한다는 판단도 맞다.** 신경 소스-필터 모델의 초기
   실패 사례가 정확히 "마찰음이 뭉개지거나 무음이 된다"였고, 해결책이
   하모닉/노이즈 분리 생성이었다 (Wang et al. 2019).
4. **성대를 진짜 미분방정식으로 두면 얻는 게 있다.** 지터·시머·이중음·성구 전환이
   난수 주입이 아니라 방정식의 분기(bifurcation)로 나온다. 이건 통계 모델이
   흉내내기 가장 어려운 부분이다.

### 틀렸거나 위험한 부분 (설계에 반영함)

1. **"노이즈가 없어진다"가 아니라 "노이즈의 종류가 바뀐다".**
   물리모델의 대표적 실패는 *히스/지직*이 아니라 **부저 같은(buzzy) 과도한 주기성**,
   그리고 **모델이 표현 못 하는 소리에서의 뭉개짐**이다. 즉 잡음이 사라지는 대신
   자연성 상한(ceiling)이 생긴다. → 대책: 잔차(residual) 단계를 로드맵에 넣되,
   *마지막에* 붙인다 (§4 Phase 4).
2. **"각각 학습시켜 합친다"를 문자 그대로 하면 안 된다.** 모듈을 따로 학습해
   나중에 합치면 경계에서 위상/이득 불일치가 생긴다. → **처음부터 하나의
   미분가능 그래프로 묶어 공동학습**하고, 모듈성은 *구조와 손실*로 강제한다.
3. **역문제(inverse problem)가 진짜 난관이다.** "이 소리를 낸 성대 파라미터는?"은
   해가 여러 개이고 비볼록이다. 성대 ODE를 직접 역추적하는 건 초기 단계에서
   거의 확실히 발산한다. → **LF 파형 사전을 기본 경로**로 쓰고, ODE는 시뮬레이터/
   해석/증강용으로 분리 (§2).
4. **"위상차 필터"는 별도 학습 모듈이 아니라 올패스 네트워크로 두는 게 맞다.**
   크기응답을 건드리지 않고 군지연만 바꾸는 필터가 정확히 그 역할이다.
   위상을 자유롭게 예측하게 두면 우리가 없애려던 문제가 되돌아온다.

## 1. 아키텍처

```
 텍스트/화자 (Phase 3~)          입력 음성 (Phase 1~2)
        │                              │
        ▼                              ▼
                    ┌──────────────────────────┐
                    │  제어 파라미터 인코더     │  ← 신경망은 여기까지만
                    │  (mel + F0 → 물리 파라미터)│
                    └──────────────┬───────────┘
      f0, Rd, amp │      노이즈 대역/협착위치/AM │      포먼트 F,BW,G / 면적함수
        ▼                          ▼                          ▼
 ┌───────────────┐        ┌────────────────┐        ┌──────────────────┐
 │ 성문 소스      │        │ 난류 노이즈     │        │ 성도 공명         │
 │ LF 가산합성    │───┐    │ 백색잡음 ×      │        │ (a) 포먼트 캐스케이드│
 │ (또는 2질량ODE)│   │    │ 성문동기 AM     │        │ (b) KL 도파관      │
 └───────────────┘   │    └───────┬────────┘        └──────────────────┘
                     │            │                     │        │
                     │            │   협착 하류 단만 ────┘        │ 전체 단
                     ▼            ▼                              ▼
                    [ LTV 필터 ]  [ LTV 필터 ]  →  + →  올패스(위상/군지연) → 음성
```

핵심 설계 원칙 네 가지:

1. **신경망은 파형을 만들지 않는다.** 물리모델의 손잡이만 예측한다.
2. **모든 필터는 설계상 안정하다.** 극점 반지름 `r = exp(-πB/fs) < 1`,
   도파관은 반사계수 `|k|<1`. 발산이 원천적으로 불가능하다.
3. **포먼트는 순서가 보장된다.** `F_k = F_min + cumsum(softplus(Δ))` 로
   `F1 < F2 < ...` 를 구조로 강제한다 (학습 중 포먼트가 서로 교차해 망가지는
   전형적 실패를 없앤다).
4. **노이즈는 협착 하류만 통과한다.** /s/가 고역인 이유는 앞공동이 짧기 때문이다.
   이걸 구조에 박아 두면 모델이 데이터에서 다시 배울 필요가 없다.

## 2. 성대: 두 경로를 분리한다

| | 경로 A: LF 파형 사전 (기본) | 경로 B: 2질량 자가진동 ODE |
|---|---|---|
| 미분가능 | O (Rd 보간) | 부분적 (충돌이 비미분) |
| 속도 | 빠름(가산합성, 병렬) | 느림(샘플 루프) |
| 지터/시머 | 명시적으로 넣어야 함 | 방정식에서 자동 발생 |
| 성구/이중음 | 표현 불가 | q, 비대칭 파라미터로 분기 |
| 용도 | **학습 파이프라인 본선** | 시뮬레이터 / 데이터 증강 / 해석 |

두 경로를 잇는 다리: ODE 시뮬레이션 → 유량미분 파형 → **LF Rd 값으로 회귀**.
이렇게 하면 "이 근육 상태(q, 내전, 비대칭) ↔ 이 Rd" 대응표가 생기고,
Phase 5에서 근육 좌표계로 직접 제어할 수 있게 된다.

## 3. 왜 이 구조가 잡음에 강한가 (검증 가능한 주장)

| 흔한 아티팩트 | 일반 신경 보코더 | 이 구조 |
|---|---|---|
| 위상 불일치 buzz | 위상을 예측하거나 암묵적으로 학습 | 시간영역 위상 누적 → 발생 불가 |
| 에일리어싱(고역 앨리어스) | 업샘플 레이어의 부산물 | 나이퀴스트 위 하모닉을 명시적으로 마스킹 |
| 필터 발산/폭발 | 없음(FIR) 또는 불안정 IIR | 극점 반지름 파라미터화로 항상 안정 |
| 마찰음 뭉개짐 | 하모닉 모델이 노이즈를 못 만듦 | 별도 난류 경로 |
| 프레임 경계 클릭 | OLA 불연속 | 위상 연속 + 오버랩애드 |
| **대신 새로 생기는 문제** | — | **buzzy 함, 표현 상한** → Phase 4에서 대응 |

## 4. 로드맵

### Phase 0 — 물리 엔진 (완료, 이 커밋)
- [x] LF 성문 소스(가산합성, 대역제한), Rd 보간
- [x] 포먼트 캐스케이드(Klatt DC 정규화, 항상 안정)
- [x] Kelly-Lochbaum 도파관 전달함수(래티스 재귀, 주파수축 병렬)
- [x] 협착 위치 기반 난류 노이즈 + 성문동기 AM
- [x] 올패스 위상 정형, 반공명
- [x] 2질량 자가진동 성대 모델(분기 확인)
- [x] 검증: 균일관 500/1500/2500 Hz, 포먼트 캐스케이드 목표치 ±3%
- **성공 기준(달성): 학습 없이 모음/치찰음/음절이 알아들을 수 있게 나온다.**

### Phase 1 — 복사합성 (다음 할 일)
목표: 실제 음성의 mel+F0 → 물리 파라미터 → 원음 재현.
- [ ] 데이터: 단일화자 스튜디오 녹음 1~5시간 (24 kHz). 한국어면 KSS,
      영어면 VCTK/LJSpeech. **먼저 지속모음/치찰음 몇 분으로 시작.**
- [ ] F0 추정을 YIN → CREPE/pyin 으로 교체 (F0 오차가 그대로 음질 오차가 됨)
- [ ] 손실: multi-res STFT + mel + **위상 미분(IF/GD)**
- [ ] **HNR 붕괴 대응** (§7-5 참조): 유성 구간 노이즈 억제 가중치 튜닝,
      또는 하모닉/노이즈 에너지 비를 직접 손실에 넣기
- [ ] 성공 기준: mel L1 < 0.35, 청취상 원음과 음소/억양 동일,
      마찰음이 살아 있을 것. **화자 동일성은 아직 기대하지 않는다.**

### Phase 2 — 표현력 보강
- [ ] 포먼트 캐스케이드 ↔ 도파관 모드 비교 실험 (어느 쪽이 역문제에 강한가)
- [ ] 비음(반공명), 파열음(폐쇄+파열 트랜지언트) 전용 처리
- [ ] 지터/시머를 제어 파라미터로 노출
- [ ] 성공 기준: 비음/파열음 구간의 STFT 오차가 모음 구간의 1.5배 이내

### Phase 3 — 텍스트 → 제어 파라미터 (TTS)
- [ ] 음소열 + 지속시간 → 프레임 단위 물리 파라미터 (Transformer/Conformer)
- [ ] 물리 파라미터 공간은 저차원(≈60/프레임)이라 **데이터 요구량이 크게 준다**
- [ ] 성공 기준: 학습에 없던 문장에서 MOS 3.5+ (내부 청취)

### Phase 4 — 자연성 상한 돌파
- [ ] 잔차 모델: 물리모델 출력과 원음의 차이만 학습하는 작은 신경망
      (**물리모델을 대체하지 않고 보정만**. 잔차 에너지에 페널티를 걸어
      "신경망이 다 해버리는" 붕괴를 막는다)
- [ ] 선택: 판별자(GAN) 추가 — 단, 위상 손실을 유지한 채로
- [ ] 성공 기준: 잔차 에너지 < 전체의 -20 dB 이면서 MOS 개선

### Phase 5 — 제어 인터페이스
- [ ] 근육 좌표계(q, 내전, 신장) ↔ Rd/F0 대응표 학습
- [ ] "긴장된 목소리로", "속삭이듯" 같은 지시를 물리 파라미터로 사상
- [ ] 실시간 추론 (도파관 경로는 프레임 병렬이라 유리)

## 5. 데이터

| 단계 | 필요한 것 | 규모 |
|---|---|---|
| Phase 0 | 없음 (합성만) | — |
| Phase 1 | 단일화자 깨끗한 녹음 | 10분 → 1시간 |
| Phase 2 | 음소 커버리지 있는 코퍼스 | 1~5시간 |

흡수해버린다. 초기에는 반드시 깨끗한 녹음을 쓴다.

## 6. 평가

- 객관: mel L1, multi-res STFT, **위상 IF/GD 오차**, F0 RMSE,
  포먼트 궤적 오차(Praat/formant tracker 대조), HNR
- 구조 특이 지표: **잔차 에너지 비율**(물리모델이 얼마나 설명했는가),
  노이즈/하모닉 에너지 비 (마찰음 구간에서 제대로 노이즈로 갔는가)
- 주관: MOS / 두 모델 A-B 비교. 특히 "버즈 느낌" 항목을 따로 물을 것.

## 7. 알려진 한계 (미리 적어둔다)

1. LTV-FIR 근사: 대역폭이 아주 좁은 포먼트(BW < 40 Hz)의 긴 울림은
   `ir_size` 안에 안 들어온다. 필요하면 재귀 필터 경로로 교체.
2. 2질량 ODE는 파이썬 루프라 실시간의 ~10배 느리다. 본선 학습에는 안 쓴다.
3. 면적함수 프리셋은 파라메트릭 근사다. 정밀 연구엔 MRI 측정값을 써야 한다.
4. 성도-성문 상호작용(source-tract coupling)은 아직 없다. 실제로는 성도의
   입력 임피던스가 성대 진동에 되먹임된다(특히 고음/성구 전환).
5. **관측된 문제: 초기 학습에서 HNR 이 붕괴한다.** CPU 300~600 스텝짜리
   복사합성 예비실험에서 포먼트 궤적은 잘 따라갔지만(F1 299 vs 340,
   F2 1869 vs 1975 Hz), 인코더가 **노이즈 경로로 에너지를 몰아넣어**
   HNR 이 7 dB → −6 dB 로 무너졌다. 크기 스펙트럼만 보면 노이즈로 채우는 게
   가장 빨리 손실을 줄이는 길이기 때문이다.
   현재 대응은 유성 구간 노이즈 게인 페널티(`VoiceLoss(w_noise=...)`)이고,
   이것만으로 충분한지는 아직 검증되지 않았다. Phase 1의 첫 번째 과제다.
   (참고: 위 실험은 스텝 수가 절대적으로 부족했다. 결론이 아니라 관측이다.)
