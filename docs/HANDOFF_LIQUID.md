## 0. 이 작업에서 배운 것 (다음 사람이 반복하지 말 것)

### 0.1 손으로 음절을 작곡하지 마라. 복사합성부터 하라.

이 세션의 가장 큰 낭비는 **정답이 없는 상태로 스펙트럼 지표만 맞춘 것**이다.
음절을 손으로 짜고 "포먼트 오차 3 %" 같은 숫자를 개선했는데, 사용자는
"전혀 인간의 발음이 없는 수준" 이라고 했다. 지표가 좋아지는 방향과 소리가
좋아지는 방향이 달랐고, 정답이 없으니 그걸 알 방법이 없었다.

복사합성은 정답이 원본 파형이다. 되합성이 원본처럼 안 들리면 엔진이 틀린
것이고, 어느 파라미터가 부족한지 좁혀진다. PLAN.md 의 Phase 1 이 이것이고,
그걸 건너뛰고 Phase 3(작곡)부터 한 것이 실패의 구조였다.

### 0.2 평균 지표가 결함을 **보상**할 수 있다

한때 "포락선 오차 5.2 dB" 를 성과로 보고했다. 나중에 보니 그 값은
**전이 구간의 노이즈 버스트가 고역을 메워서** 나온 것이었다. 버스트를 없애자
오차는 10 dB 로 올라갔지만 소리는 나아졌다. 평균 하나로 판정하지 마라.
최소한 **프레임간 최대 도약**과 **스펙트럼 변화율(flux)** 을 함께 봐라.

### 0.3 그림을 그려라

사용자 제안으로 `plot_compare.py` 를 만들었고, **만들자마자 원인이 보였다.**
유성도가 0 으로 떨어지는 지점과 4~7 kHz 노이즈 뭉치가 정확히 겹쳐 있었다.
숫자 하나로 요약하면 전이 구간의 짧은 사건이 평균에 묻힌다.

### 0.4 내부 상태만 보는 테스트는 소리를 보증하지 않는다

한동안 테스트 114 개가 전부 통과하는 동안 출력은 음성이 아니었다. 전부
기계의 내부(접촉 횟수, 간극, 반사계수, 노치 깊이)만 봤기 때문이다.
`tests/test_acceptance.py` 와 `tests/test_copysynth.py` 는 **파형을 재서**
판정한다. 새 기능을 넣을 때 이 두 가지 성격을 구분해서 테스트를 써라.

## 1. 지금 되는 것 — 복사합성

`scripts/copysynth.py` 가 녹음을 분석해 물리모델로 되합성한다.
경로는 **포먼트 캐스케이드**(`tract_mode="formant"`). 도파관은 방사 임피던스가
없어 이득이 기하에 끌려다니므로 이 작업에서는 쓰지 않았다(§4.1).

사용자 녹음(남성, "라 / 을라 / 아라 / 아라") 기준 측정:

| 토큰 | 포락선 오차 | 세기 상관 | 4~7 kHz (합성/원본) | 변화율 (합성/원본) |
|---|---|---|---|---|
| ra | 3.6 dB | 0.920 | −28.2 / −30.9 | 0.0327 / 0.0419 |
| eulla | 5.1 dB | 0.903 | −40.0 / −35.1 | 0.0246 / 0.0312 |
| ara | 6.0 dB | 0.897 | −37.2 / −31.6 | 0.0303 / 0.0375 |
| ara2 | 5.6 dB | 0.878 | −40.7 / −33.8 | 0.0233 / 0.0383 |

### 1.1 여기까지 오면서 고친 버그 (전부 측정으로 찾았다)

1. **유령 극 4 개.** 포먼트 추적기가 못 찾은 슬롯을 0 으로 채웠고, 합성기가
   `f_min` 으로 클램프해 **150 Hz 짜리 가짜 공명기 4 개**를 만들었다. 하나당
   −12 dB/oct 씩 붙어 고역을 40 dB 죽였다. 되합성 오차 33 dB 의 주범.
   → 빈 슬롯은 나이퀴스트 근처에 넓은 대역폭으로 둔다(무해).
2. **노이즈 주입 위치.** `noise_entry = K*0.7` 이면 노이즈가 상위 포먼트
   (5~11 kHz)만 통과해 **+33 dB/oct** 로 치솟는다. 유성 구간에 섞인 2 % 만으로
   고역 전체를 덮어 "굉장히 쨍한" 소리가 됐다. 기식은 성문에서 나므로
   `entry=0` 이 맞다.
3. **이진 유성 판정을 게이트로 씀.** 유음처럼 진폭이 잠깐 꺼지는 구간에서
   검출기가 0 을 내면 (a) 진폭이 파이고 (b) 무성으로 보고 노이즈가 125 배로
   튄다. → 연속 주기성 + 시간축 평활, 노이즈는 **고역 에너지 증거**에도
   비례하게 한다(조용한 모음 꼬리를 무성으로 오인하지 않게).
4. **포먼트 궤적 밀림.** 남은 근을 빈 슬롯에 아무렇게나 채우면 F1 이 한 프레임
   빠졌을 때 F2 가 슬롯 0 으로 들어와 저역 극이 사라지고 출력이 11 dB 튄다.
   반대로 "순서를 깨지 않을 때만" 으로 막으면 실재하는 5~7 kHz 극을 못 넣고
   죽은 극으로 대체해 고역이 20 dB 죽는다. **둘 다 겪었다.**
   → 답은 **앵커 기반 단조 정렬 + 양방향 추적**이고, 씨 프레임은
   **근이 가장 많이 잡힌 곳**으로 고른다(에너지로 고르면 그 프레임이 놓친
   극의 슬롯이 밀려 3318 Hz 가 통째로 사라졌다).
5. **소스가 어두웠다.** `tilt=0, Rd=1.2` 에서 4~7 kHz 가 원본보다 13 dB 낮았다.
   측정으로 `tilt=-12, Rd=0.6` 을 골라 오차 10.6 → 3.4 dB.
   주의: 이 레포의 `tilt` 는 값이 **클수록 어두워진다**(one_pole_tilt 는 저역통과).
6. **과평활.** `_fill` 이 모든 프레임에 3 점 중앙값을 걸어 실제 전이까지
   뭉갰다(변화율이 원본의 절반). 보간한 자리에만 걸도록 고쳤다.
7. **LPC 대역폭이 미친 듯이 요동쳤다.** F3 의 BW 가 연속 프레임에서
   849 -> 33 -> 779 -> 71 Hz 로 뛰었다. 33 Hz 는 Q=79 짜리 면도날 공명이라
   스펙트로그램에 밝은 가로줄로 찍히고(사용자가 "2500 쯤 강한 진폭" 으로 지적),
   849 Hz 프레임은 원본보다 +10.8 dB 튄다. **주파수는 믿을 만한데 대역폭만
   못 믿는다.** Fant 경험식 기준 [0.5, 2.5] 배로 묶고 프레임간 변화를 1.6 배로
   제한했다(`track._tame_bandwidths`). 프레임간 최대 비율 25.7 -> 1.6 배,
   2.4~2.8 kHz 최대 초과 +10.8 -> -1.5 dB.
   **여기서 배운 것**: 집계 지표(고역 스펙트럼 변화율)는 이걸 못 잡았다
   (합성 0.0506 vs 원본 0.0483). 맞는 지표는 **프레임간 대역폭 비율**이었다.
   증상이 국소적이면 집계 지표로는 안 보인다.

## 2. 아직 안 되는 것

- **상위 포먼트가 프레임마다 흔들린다.** 스펙트로그램에서 3 kHz 위가
  원본의 매끄러운 하모닉 줄무늬 대신 얼룩덜룩한 반점으로 보인다. 사용자가
  "혀가 움직일 때마다 기식 같은 게 통과한다" 고 한 것이 이것으로 보인다.
  노이즈 경로를 완전히 꺼도, 지터/시머를 꺼도, 포먼트를 고정해도 측정
  지표(주기성·대역에너지비·flux)로는 안 잡혔다 — **다음 사람은 지각과
  맞는 지표를 먼저 찾아라.** 후보: 상위 포먼트의 프레임간 궤적 안정성.
- IR 절단은 아니다(ir_size 512↔1024 차이 −1.2 dB). `ir_size` 는 `n_fft` 에
  묶여 1024 가 상한이다.
- **지터/시머도 아니다.** 지터가 고역 하모닉을 뭉갠다고 의심했지만(0.6 % 는
  60 번째 하모닉에서 36 % 요동), 하모닉 빗살 또렷함을 재니 **원본의 고역도
  하모닉이 안 잡힌다**(−0.2 dB). 스펙트로그램에서 원본에 가로줄이 보인 것은
  착시였다. 값은 생리적 범위(0.002/0.02)로만 낮췄다.
- 여성 목표로의 이전은 아직 안 했다. 화자 정규화 방법은 §3.2 에 적어 뒀다.

## 3. 유음(/ㄹ/) 에 대해 확정한 것

### 3.1 문헌 (원문 대조 완료, docs/RIEUL.md 에 상세)

- Lee et al.(2015) rt-MRI: **초성·종성은 설측음 지각, 모음사이는 탄음 지각.**
  탄음에는 **설체 상승이 아예 없다**(범주적 차이). "탄음 = 짧은 설측음" 구현 금지.
  단위가 픽셀 강도이고 평활창이 90 ms 라 **시간 수치는 이 논문에서 못 얻는다.**
- Cathcart(2012) 초음파: 탄음 폐쇄 **약 1/24 초(42 ms)**. 혀끝은 예외 없이
  위→아래(탄도). 굉장히 중요한 것 — **굴곡(혀 말림)은 분절이 아니라 화자의
  속성**이다(화자 A 는 120 개 중 12 개, 화자 B 는 항상). 그리고 **말림은
  F1~F3 로 거의 안 보이고 F4/F5 간격으로 봐야 한다**(Zhou et al. 2008).
- Hwang et al.(2019) 3D 초음파, **서울말 여성 5 명**: 전원 전방 폐쇄가 있으나
  위치·크기가 화자마다 크게 다르다(설첨-치음/설단-치경/설단-후치경/**권설**).
  권설이 한국어 여성 화자에게서 실제로 나오고, **모음 의존적**이다(/i/ 앞에서는
  안 나옴). **좌우 비대칭이 실재한다**(5 명 중 3 명). 그리고 결정적으로 —
  **혀몸 높이와 설근 전진은 독립 손잡이가 아니라 관상 폐쇄 위치에서 따라 나온다.**
- Ying(2026) EMA: F3 가 측면화의 1차 상관물(β=0.081). coda 에서 F3 음향 정점이
  조음 정점보다 **11.2 ms 먼저** 온다.

### 3.2 사용자 녹음에서 잰 것

화자 정규화는 **본인 모음을 기준으로** 한다 — 본인 /아/(761/1222/2492)와
목표 여성 /아/(850/1220/2810)의 포먼트별 비(1.117/0.998/1.128). 단일 상수보다 낫다.

- **어두 설측음과 모음사이 탄음이 실제로 다르다: F2 1459 vs 1100 Hz.**
  Lee(2015)의 위치별 이음과 방향이 맞는다.
- 유음 포락선에 **극-영점 쌍**이 뚜렷하다: F1 330, F2 1400, **영점 ~2100**,
  극 2800, **영점 ~3800**, 극 4600. 2800 봉우리가 도드라지는 것은 양옆의 골
  때문이고, **전극(all-pole) 모델로는 원리상 못 낸다.**
  영점이 함의하는 측지 길이 1.8~3.8 cm 는 Stevens(1998)의 2~4 cm 안이다.
- 세기: 설측음은 뒤 모음보다 **5~6 dB 낮고**, 탄음은 **5~8 dB 짜리 짧은 골**
  (20~40 ms)이다. 무음이 아니다 — 폐쇄가 짧아 압력이 안 쌓여 발성이 이어진다.

### 3.3 혀끝 물리모델 (`dsp/tongue.py`)

혀끝을 유동유발 진동자로 두면 **조음 방식이 파라미터가 아니라 결과**가 된다.
목표 간극 h0(t) 와 구강압 Po 두 물리량이 접근음/탄음/전동음을 가른다.

- 질량 **1 개는 절대 안 떤다**(위상차가 없어 기류에서 순 에너지를 못 받는다).
- **2 개는 48 Hz 로 뜬다** — 파동이 생길 만큼 결합을 풀면 고차 모드로 뛰고,
  조이면 진동수는 맞지만 파동이 사라진다. **3 개부터** 28 Hz 로 안정.
- **균일한 사슬은 몇 개를 쌓아도 안 떤다.** 앞뒤 물성 기울기(앞으로 갈수록
  얇고 무름)가 있어야 협착이 이동한다. 질량 수가 아니라 비대칭이 관건이다.
- 예측: 접촉이 **후단에서 전단으로** 진행한다(주기의 14 %). Cathcart 의
  back-to-front 관찰과 방향이 같다.

**주의**: 이 모듈은 검증되었으나 아직 소리를 내는 경로에 연결되어 있지 않다.
`liquid.py` / `scripts/gen_liquid.py` 가 그 시도였고 §0.1 의 이유로 보류했다.

## 4. 알려진 함정

### 4.1 도파관(`tract_mode="waveguide"`)에는 방사 임피던스가 없다

입술이 좁을수록 Q 가 올라가 출력이 **커진다**. 실제 물리는 반대다.
측정: 유음 자세가 /아/ 보다 4.0~8.1 dB 크다. 그래서 폐쇄에 감쇠를 넣어도
부호가 뒤집혀 자음이 모음보다 크게 들린다. 주파수축 정규화를 두 번 시도했고
(균등 RMS, 1/f 가중) 둘 다 실패했다 — 소스 하모닉과 낮은 F1 의 정렬 효과라
정적 정규화로는 못 잡는다. 임시 대응은 `presets.POSTURE_GAIN_20`(자세별로
표준 소스로 렌더해 잰 역수)이고, **근본 해결은 방사 임피던스**다.

### 4.2 실측 포먼트에 맞춰 푼 면적함수 위에 영점을 또 얹지 마라

자세 면적함수는 그 자세의 협착을 이미 담고 있다. 그 위에
(1) 혀끝 폐쇄를 곱하면 316/1412/2795 → 222/676/1470,
(2) 이론 측지 영점을 걸면 → 294/578/1227 로 무너진다. **둘 다 겪었다.**
영점이 필요하면 `areafit.fit_area_with_zeros` 로 **함께** 풀어라.

### 4.3 `tilt` 의 부호

`one_pole_tilt` 는 저역통과다. **값이 클수록 어두워진다.** 그리고 경로마다
필요한 값이 다르다(도파관에서는 +7, 포먼트 캐스케이드에서는 −12).

### 4.4 포먼트 추적기의 한계 (합성 결함이 아니다)

- /u/ 는 F1 357 / F2 914 가 가까운데 F0 가 200 Hz 라 LPC 가 둘을 못 나누고
