# 이론 노트 — 구현된 방정식

기호: `fs` 샘플레이트, `T0 = 1/F0` 기본주기, `z⁻¹` 한 샘플 지연.

## 1. 성문 소스: LF (Liljencrants-Fant) 모델

유량미분 `E(t) = dU_g/dt` 를 두 구간으로 정의한다.

```
개방기  0 ≤ t ≤ te :   E(t) = E0 · e^{αt} · sin(ω_g t),      ω_g = π/tp
복귀기  te < t ≤ tc :   E(t) = −(Ee / (ε·ta)) · [ e^{−ε(t−te)} − e^{−ε(tc−te)} ]
```

Fant 의 **Rd** 한 개로 형상을 요약한다 (`Rd` 작음 = pressed, 큼 = breathy):

```
Ra = (−1 + 4.8·Rd)/100
Rk = (22.4 + 11.8·Rd)/100
Rg = (Rk/4)·(0.5 + 1.2·Rk) / (0.11·Rd − Ra·(0.5 + 1.2·Rk))
tp = 1/(2·Rg),   te = tp·(1+Rk),   ta = Ra,   tc = 1
```

두 개의 제약으로 `ε`, `α` 가 결정된다.

```
(i)  ε·ta = 1 − e^{−ε(tc−te)}                     → 고정점 반복
(ii) ∫₀^{tc} E(t) dt = 0  (유량이 다시 0으로 닫힘) → α 에 대해 이분법
```

구현: `dsp/glottal.py::_lf_waveform`. Rd 그리드에서 파형을 미리 만들고 FFT 해
**하모닉 복소계수**로 저장한다. 학습 시에는 인접 두 테이블 계수를 선형보간하므로
Rd 에 대해 미분가능하다.

### 대역제한 가산합성

웨이브테이블을 그냥 재생하면 에일리어싱이 생긴다. 대신

```
x(t) = Σ_k 2·|c_k|·m_k·cos(k·φ(t) + arg c_k),   φ(t) = Σ_n 2π f0(n)/fs
m_k = σ((0.95·fs/2 − k·f0)/(0.02·fs/2))          ← 나이퀴스트 부근 소프트 마스킹
```

`φ` 를 **샘플 단위로 누적**하므로 프레임 경계에서 위상 불연속이 없다.
이것이 "합성 잡음이 안 생기는" 첫 번째 이유다.

## 2. 성대 자가진동: 비대칭 2질량 모델

```
m₁ ẍ₁ = −c₁ẋ₁ − k₁x₁ − k_c(x₁−x₂) − Θ(−a₁)·k_col·a₁/(2L) + L·d₁·P₁
m₂ ẍ₂ = −c₂ẋ₂ − k₂x₂ − k_c(x₂−x₁) − Θ(−a₂)·k_col·a₂/(2L) + L·d₂·P₂
a_i = a_{0i} + 2L·x_i,   a_min = min(a₁,a₂)
P₁  = Ps·[1 − Θ(a_min)·(a_min/a₁)²]·Θ(a₁),   P₂ = 0        (베르누이)
U   = a_min⁺ · √(2Ps/ρ)
```

- 긴장도 `q`: `k_i ← q·k_i`, `m_i ← m_i/q` → `F0 ∝ q` (구현에서 확인: q=1→167 Hz, q=2→320 Hz)
- 비대칭 `asym`: 한쪽 성대 강성만 스케일 → 1:1 모드락이 깨지며 서브하모닉/이중음
- 적분: semi-implicit(symplectic) Euler, 4배 오버샘플

구현: `dsp/vocalfold.py`. **충돌항이 비미분**이라 학습 본선에는 쓰지 않는다
(PINN 계열은 이 지점을 미분가능 근사로 우회한다 — arXiv:2511.00428).

## 3. 성도 (a) 포먼트 캐스케이드

Klatt(1980) 관례. 극점 반지름과 각도:

```
r = e^{−π·BW/fs},   θ = 2π·F/fs
D(z) = 1 − 2r cosθ·z⁻¹ + r²·z⁻²
H(z) = D(1)/D(z) = (1 − 2r cosθ + r²)/D(z)        ← DC 이득 = 1
```

**DC 정규화가 중요하다.** 피크 이득 1로 정규화하면 각 단이 대역통과가 되어
캐스케이드 전체가 0으로 죽는다(실제로 구현 중 겪은 버그). `r<1` 이 항상
성립하므로 필터는 설계상 안정하다.

반공명(비음/마찰음의 골): `H(z) = D(z)/D(1)`.

## 4. 성도 (b) Kelly-Lochbaum 도파관

길이 `Δ = c/(2fs)` 인 원통관 N개. `fs=24 kHz, c=350 m/s` 면 `Δ=0.729 cm`,
성도 17.5 cm → **N=24**. 반사계수와 래티스 스텝업 재귀:

```
k_m = (A_m − A_{m+1})/(A_m + A_{m+1}),        k_N = 입술 종단(≈0.9)
A₀(z) = 1
A_m(z) = A_{m−1}(z) + k_m·z^{−m}·A_{m−1}(1/z)
H(ω) = g / A_N(e^{jω})
```

- 시간영역 산란 루프가 없으므로 **주파수축 병렬**, 학습에 적합하다.
- `|k_m| < 1` (면적이 양수면 자동) ⇒ `A_N(z)` 최소위상 ⇒ **항상 안정**.
- 손실(대역폭): `a_j ← a_j·ρ^j` 로 극점 반지름을 ρ배 축소.
- 배열 규약: `area[..., 0]`=성문, `[..., -1]`=입술 (내부에서 뒤집어 재귀).

검증: 균일관 → 498/1500/2502 Hz (이론 500/1500/2500), /a/형 → F1 상승,
/i/·/u/형 → F1 하강.

## 5. 난류 노이즈

```
n(t) = w(t)·[(1−d) + 2d·sin²(π·frac(φ/2π)/0.6)]      ← 성문 개방기 동기 AM
y_n  = LTV_filter(n, H_bands · Π_{i≥c}(성도 단_i))
```

- `d`(am_depth): 기식성. Klatt & Klatt(1990) — 이 변조가 없으면 하모닉과
  노이즈가 "두 개의 층"으로 분리되어 들린다.
- `c`(noise_entry): 협착 위치. 노이즈는 **협착 하류(앞공동)만** 통과한다.
  소프트 게이트 `w_i = σ((i − c)/0.7)`, 단 응답은 `(1−w_i) + w_i·H_i` 로 보간
  (복소 로그의 분지 문제를 피한다).

## 6. 위상 정형 (올패스) 과 위상 손실

2차 올패스는 크기응답이 정확히 1이고 군지연만 바꾼다:

```
H_ap(z) = (r² − 2r cosθ·z⁻¹ + z⁻²) / (1 − 2r cosθ·z⁻¹ + r²·z⁻²),  |H_ap| ≡ 1
```

위상은 순환량이므로 손실은 **미분량**에 걸고 anti-wrapping 을 적용한다:

```
⟨x⟩ = x − 2π·round(x/2π)
L_IF = E[ |⟨Δ_t∠X − Δ_t∠Y⟩| · w ]        (순시주파수)
L_GD = E[ |⟨Δ_f∠X − Δ_f∠Y⟩| · w ]        (군지연)
w    = |Y| / max|Y|                        (작은 성분의 위상은 무의미)
```

## 7. 시변(LTV) 필터 적용

```
프레임별 복소응답 H_t(ω) → irfft → ir_size/2 만큼 회전 + 해닝 창 → 유한 IR
x 를 hop 길이 비중첩 프레임으로 분할 → 각 프레임을 해당 IR 과 FFT 컨볼루션
→ overlap-add → ir_size/2 지연 보정
```

`H ≡ 1` 일 때 출력 = 입력 (오차 7e-7) 로 검증. 재귀가 없어 길이에 대해 병렬이다.
한계: `BW < 40 Hz` 처럼 울림이 `ir_size` 보다 길면 근사 오차가 생긴다.
