# 2D 혀 모델 — 설계와 검증 계획

> 이 문서는 **구현보다 먼저** 쓴다. 지난 시도가 실패한 방식이 "만들고 나서
> 상수를 맞추는 것" 이었기 때문이다. 여기서 정한 지표와 게이트를 구현 도중에
> 바꾸지 않는다. 바꿔야 한다면 **왜 바꾸는지를 먼저 이 문서에 적는다.**

## 0. 이전 실수 — 반복 금지 목록

앞선 세션에서 실제로 저지른 것들이다. 각 항목에 **어떻게 막을지**를 붙였다.

| # | 실수 | 무슨 일이 있었나 | 이번에 막는 법 |
|---|---|---|---|
| 1 | 결함 위에서 상수를 골랐다 | `tilt`/`Rd` 를 **네 번** 골랐고 앞의 셋이 전부 무효였다. 매번 그 아래 단(시변 필터 / 가짜 극)에 결함이 있었고, 상수가 그 결함을 보상하도록 자기를 맞췄다 | **게이트 통과 전에는 어떤 상수도 고르지 않는다**(§2). 상수를 고르면 고른 **조건**을 코드 주석에 같이 적는다 |
| 2 | 지표를 섞어 썼다 | 총에너지 정규화 대역비 / 프레임평균 뺀 포락선 모양 / 절대 대역 레벨이 서로 다른 답을 냈고, 그때그때 유리한 것을 봤다 | **판정 지표를 §3 에 미리 고정**한다. 진단 지표와 판정 지표를 구분해서 부른다 |
| 3 | 짧은 발췌로만 쟀다 | 토큰 4 개(각 0.5~0.9 초)로 튜닝해서 **무음 구간의 결함을 통째로 못 봤다**. 사용자가 듣고서야 드러났다 | 모든 판정은 **무음을 포함한 전체 발화**로 한다 |
| 4 | 집계 지표가 국소 결함을 가렸다 | 평균 오차가 좋아지는 동안 8 kHz 에 가짜 공명이 자라고 있었다 | 판정에 **최대 오차와 대역별 분포**를 항상 같이 낸다 |
| 5 | 건강하지 않은 baseline 에서 절제 실험을 했다 | 모든 ablation 을 `tilt=-12` 에서 해서 인과 순서를 거꾸로 보고했다(필터가 1 차 원인이라고 했는데 실제로는 tilt 가 1 차였다) | ablation 은 **다른 축이 전부 검증된 뒤에만** 한다 |
| 6 | 파워만 보고 질감을 못 봤다 | 대역 파워가 맞는데도 "저질 TTS" 로 들렸다. 원본은 노이즈 안개, 합성은 성긴 하모닉 빗살이었다 | **빗살 깊이**를 판정 지표에 포함한다(§3) |
| 7 | 소리를 안 듣고 지표만 봤다 | 세 라운드의 결함이 전부 청취로 드러났다 | 각 단계마다 `make_listening_set` 로 A-B 세트를 낸다. **지표가 좋아도 안 들어봤으면 통과가 아니다** |
| 8 | 재현되지 않는 분석기 위에서 측정했다 | 포먼트 추적기가 전역 씨 프레임 + 양방향이라 분석 구간 길이에 결과가 딸려 왔다. 같은 소리를 0.5 초로 자르느냐 5.8 초 안에서 보느냐로 답이 달랐다 | 분석기를 판정에 쓰기 전에 **재현성부터 검증**한다(§3.3) |
| 9 | 손으로 작곡했다 (이전 세션, §0.1) | 정답이 없어서 "지표는 맞는데 사람 소리가 아닌" 상태를 못 벗어났다 | 2D 혀도 **역추정(analysis-by-synthesis)** 으로 녹음에 맞춘다. 정답은 항상 원본 파형이다(§4) |

## 1. 왜 2D 혀인가 — 문헌이 요구한다

Hwang, Charles & Lulich (2019), 서울말 여성 5 명 3D 초음파:

> "혀몸 위치와 설근 전진은 대체로 **관상 폐쇄의 위치에 의해 결정된다.**"

즉 **TB(설체 상승)·TR(설근 전진)은 자유 파라미터가 아니다.** 혀끝을 어디에
어떻게 대느냐에서 따라 나온다. 치음 폐쇄는 혀 전체가 앞으로 나가야 하고,
권설 폐쇄도 혀몸이 앞으로 가야 혀끝이 말릴 수 있다 — 그래서 혀몸이 다른
위치만큼 올라갈 수 없다.

1D 모델(지금의 `dsp/tongue.py`, 혀끝 질량사슬)은 이 구속을 **표현할 수 없다.**
혀끝만 있고 혀몸이 없으니, TB·TR 을 넣으려면 별도 손잡이로 넣어야 하고 그러면
문헌이 아니라고 한 것을 그대로 하게 된다.

**2D 혀는 이 구속을 공짜로 준다** — 혀가 하나의 연결된 비압축성 몸이면,
혀끝을 움직이는 것이 나머지를 끌고 간다. 그게 Hwang 이 관찰한 것이다.

부수적으로 얻는 것:
- Cathcart(2012)의 **굴곡(flexion)** 이 자세가 아니라 형상으로 표현된다.
  "말림은 F1~F3 로 거의 안 보이고 F4/F5 간격으로 봐야 한다"(Zhou 2008)는
  2D 형상이 앞공동 길이를 바꿔야 나오는 결과다.
- 탄음의 **탄도 운동**(위→아래, Ladefoged)이 목표 위치가 아니라 초기속도로
  들어간다.

## 2. 게이트 0 — 방사 임피던스 (**측정 완료, 미해결이면 착수 금지**)

2D 혀의 산출물은 **면적함수**다. 면적함수가 소리가 되는 경로가 틀려 있으면
혀 모델이 아무리 맞아도 소리가 틀리고, 그러면 실수 #1 을 그대로 반복한다.

현행 `dsp/tract.py` 는 입술 반사를 **실수 상수 0.9** 로 둔다. 측정:

| 입술 면적 [cm²] | 현행 도파관 출력 | 전달행렬 + 방사 임피던스 |
|---|---|---|
| 1.00 | +2.7 dB | −2.8 dB |
| 0.10 | **+10.0 dB** | **−14.6 dB** |
| 0.05 | **+13.1 dB** | **−19.4 dB** |

**입술을 좁힐수록 출력이 커진다.** 실제 물리는 반대다(닫으면 0 으로 간다).
협착이 곧 자음이므로, 이 상태에서는 자음이 모음보다 크게 나온다. 지금 코드가
`presets.POSTURE_GAIN_20`(자세별 출력 역수)으로 덧대고 있는 것이 이것이다.

**해결**: Levinson 스텝업(실수 반사만 받는다)을 버리고 **전달행렬(TMM)** 로
간다. 주파수마다 2×2 행렬을 곱하고 끝단에 복소 방사 임피던스를 건다.
검증(프로토타입 완료):
- 균일관 17.5 cm → 505 / 1520 / 2528 Hz (고전값 500/1500/2500)
- 방사 임피던스를 켜면 481 / 1448 / 2420 — 끝단 보정만큼 내려간다(맞는 방향)
- 입술을 좁히면 출력이 **단조 감소** (3.0 → 0.02 cm² 에서 −26.4 dB)

**이 게이트를 통과하기 전에는 2D 혀의 어떤 상수도 고르지 않는다.**

### 2.1 G0 결과 (2026-09-06) — **통과**

`src/formant_ml/dsp/tmm.py`, 검사 9 개 `tests/test_tmm.py`.
**검사에 자유 파라미터가 하나도 없다** — 고전 결과와 해석해로만 판정한다.

| 검사 | 결과 |
|---|---|
| 방사 임피던스 vs 정확식(Bessel J1 / Struve H1) | 최대 오차 1.5e-6 (24 항 정급수) |
| 균일관 17.5 cm, 이상 개방 | **498 / 1500 / 2502 / 3498 Hz** (고전값 대비 0.4 % 이내) |
| 입술 폐쇄 -> 반파장 계열 | 1052 / 2106 / 3158, 유효길이 16.625 cm 의 n·c/2L 과 0.2 % 이내 |
| 입술 좁히기 | 3.0 -> 0.02 cm² 에서 **−24.5 dB 단조 감소** (예전 도파관은 +19.1 dB) |
| 섭동 이론 부호 | 압력 배 협착 F1 +15 Hz, 유속 배 협착 F1 −56 Hz (부호 맞음) |
| 헬름홀츠 공진 | 끝보정한 해석해와 15 % 이내, 항상 낮은 쪽(끝보정 방향 맞음) |
| 포먼트 대역폭 | **47 / 41 / 76 Hz** (Fant 실측 F1 40~90, F3 70~140) — 튜닝 없이 |
| 벽 진동이 함의하는 벽 공진 | **214 Hz** (문헌 180~200) |
| 면적함수에 대한 미분가능성 | 기울기 유한, 0 아님 |

기존 테스트 125 개 회귀 없음 (전체 134 passed).

**이 과정에서 실제로 세 번 틀렸고, 셋 다 모델이 아니라 검사 쪽이었다.**
같은 함정을 다시 밟지 않도록 적어 둔다:

1. `formant_peaks` 가 **크기 상위** n 개를 골랐다. 무손실 관은 모든 첨두가 다
   커서 어느 것이 뽑힐지가 수치오차로 정해진다 — 500/1500/2500 대신
   1500/4500/7500 이 나왔다. 포먼트는 정의상 **낮은 쪽부터**다.
   (`tract.formants_from_response` 도 같은 문제를 갖고 있다.)
2. 입술을 `radiate=False` 로 닫으려 했다. 그건 Z_r=0, 즉 P=0 이라 여전히
   **열린** 끝이다. 폐쇄를 만드는 것은 방사 임피던스다.
3. 마지막 2 단을 막고 1000 Hz 를 기대했다. 막은 만큼 관이 짧아지므로
   1053 Hz 가 맞다. 모델이 5 % 틀린 것처럼 보였는데 틀린 건 기대 쪽이었다.

그리고 **진짜 버그가 하나 있었다**: f=0 에서 파수 k=0 이라 벽 손실의
`sqrt(k²)` 미분이 발산해서 **기울기 전체가 NaN** 이었다. 역추정(G3)에 쓸
것이므로 치명적이다. DC 를 1e-3 Hz 로 밀어 해결했다(방사 미분 jω 가 DC 를
어차피 0 으로 만들므로 무해하다).

## 3. 판정 지표 — 구현 전에 고정한다

### 3.1 판정 (이걸로만 합격/불합격을 정한다)

1. **라우드니스 맞춘 절대 대역 레벨** — 발화 구간 RMS 를 맞춘 뒤 대역별
   절대 레벨의 원본 대비 오차. 대역: 0.1–1 / 1–2.5 / 2.5–4 / 4–7 / 7–9.5 /
   9.5–12 kHz. **평균과 최댓값을 함께** 낸다(실수 #4).
2. **빗살 깊이** — 대역 안 (파워 평균 − 로그 평균) [dB]. 노이즈면 약 2.5,
   성긴 하모닉 빗살이면 크다. 파워가 맞아도 사람 소리가 아닌 것을 잡는다.
3. **청취** — `make_listening_set` 의 A-B 세트. 지표가 좋아도 안 들어봤으면
   통과가 아니다(실수 #7).

### 3.2 진단 (원인 좁히기용. 합격 판정에 쓰지 않는다)

- 총에너지 정규화 대역비 — 한 대역이 뜨면 나머지가 낮아 보인다
- 프레임평균 뺀 포락선 모양 — 대역 전체가 뜨는 것을 못 본다
- 고역 포락선의 프레임간 |Δ| — 시간축 불연속('토막')

### 3.3 분석기 재현성 (판정에 쓰기 전에 통과해야 한다)

포먼트 추적기를 판정에 쓰려면 먼저:
- 같은 구간을 **전체 발화 안에서** 본 결과와 **잘라내서** 본 결과가 일치하는가
- 허용: 상위 포먼트 중앙값 차이 < 5 %

통과 못 하면 그 추적기는 **진단 전용**이고, 판정은 §3.1 로만 한다.

## 4. 2D 혀 — 설계

### 4.1 좌표계

중시상면(mid-sagittal). 성문에서 입술까지의 중심선을 따라 **반극(semi-polar)
격자**를 놓는다(Maeda/Mermelstein 관례). 격자선마다 혀 표면과 구개/인두벽
사이의 거리 d 를 재고, 면적으로 환산한다:

    A = alpha * d^beta      (Heinz & Stevens; 부위마다 alpha, beta 가 다르다)

이 환산 상수는 **문헌값으로 고정**하고 튜닝하지 않는다(실수 #1).

### 4.2 혀의 표현 — 구속 우선, 근육은 나중

혀를 **비압축성 2D 몸**으로 둔다. 노드 격자 + 스프링 + **면적(부피) 보존
구속**. 근육 모델을 먼저 넣지 않는다 — 파라미터가 폭발하고 검증할 데이터가
없다(실수 #1 의 조건).

핵심은 이것 하나다:

> 혀는 물이 든 주머니다. 혀끝을 앞으로/위로 밀면 **나머지가 반드시 물러난다.**

이 구속만으로 Hwang 의 관찰(TB·TR 이 폐쇄 위치에서 따라 나온다)이 재현되어야
한다. **재현되지 않으면 구속이 틀린 것이고, 그때 근육을 논한다.**

제어 입력은 최소로 시작한다:
- 턱 개폐 (jaw)
- 혀끝 목표 위치 (x, y) — 기존 `tongue.py` 의 유동유발 진동자가 여기 붙는다
- 혀몸 전후 (앞뒤로 미는 힘 하나)

세 개로 시작해서, **부족한 것이 측정으로 드러날 때만** 늘린다.

### 4.3 측면 통로는 2D 가 아니다

설측음의 측면 통로는 중시상면에 **없다**(그게 측면이라는 뜻이다).
2D 모델은 정중선 폐쇄까지만 내고, 측면 통로는 지금처럼 **측지(side branch)의
극-영점**으로 붙인다. Zhang & Espy-Wilson(2004): 비대칭 측면 개구가
2~5 kHz 에 영점. 한국어 여성 화자 5 명 중 3 명이 비대칭(Hwang 2019).

## 5. 순서 (게이트마다 통과해야 다음으로 간다)

| 단계 | 산출물 | 통과 조건 |
|---|---|---|
| **G0** | 전달행렬 성도 + 방사 임피던스 | 균일관 500/1500/2500 ±3 %, 입술 좁힐수록 출력 **감소**, 기존 테스트 회귀 없음 |
| **G1** | 분석기 재현성 (§3.3) | 통과하면 판정에 쓰고, 실패하면 진단 전용으로 격리 |
| **G2** | 2D 혀 → 면적함수 | 모음 자세가 문헌 포먼트 범위 안(±10 %), **혀끝을 움직이면 TB·TR 이 따라 움직인다**(Hwang 구속) |
| **G3** | 역추정: 녹음에 맞춘 혀 궤적 | §3.1 판정 지표. 정답은 원본 파형이다(실수 #9) |
| **G4** | 유음 4 토큰 | §3.1 + 청취 |

**각 게이트에서 측정값을 이 문서에 적는다.** 통과 못 하면 다음으로 안 간다.
