# 로컬 적합 결과 (2026-09-10 ~ 09-11)

`godsods3122-dot/Formant_ml` 의 복사합성 적합 산출물이다. 코드는 `main` / 
`claude/voice-parametrization-engine-fit-jscklg` 브랜치에 있고, 측정은
`docs/MEASUREMENTS.md` §46~§48, 판단은 `docs/HANDOFF.md` §14 에 있다.

파일은 태그마다 두 음원씩 있다.

* `yang_00000040` = **"방이 오층인데?"** — 치찰 사건이 `ㅊ`(층) 하나
* `yang_00000101` = **"집이 다들 좋으신데?"** — `ㅈ`·`ㅈ`·`ㅅ` 셋

각 태그 폴더 안:

| 파일 | 무엇 |
|---|---|
| `s040_target.wav` | 잡음 제거를 거친 **목표** (적합이 맞추려는 신호) |
| `s040_fit.wav` | **합성** 결과 — 이것을 목표와 번갈아 들으면 된다 |
| `s040_track.npz` | 적합된 물리 제어열 (이것이 학습 데이터가 된다) |
| `s040_report.json` | 포락·정밀·시간평균 스펙트럼 일치율, 손실, 움직인 파라미터 |
| `s040.log` | 단계별 진행 로그 (어디서 꺾였다 회복했는지 보인다) |

## 태그가 무엇인가

엔진은 `c8a3531` 로 되돌린 상태다 (고차 극이 균일관 고정 위치). 손실 항의
기본값은 `--corr 2 --hnr 2` 이고 나머지는 0 이다.

| 태그 | 설정 | 한 줄 |
|---|---|---|
| `L0` | `--corr 0 --hnr 0` | 기준선 재현. s040 은 `out/fix`(92.44)를 재현하고 s101 은 위상 단계가 회복을 못 끝내 3.7 점 낮다 |
| `L3` | (기본값) | `--corr 2 --hnr 2`. §4.1 의 세 조건을 두 파일 모두에서 통과한 유일한 설정 |
| `L4` | `--corr 5 --hnr 5` | 세기 5.0 은 과하다 — s101 에서 끊김이 안 줄고 고역이 −7.6/−10.1 dB |
| `L5` | `--subf0 3.0` | F0 **아래**는 확실히 지우는데 F0 **자체**가 늘어난다 (마찰음 속 주기성 최악) |
| `L6` | (기본값) + **고역 손잡이 켜짐** | `log_extra_bw`·`log_front_bw` 를 옵티마이저에 넣은 뒤. **지금의 기준선** |
| `L7` | `--motion` (생 이중적분) | **반증된 형태.** 점수는 무너졌지만 청취로는 "소리가 안 끊기고 치찰음이 만족스럽다" 는 평을 받았다 |
| `L8` | `--motion` (B-스플라인 다중 해상도) | 제어열 60 Hz 위 에너지 최대 75 % → **3 %**, 지글거림 목표의 7.2 배 → **1.9 배** |
| `L9` | `--motion --motion-single` | 층 쌓기의 대조군 (단층) |
| `_ladder_20260910/` | 혼합 사다리 판(커밋 `8c3b951`, 지금은 보류)에서 돌린 여섯 태그 | `lad`/`ph800`/`ph800lr`/`sub1`/`sharp1`/`cont1` |

## 들을 때

먼저 `L6` 과 `L8` 의 `_fit.wav` 를 `_target.wav` 와 번갈아 들어 보라.
`L8` 이 **지글거림이 적고** `L6` 이 **스펙트럼 점수가 높다** — 그 맞바꿈이 지금의
쟁점이다. 자 셋이 다 좋다고 해도 소리가 나쁘면 자가 틀린 것이다.
