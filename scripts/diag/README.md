# 진단 스크립트 — `docs/BOTTLENECK.md` 의 표를 만드는 것들

전부 `PYTHONPATH` 없이 저장소 뿌리에서 `python scripts/diag/<이름>.py <스템> ...` 로 돈다.
스템은 `out/M/M14/s101` 처럼 `_target.wav`·`_fit.wav`·`_track.npz` 앞부분이다.

| 스크립트 | 무엇을 답하는가 |
|---|---|
| `ceiling.py` | **이 지표의 천장**. 잡음의 실현이 다르면 완벽한 모형도 몇 점인가 |
| `roi.py` | **어디를 고치면 몇 점인가**. 한 부분만 목표로 갈아 끼우고 env 재계산 |
| `where.py` | 남은 오차를 구간(유성·마찰·무음)과 대역으로 쪼갠다 |
| `harm.py` | 배음 차수별 진폭·주파수 오차 |
| `harmctl.py` | 위 오차가 **실현 잡음인지** 대조군으로 가른다 |
| `slope.py` | 배음 오차가 **포먼트 자리** 탓인지 (국소 기울기와의 상관) |
| `physcheck.py` | 극이 물리와 맞는가 — 관 길이·대역폭·극 간격·개수 |
| `bwsrc.py` | 대역폭 과대가 **분석기** 탓인지 **적합기** 탓인지 |
| `harmcoh.py` | **배음 사이 상관** — 갈라짐의 자 (목표 0.606) |
| `hcoh_vs_ruler.py` | `--hcoh` 손실 항이 **실제 녹음에서** 자와 같은 값·순서를 내는지 (§52.382) |
| `discrim.py` | **어느 대역에서 목표와 합성이 구별되는가** — 대역별 판별 AUC, 창 길이를 바꿔 확대한다 (§52.384) |
| `bandphase.py` | 대역 안 위상이 틀렸는가(`rmax`) 시각이 밀렸는가(`r0`·지연) (§52.384) |
| `cycleshape.py` | **성문 주기를 접어 본 펄스 응답** — 잠김·모양·울림 시각의 흔들림. 흐릿함의 자 (§52.384) |
| `lockcorpus.py` | 위 두 값을 코퍼스 220 개에서 내 **화자의 상수**로 만든다 |
| `ringdecay.py` | **울림이 주기 안에서 사그라드는 기울기** = 공진의 유효 대역폭. 목표 4.5-6k 273 Hz, 우리 38~182 Hz (§52.385) |
| `hfinterharm.py` | 고역 **배음 자리 대 배음 사이**(HIR) — §52.236 |
| `hcorrshape.py` | 주기별 배음 보정의 **모양** — 크기와 무관한 배음 축 틈 비율·에너지 분포 |
| `tone404.py` | 목표가 조용해지는 자리에 남는 **순음** (대역·창은 인자로 바꾼다) |
| `f3prom.py` | 감사의 **F3 돌출 얕은 창**을 셋으로 가른다 — 봉우리가 낮은가·골이 메워졌는가·자리가 어긋났는가 |
| `mktrack.py` | 제어열을 손으로 고친 사본을 만든다 (`--init … --no-fit` 재렌더 A/B 용) |

**새 자는 정답을 아는 입력으로 눈금을 맞춘 뒤에만 결론에 쓴다.** 봉우리 모양을 배음 표본으로
재려던 `poleshape2.py` 가 그러지 않아서 네 번 결론을 뒤집었고, 정답 200 Hz 극을 칸마다
26~2354 Hz 로 내놓아 **무효로 판명돼 삭제했다** (§52.379). 기존 자(`audit.py` 의 항목,
보고서의 포락·정밀, `harmcoh.py`)로 답할 수 있는 질문이면 새 자를 만들지 않는다.

**청취 결함이 먼저다.** 사용자가 보고한 결함에는 대개 이미 전용 자가 있다 — 갈라짐은
`harmcoh.py`(배음 사이 상관, 목표 0.606)다. 감사표의 남은 ✗ 를 지우는 일은 그다음이다.

`ceiling.py`·`roi.py` 는 **새 판을 판정하기 전에 먼저** 돌린다. 도달 불가능한 목표를 향해
시뮬레이션을 돌리는 일을 막는다.
