# 진단 스크립트 — `docs/BOTTLENECK.md` 의 표를 만드는 것들

전부 `PYTHONPATH` 없이 저장소 뿌리에서 `python scripts/diag/<이름>.py <스템> ...` 로 돈다.
스템은 `out/M/M14/s101` 처럼 `_target.wav`·`_fit.wav`·`_track.npz` 앞부분이다.

| 스크립트 | 무엇을 답하는가 |
|---|---|
| `ceiling.py` | **이 지표의 천장**. 잡음의 실현이 다르면 완벽한 모형도 몇 점인가 |
| `roi.py` | **어디를 고치면 몇 점인가**. 한 부분만 목표로 갈아 끼우고 env 재계산 |
| `where.py` | 남은 오차를 구간(유성·마찰·무음)과 대역으로 쪼갠다 |
| `harm.py` | 배음 차수별 진폭·주파수 오차 |
| `harmctl.py` | 위 오차가 **실현 잡음인지** 대조군으로 가른다 |
| `slope.py` | 배음 오차가 **포먼트 자리** 탓인지 (국소 기울기와의 상관) |
| `physcheck.py` | 극이 물리와 맞는가 — 관 길이·대역폭·극 간격·개수 |
| `bwsrc.py` | 대역폭 과대가 **분석기** 탓인지 **적합기** 탓인지 |

`ceiling.py`·`roi.py` 는 **새 판을 판정하기 전에 먼저** 돌린다. 도달 불가능한 목표를 향해
시뮬레이션을 돌리는 일을 막는다.
